# 官方录音选择与播放恢复

## 1. 职责与入口

- `MusicNativeApplication` 在进程内公开 `music.official.candidates`，负责网易云、QQ、酷狗官方录音的匹配、已确认来源偏好和有界目录发现。
- 该入口不是 Node RPC，也不执行洛雪音源脚本。官方平台协议、账号快照、质量策略和持久缓存均由原生 owner 持有。
- 候选只描述可继续核验的录音身份，不授予播放权限。真正取链、完整文件复用和恢复都必须重新核对当前账号代次、账号作用域、质量策略、录音身份及媒体授权。
- 稳定队列歌曲和 occurrence 不会被跨平台发现结果替换。播放器只保存当前接受的录音快照，歌词、高潮、反馈和来源显示消费同一快照。

## 2. `music.official.candidates`

请求使用唯一当前形态：

```text
{ song, quality, qualityPolicySignature, discover, page? }
```

约束：

- `song` 必须满足当前歌曲 DTO；`quality` 为 `auto` 或当前质量策略支持的明确请求。
- `qualityPolicySignature` 必须等于本次获取到的当前策略签名。
- `discover` 为布尔值；`page` 缺省为 1，只允许 1–3。
- 每个平台目录请求每页最多 30 条，单次发现总预算 12 秒。
- 仅使用当前可取得官方播放会话的平台。网易云 128k 在账号读取已经稳定为空时可以取得受限匿名会话；该会话不是登录账号，不适用于更高音质或公共账号接口。

响应包含当前歌曲快照、候选、平台失败、页号、后续页标记、质量策略签名及是否完全缺少授权会话。候选附带 `platform`、`sourceKey`、`scope` 和 `generation`，但不包含凭据、Cookie、媒体 URL 或请求头。

录音匹配遵循以下边界：

- 只接收 `wy`、`tx`、`kg` 三个平台的当前录音映射。
- 必须通过当前歌曲身份、时长／版本兼容和 quarantine 检查，不能只按标题匹配。
- 最多保留 24 个候选，每个平台最多 8 个。
- 同质量下优先最近确认来源，其次原歌曲主来源，再按稳定来源键排序。
- 发现不会写曲库、队列、搜索历史或可见搜索会话。

## 3. 自动选择

未指定脚本实例或明确录音时，播放器执行唯一自动链：

1. 读取当前歌曲已有映射和同账号作用域、同代次、同质量策略／请求下的已确认来源偏好。
2. 在目录发现或取新 URL 前，依次核验可复用的已授权完整文件。
3. 首次需要发现时，对当前可用的三个官方平台并发请求第一页；每个平台最多 30 条，发现预算 12 秒。
4. 按平台分组解析候选。平台之间最多三个 worker 并发，同一平台录音串行尝试；整体解析预算 35 秒。
5. 选择当前策略下质量排名最优的成功结果。相同排名保持确认来源优先顺序；其他稍后完成的结果不能切换已经接受的流。

已确认来源只影响顺序，不授予播放权限。缓存命中、URL 解析、平台返回和原生媒体打开都要继续通过当前授权与身份检查。失败不能改播无关歌曲、标题近似但身份不兼容的录音或脚本来源。

## 4. 手动录音选择

- 当前播放器的来源面板最多加载三页候选；滚动到末尾时才请求下一页。关闭面板、切歌或关闭 App 会取消当前发现。
- 歌曲列表中的平台意图属于被选中的列表行，不得切换另一首正在播放的歌曲。
- 手动选择先解析并验证目标，仍在播放的输入在目标可用前不会退休。
- 目标打开失败后，只允许重新解析并恢复此前接受的录音一次；不得转向其他录音、其他歌曲或自动来源。
- 手动操作成功后才更新当前录音快照、反馈、歌词来源、高潮信息和来源记忆。

## 5. 播放恢复

自动官方播放的恢复顺序固定为：

1. 对当前已选录音执行一次精确 URL 刷新。
2. 仍失败时，排除已经失败的 `sourceKey` 和 URL，在兼容官方候选中最多执行 4 次跨录音尝试。
3. 单次自动恢复链总预算为 55 秒。

只有可刷新网络错误、明确媒体打开／播放失败及已分类的候选不可用错误可以进入上述恢复。鉴权代次变化、账号作用域失效、质量策略变化、撤销和调用方取消直接围栏旧操作。脚本来源和手动明确录音不进入自动跨录音恢复。

恢复保持同一队列 occurrence、播放位置、暂停意图和倍速。新来源只有在原生播放器成功重新打开后才成为当前来源；旧来源的迟到缓存回执或回调不得覆盖新状态。恢复权耗尽或授权到期且无法续期时停止当前输入，不启动无限重试或刷新环路。

## 6. 当前持久格式

### `music.playback-sources.v1`

- 保存有界 URL 缓存和真实 `Started` 后确认的录音偏好。
- 确认指针只保存受限录音元数据、账号作用域／代次、质量请求和策略签名，不保存凭据。
- 读取确认指针不会续期；当前 TTL 为 30 天。
- 缺失文档视为空，首次写入直接创建当前 schema 1。
- schema 不符、字段缺失／多余、非规范整数、损坏保护数据或超限文档明确返回 `CACHE_DATA_INCOMPATIBLE`，原字节不改写。

### `music.playback-files.v1`

- 保存完整音频文件索引及与 `scope + songId + qualityCacheSignature` 严格绑定的当前回执。
- 索引、键、文件名、摘要、规范整数、时长、授权期限和受限媒体信息必须整体通过当前格式校验后才能打开文件、启动 producer 或请求网络。
- 缺失索引视为空；非当前 schema、损坏 entry、保护失败或超限索引明确失败，不能降级为缓存 miss。
- 普通文件丢失、可淘汰缓存存储不可用或媒体文件不可用仍可按缓存 miss 处理，但不会创造离线授权。
- 只有用户明确确认的“清空播放缓存”操作可以替换索引并回收缓存文件；它是用户确认后的显式删除。

不兼容数据保持原样并通过明确错误交给调用方。

## 7. 确认、授权与匿名标准音质

- 只有原生播放器的真实 `Started` 事件可以确认来源历史或发布待播放完整文件；解析、预载和候选发现不能确认播放。
- 官方完整文件复用仍需当前授权。仅在线缓存不会自动获得离线许可。
- 网易云标准音质使用固定 128000 bitrate 的官方原生请求，由服务端实际响应决定是否可播；必须拒绝试听片段、空 URL、错误格式、错误录音和过期媒体。
- 网易云匿名会话只在账号状态已稳定为空且未被撤销时存在；登录、登出、账号写入不确定、owner 关闭或代次变化都会使其失效。
- QQ、酷狗及网易云更高音质继续要求各自当前账号和权益边界，不得借匿名标准音质扩大权限。
