# 统一音源、录音选择与播放恢复

## 1. 职责与入口

- `MusicNativeApplication` 在进程内公开 `music.official.candidates`，负责网易云、QQ、酷狗官方录音的匹配、已确认来源偏好和有界目录发现。
- 该入口不是 Node RPC，也不执行洛雪音源脚本。官方平台协议、账号快照、质量策略和持久缓存均由原生 owner 持有。
- `MusicCapability` 在该目录能力之上统一选择已启用的内置与网络源。内置／网络是类型和适配职责，启停状态各自独立；关闭内置平台不排除脚本的同平台能力，禁用脚本不参与候选。
- 候选只描述可继续核验的录音身份，不授予播放权限。真正取链和恢复必须核对质量策略、录音身份及实际来源权限：内置来源检查当前账号代次、作用域与媒体授权，脚本来源检查 installation、generation 与声明能力。完整文件复用仍限于具备当前授权的官方音频。
- `ResolveAutomaticSources` 通过单次官方 planning 结果回调，将当次 `song` 快照与 `preference` 顺序交给网络源；发生目录发现时使用本次发现的兼容录音，不额外重复发现，也不把官方账号权限作为脚本权限。最终接受的来源保留实际 installation、platform、generation 和 sourceKey，不能由录音的目录来源推断取链类型。
- 稳定队列歌曲和 occurrence 不会被跨平台发现结果替换。播放器只保存当前接受的录音快照，歌词、高潮、反馈和来源显示消费同一快照。
- 官方请求显式消费[同一客户端上下文](music-platform-client-context.md)。WY 资源、协商密钥和实际媒体响应完成各自校验后才交接 Cookie；错误录音、受限／过期媒体或无效结果不更新客户端状态。

## 2. `music.official.candidates`

请求使用唯一当前形态：

```text
{ song, quality, qualityPolicySignature, discover, page? }
```

约束：

- `song` 必须满足当前歌曲 DTO；`quality` 为 `auto` 或当前质量策略支持的明确请求。
- `qualityPolicySignature` 必须等于本次获取到的当前策略签名。
- `discover` 为布尔值；`page` 缺省为 1，只允许 1–3。
- 每个平台目录请求每页最多 30 条，单次发现总预算 12 秒。
- 仅使用当前可取得官方播放会话的平台。网易云 128k 在账号读取已经稳定为空时可以取得受限匿名会话；该会话不是登录账号，不适用于更高音质或公共账号接口。

响应包含当前歌曲快照、候选、平台失败、页号、后续页标记、质量策略签名及是否完全缺少授权会话。候选附带 `platform`、`sourceKey`、`scope` 和 `generation`，但不包含凭据、Cookie、媒体 URL 或请求头。

录音匹配遵循以下边界：

- 该官方目录入口只选择 `wy`、`tx`、`kg` 三个平台的当前录音映射；输入歌曲中其他合法平台映射继续保留，可由声明对应能力的已启用脚本消费。
- 复用[统一歌曲录音集合](music-native-library.md#统一歌曲与录音分组)，新候选与代表及所有已保留录音都必须兼容（包括非官方平台映射），不能只按标题或代表时长匹配。
- 官方目录候选最多 24 个、每个平台最多 8 个；这是目录发现的资源边界，不限制脚本安装数量，也不删除输入歌曲已有的映射。录音数据由同一个集合拥有，网络源直接消费本次发现的快照和偏好顺序。
- 同质量下优先最近确认来源，其次原歌曲主来源，再按稳定来源键排序。
- 发现不会写曲库、队列、搜索历史或可见搜索会话。

## 3. 自动选择

未指定当前歌曲录音时，播放器执行统一自动选择：

1. 读取当前启用的内置平台和脚本实例、歌曲已有兼容录音，以及同账号作用域、同代次、同质量策略／请求下的已确认录音偏好。读取安装集合不启动脚本运行时。
2. 在目录发现或取新 URL 前，依次核验可复用的官方已授权完整文件。命中的完整文件或 prepared 缓存作为内置候选，仍与脚本候选比较质量；缓存命中不能跳过脚本选择或直接决定最终来源。
3. 首次需要发现时，对当前可用的三个官方平台并发请求第一页；每个平台最多 30 条，发现预算 12 秒。网络源通过本次 planning 结果回调取得同一兼容录音快照及排序，不额外发现；内置音频准入不能删除脚本可用的同平台录音。
4. 内置解析仍按平台分组，最多三个 worker 并发、同一平台录音串行尝试；网络源按录音偏好顺序逐个请求已启用脚本，实际需要时才激活实例。两类来源共用整体 35 秒解析预算。
5. 选择当前策略下质量排名最优的成功结果。已验证实际音质参与排名，未验证结果沿用请求音质且不标称已验证；同质量先按现有录音偏好排序（已确认录音、原歌曲主录音及稳定录音键），再按稳定 provider 顺序选择。类型不构成互斥条件，也不新增类型排序设置；迟到结果不能切换已经接受的流。

已确认偏好只影响顺序，不授予播放权限。缓存命中、URL 解析、平台返回和原生媒体打开都要继续通过当前权限、质量与身份检查。已分类的候选不可用允许跨类型继续，候选仍须与当前歌曲兼容；取消、存储损坏、未知提交、账号或脚本代次变化、质量或音源策略变化均终止旧操作，不能当作候选失效吞掉。

`ScriptPlayback` 的内部 25 秒期限届满返回 `TIMEOUT`，仅令该脚本候选不可用，其他已成功的内置候选仍可参与最终比较。普通调用方取消、源撤销或质量取消保持 `CANCELLED` 并终止旧操作；它们同时发生时，不能改报为内部超时。

## 4. 手动录音选择

- 当前播放器的来源面板最多加载三页候选；滚动到末尾时才请求下一页。关闭面板、切歌或关闭 App 会取消当前发现。
- 歌曲列表中的平台意图属于被选中的列表行，不得切换另一首正在播放的歌曲。
- 手动选择限定当前歌曲的 `platform + sourceKey`，由满足质量与权限要求的已启用源提供；不选择内置／网络类型或全局播放模式，不改变队列歌曲身份。
- 同一录音可以经不同类型或不同脚本实例提供。统一选择先解析并验证来源，仍在播放的输入在新来源可用前不会退休；来源实际身份随本次接受结果记录。
- 手动切换打开失败后，只允许精确恢复此前接受的来源一次，不改选另一录音或歌曲。成功选定录音后的恢复保持原 20 秒预算；精确刷新失败后可切换同一录音的已启用 provider，继续保持该录音约束。
- 手动操作成功后才更新当前录音快照、反馈、歌词来源、高潮信息和来源记忆。

## 5. 播放恢复

自动播放的恢复顺序固定为：

1. 对当前接受的来源执行一次精确 URL 刷新，保持其 installation、platform、generation、sourceKey 和质量。
2. 仍失败或候选明确不可用时，排除已经失败的 `installation + platform + sourceKey` 和 URL，在已启用内置／网络源的兼容候选中最多执行 4 次来源切换。内置转网络、网络转内置和跨脚本实例都遵守同一边界；同平台同录音的内置失败不排除脚本提供该录音。
3. 单次自动恢复链总预算为 55 秒。

只有可刷新网络错误、明确媒体打开／播放失败及已分类的候选不可用错误可以进入上述恢复。鉴权或脚本代次变化、账号作用域失效、质量或音源策略变化、撤销、调用方取消、存储损坏和未知提交均终止旧操作。手动明确录音继续限定同一录音；自动选择则可在兼容录音间恢复。

恢复保持同一队列 occurrence、播放位置、暂停意图和倍速。新来源只有在原生播放器成功重新打开后才成为当前来源；旧来源的迟到缓存回执或回调不得覆盖新状态。恢复权耗尽或授权到期且无法续期时停止当前输入，不启动无限重试或刷新环路。

## 6. 当前持久格式

### `music.playback-sources.v1`

- 保存官方来源的有界 URL 缓存和真实 `Started` 后确认的录音偏好；统一选择复用这些偏好，不新增脚本持久缓存。
- 确认指针只保存受限录音元数据、账号作用域／代次、质量请求和策略签名，不保存凭据。
- 读取确认指针不会续期；当前 TTL 为 30 天。
- 缺失文档视为空，首次写入直接创建当前 schema 1。
- schema 不符、字段缺失／多余、非规范整数、损坏保护数据或超限文档明确返回 `CACHE_DATA_INCOMPATIBLE`，原字节不改写。

### `music.playback-files.v1`

- 保存官方完整音频文件索引及与 `scope + songId + qualityCacheSignature` 严格绑定的当前回执。
- 索引、键、文件名、摘要、规范整数、时长、授权期限和受限媒体信息必须整体通过当前格式校验后才能打开文件、启动 producer 或请求网络。
- 缺失索引视为空；非当前 schema、损坏 entry、保护失败或超限索引明确失败，不能降级为缓存 miss。
- 普通文件丢失、可淘汰缓存存储不可用或媒体文件不可用仍可按缓存 miss 处理，但不会创造离线授权。
- 只有用户明确确认的“清空播放缓存”操作可以替换索引并回收缓存文件；它是用户确认后的显式删除。

不兼容数据保持原样并通过明确错误交给调用方。

## 7. 确认、授权与匿名标准音质

- 只有原生播放器的真实 `Started` 事件可以确认来源历史或发布待播放完整文件；解析、预载和候选发现不能确认播放。
- 官方完整文件复用仍需当前授权。仅在线缓存不会自动获得离线许可。
- 受保护完整文件缓存和离线授权仅属于官方音频。混合启用以及当前由网络源播放不阻止下一曲可用的官方预加载，网络源不新增离线缓存；prepared 候选仍须与脚本比较质量，再按录音偏好和稳定 provider 顺序选择，实际播放继续核对当前身份与授权。
- 网易云标准音质使用固定 128000 bitrate 的官方原生请求，由服务端实际响应决定是否可播；必须拒绝试听片段、空 URL、错误格式、错误录音和过期媒体。
- 网易云匿名会话只在账号状态已稳定为空且未被撤销时存在；登录、登出、账号写入不确定、owner 关闭或代次变化都会使其失效。
- QQ、酷狗及网易云更高音质继续要求各自当前账号和权益边界，不得借匿名标准音质扩大权限。
