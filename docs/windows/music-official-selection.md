# 统一音源、录音选择与播放恢复

## 职责与契约

跨端行为以[歌曲资料与智能播放](../common/music/smart-playback.md)为准，本文件说明 Windows 接口与准入。

`MusicSourceSession` 属于当前歌曲的播放意图。自动播放、手动换档、查看更多、加载更多与音源不对复用同一份尝试结果。
稳定队列及 occurrence 不被补搜结果替换；歌词、封面和反馈消费接受的录音快照。

- `music.official.candidates {song,quality,qualityPolicySignature,manualSource?}`：只读已接受映射、当前账号权限和来源偏好；不搜目录。`manualSource` 仅使明确档位跳过自动音质准入，仍检查来源启用、录音及账号授权；取链、确认及缓存授权接口沿用该手动意图。
  返回 song、candidates、qualityPolicySignature、authorizationRequired。候选有 platform/sourceKey/scope/generation，无 URL 或凭据。
- `music.songs.complete {song,platforms,contentFailed?}`：共享 matcher 补缺失平台，并由服务端对内容失败平台核对陈旧条件后重查；官方和脚本共用，关闭官方不阻断同平台脚本。
- 官方仍只有 wy/tx/kg；五平台目录映射可用于声明相应能力的脚本。官方最多 24 个候选/每平台 8 个是候选资源边界，不是安装数量限制。
- 三页官方发现、强制绕过 matcher 冷却与手动强制取新 URL 的路径已移除。

## 按需匹配与匹配状态

每歌曲/平台记录 matched、notFound、failed、时间、条件和检索词。相同条件的 notFound 在 24 小时内不重搜；failed 不视为无结果。
7 天仅为匹配新鲜度：不删除已有正确映射、不后台请求、不阻断缓存。已有可用映射直接复用。`MusicSongMatcher` 统一接收搜索、目录和曲库已获资料，读取时投影兼容录音事实；平台重查须同时满足本次内容失败与陈旧／缺失查询证据。
同条件在途匹配合并、等待者取消互不误伤；账号变化封闭旧结果。只有收藏或本地歌单成员的派生数据落盘。
匹配文档命名空间仍为 `music.song-matches.v1`，当前 envelope 为 `version: 2`：统一录音资料、逐平台 query/context/checkedAt/范围及 matchedAt、入口作用域的录音排除。只读取当前格式；旧版不迁移或覆写，补搜明确报告 `CACHE_DATA_INCOMPATIBLE`。目录／曲库已有资料仍可在可选派生缓存不可用时展示。
搜索结果观察遵守[搜索观察者](music-search-observers.md#匹配观察)，保留查询范围和原检查时间，不把宽泛单页缺席当成歌曲专用查空。失败与取消不写成 notFound，晚到旧观察不覆盖较新证据。
新录音与所有保留录音核对身份及 `max(3s,较短×2%)` 时长容差；自动错录音排除与用户错源排除独立。

## 自动选择

1. 读取策略、官方启用、脚本声明和用户排除。只派发歌曲映射与启用脚本声明的平台/音质交集。
2. 按设置从首选类目开始沿 qualityOrder 向后，跳过禁用项；auto 从首项开始。默认 flac，无损。
3. 每档先找合格完整文件、URL 回执和会话缓存，再并发最多三个候选取链；首个合格结果停止未完成请求。
4. 该档已有候选耗尽才补搜缺失且有来源可参与的平台一次，所有脚本共享结果，再尝试新增映射。
5. 首选档完全耗尽才降级。官方返回更低的实测档只作为低档候选，不抢过高档脚本；低档缓存同理。

排除先于所有缓存。脚本无显式到期时间的会话 URL 最多保留十分钟；有到期时间的提前三十秒失效。
本次刚解析/刷新的 URL 按实际有效期完成当前选源，不因上述缓存提前失效窗口立即重复解析；重新选择时仍按音质顺序评估。
脚本服务不可用与没有脚本不同，但不阻断官方候选。网络或媒体表示失败只排除本次来源的请求档，不阻断其其他档位；明确录音失配才跨档拒绝。暂时拒绝不继承到新的来源/策略会话，用户持久排除保持独立。
官方去除本地 VIP 前置拦截，由上游返回决定；试听、加密、失配仍拒绝，会员只影响完整文件离线许可。

## 当前播放操作

- 未播放隐藏音质按钮；解析中为匹配中，就绪按实测档显示标准/高音质/无损/Hi-Res/母带，空间统一显示空间；无确证为音质未知。
- 菜单最上方查看更多，只投影缓存尝试，不发请求。加载更多按独立手动档位集合探索所有启用脚本的兼容声明，不读取自动档位裁剪；明确选择、精确续链和文件回源同样保留手动准入。关闭面板、换歌取消旧探索。
  补搜仅在收到并校验结果后记为完成；取消不算“已搜无结果”，后续明确操作可重试，已完成的正/负结果仍去重。
- 音源选择按内容自适应高度，候选较多时仅列表滚动。当前播放区展示已接受回执的音质标识、音质名和平台／来源；未确认音质不画档位标识。没有已确认可切换项且未加载时显示空态，失败候选仍保留禁用状态；自动选择保留为底部独立动作。该外观不引入自动解析、滚轮扩展或新的选源策略。
- 手动档位只作用于当前播放，不改全局、不降级。找不到提示未匹配到对应音质，旧流继续。
- 具体结果的请求档位与实测音质分开：同一provider／平台／录音／请求档的完整文件验证可以补齐原未知回执，不能拿请求标签否定实测结果；两份回执均已确认实际音质时，不允许续链暗换实际档位。未知仍显示未知，不伪造为已确认音质。交接接受的回执与来源列表共享后续文件证据，不因选择操作延长URL有效期。
- 坏 URL 或准备失败继续尝试其他同档候选，全部失败保留旧流。指定一条结果锁定 provider×平台×录音×请求及已知实测音质，URL 刷新、缓存回源与恢复也不暗换或降档。
- 新媒体先静音暂停准备、核对真实时长，再按实时位置交接；旧流在准备期继续，失败/取消不受影响。
  保留暂停意图、倍速和音量，换歌/二次选择取消旧准备；旧流先静音再允许新流输出，完整文件缓存亦走准备交接。原生提交点同步发布业务来源与选择条件，不等待旧输入异步释放。
- 再选当前档也取消较早的异档请求；仅当前输入健康、会话有效且未排除时直接复用，否则同档重选并保留暂停意图。脚本/官方启用/默认策略变化后的显式操作重读当前准入集合，复用有效历史，记住录音仅作优先而非硬限制。既有“录音”控件的显式指定仍锁录音，与源列表产生的历史偏好分开；自动选择/音源不对解除当前录音锁。
  官方账号代次变化同样刷新后续选源会话，不继承旧账号的成功回执或授权失败；当前合法脚本播放及用户持久排除不受影响。
- 更多为菜单，包含播放倍速（0.5–3.0，步长0.1，恢复1.0×）与音源不对。

## 错源管理

错源暂停后，普通播放、系统媒体 Play、歌词确认及推荐恢复都不能直接恢复被排除的输入；保持暂停并提示切源或手动解除。解除记录本身不播放，解除后的明确恢复才允许使用该输入。

`music.sourceExclusions.list/add/remove` 持久保存歌曲 songId × provider（installation UUID 或 official）× platform，覆盖所有音质。
多条可累计，不随七天、清缓存、脚本更新或重启解除；仅用户主动恢复，恢复不播放也不启用来源。
设置提供查看、选择真实队列歌曲及来源/平台添加、恢复；重复添加幂等，写失败不假成功。
添加排除也会撤销尚未接受的同来源故障恢复媒体；解析完成、文件读取与重新打开之后仍核对最新排除，不能只围住手动切换。无关歌曲、provider 或平台的排除不撤销合法恢复。
音源不对先经 `StopOutputForHandoffAsync` 停止错误输出并保存位置，再落盘排除、按当前档缓存优先找替代；无替代或保存失败保持暂停，不跳歌。交接前再次核对排除。

## 恢复与验证边界

HTTP 过期等失败允许一次精确刷新；自动意图重新按档位评估刷新结果，低档回执不能抢过尚可用的高档来源；手动档位仅继续同档，指定结果不可暗换其他来源。意图独立于候选保存，连续故障不会变成自动降档。切换期间旧输入自身故障不取消正在执行的新选择，也不另启恢复竞速；新选择成功接管，失败后才按切换前已提交意图恢复。成功交接或换歌后旧故障不再作用于新输入，错源无替代保持暂停。取消和身份变更封闭未接受的新解析。
网络输入失败或到期时，先尝试同身份已完成并验证的本地文件，再使用精确刷新额度；脚本停用/删除不阻止有效文件续播。文件损坏只淘汰该副本，回源仍核对当前脚本运行权；录音失配和持久错源不允许借本地文件绕过。官方文件恢复仍检查当前授权/许可。
手动指定结果或切档的交接同样优先使用完整文件，不因会话结果仍携带网络 URL 而重新读取网络；排除快照变化先刷新后判断文件是否允许复用。文件准备失败可按精确条件回源，旧输入保持到替代准备成功。
音源返回、准备媒体、实际解码、完整文件校验统一与歌曲元数据比较：绝对差 ≤10 秒接受、>10 秒拒绝；未知时长不判失配。打开/恢复完成主动补检，不依赖打开期间的唯一时长事件。官方另行拒绝试听；跨平台元数据录音合并仍按上文的 3 秒/2% 规则。
脚本回执的 `duration` 独立于音质透传：正有限数字为秒数，缺失、null 或 0 归为未知，非法值拒绝。原生在打开前核对此时长，已知时长不使请求档位成为实测音质。
编译、替身和真实媒体回归不代表真实平台音源、非会员可播范围或无缝交接听感已验证。

## 独立播放历史

实际播放过的脚本音频可完整落盘，与官方文件共用 256 MiB 容量、30 天未使用淘汰、结构/哈希/静音解码校验和显式清理。只发布完整文件，不创建下载任务；每次仅一个文件生产者，实际播放缓存可异步等待被取消预取排空，不阻塞播放或并行新增下载；保存歌曲、原脚本 ID/名称、平台、录音和请求/实测音质，不持久化 URL 或请求头。脚本启停、删除、更新不撤销有效历史，只影响新解析。跨重启先查本地历史，排除先于历史。官方文件仍保留账号/许可及在线再授权边界，不能借历史绕过权限。

文件丢失、被清理或哈希不符时，可按同一身份向当前仍启用的来源回源；已删除/停用脚本不能新解析，结构不兼容的索引仍明确报错。回源结果遵循自动档位顺序或手动条件，不把文件失效等同于来源所有档位失效。历史文件不携带当前策略权力；下一首官方预加载使用当前会话/设置的策略，当前由脚本历史播放也不阻断预加载。
恢复中的索引读取或淘汰若遇到格式/保护错误，明确提示“播放缓存数据格式不兼容”，不降格为普通“播放失败”、不重建索引，也不借回源掩盖错误。
