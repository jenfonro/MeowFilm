# Windows 音乐设置呈现

## 页面与所有权

- `MusicSettingsView` 嵌入桌面壳的 `SettingsHost`；侧边栏、窗口导航和全局播放器仍由桌面壳持有，设置期间只隐藏播放器底栏而不销毁实例。“设置”标题与类别标签由公共窗口层显示在返回按钮右侧，内容区不再重复标题；标签按实际装配模块生成，当前为通用／音乐／影视。
- 普通页面与设置页都直接衔接紧凑页头，不再叠加额外内容区顶距；设置页仍以返回按钮、标题和类别栏组成专用页头。类别切换到模块自己的设置视图，不再由音乐设置显示空白影视页；[影视设置](film-settings.md)与音乐草稿各自保留，返回恢复最初内容位置，不重放已完成的业务导航。
- 顶部五个分类是“账号与平台”“搜索”“音质”“歌词与封面”“音源”。普通设置保持连续分区；前四个分类将对应分区置于滚动视口顶部，音源切换为同一内容区内的独立管理页。
- 普通分区包括账号、歌曲／歌单搜索、播放音质、错源管理和歌词／封面。手动滚动同步分类，分类不重排内容、不重复激活业务。末段置顶空间从实际视口和分区高度计算，不拉伸设置面板。
- 搜索没有模式选择，歌曲／歌单面板只显示平台列表；标题右侧“高级设置”打开应用居中对话框，编辑单次请求页数、平台并发数和缓存时长（分钟）。有效输入在失焦、回车或关闭浮窗时立即保存，越界输入恢复为已保存值，Esc 放弃编辑。搜索、音质、元数据、外观、缓存和真实账号操作继续调用既有 `MusicCapability` 与原生 owner，不新建偏好 writer、迁移或旧方案兼容层。
- 派生的编辑可用状态由 `MusicCapability` 随实际忙碌状态发布；不依赖设置视图曾经 Loaded 或视图代替业务 owner 补发状态。
- 分类切换和滚动关闭账号临时浮层；窗口移动和尺寸变化保持居中；设置激活、退休、取消与排空复用原生生命周期。
- 响应断点由 `SettingsLayout.Mode` 附加行为拥有：影视规则容器启用 `Sections`，三个双面板容器启用 `Pair`；行为读取所附加容器的实际 DIP 宽度，并通过可继承的 `IsNarrow`／`IsStacked` 供字段与双列表样式消费。业务 owner 不保存窗口或容器宽度。
- 行为在初次布局及 Loaded 时更新；Unloaded 停止尺寸监听并保留最后的布局状态，重新 Loaded 按当前宽度刷新。设为 `None` 移除监听并清除该模式写入的状态，容器不依赖业务模块即可独立使用。
- “通用 → 首页数据源”提供音乐数据源下拉框，复用现有控件样式；网易云／酷狗选择通过 `music.catalogSource.settings.get/save` 持久化。只在成功回执或权威读取确认后采用新平台，失败可重读，通知复用统一出口。来源偏好与账号、搜索、音源启停及在线设置独立；存储格式见[原生曲库](music-native-library.md)。

## 通用外观

- 通用分为“外观”“首页数据源”“缓存控制”三个独立内容区；`MusicHomeSourceSettingsView` 只激活数据源读写生命周期，隐藏时取消并排空源保存，App关闭同样排空。取消关闭会重新读取尚未加载的数据源；读取失败在当前页提供重试，不重放保存或阻断关闭取消。`MusicCacheSettingsView` 复用播放缓存owner与清空确认，不进入音乐账号/脚本管理页，不新增缓存策略。
- “通用”位于音乐之前，程序主题与播放器配色分别由 App 与音乐 owner 持有。`MusicAppearanceView` 通过 `IDesktopGeneralSettingsSource` 贡献到通用外观；只读取外观，不激活账号、来源或整页音乐设置。旧音乐外观栏目与选择处理器已移除，歌单网格／列表偏好一起迁移入口，原存储值不变。
- 播放器保留跟随歌曲／固定配色、原预设及原生 CAS 语义，`colorPalette` 还可保存不透明 `#RRGGBB`。已确认不保证写入自定义色后降级旧版；不迁移、双写或清理音乐库。自定义值沿同一 `PlayerPalette` 路径影响原播放器背景与进度颜色。
- `ColorSelection` 为主题和固定播放器色提供共用下拉框；自定义选项不写盘，同行 HEX 框显示保存色，输入失焦/回车提交，右侧笔形按钮打开锚点色盘。失败恢复权威选项与保存色。`ColorPicker` 是共用 WPF 色盘：饱和度/明度平面、色相、HEX 与草稿色块。拖动/键盘/输入只更新草稿，确认发布一次提交，取消/Esc/隐藏不写入；固定配色选项与歌单样式保持选择即保存。错误走 `NoticeOutlet`。
- 设置页面和内部来源列表使用 `SettingsScrollChrome.xaml` 的常显滚动条，横竖支持、溢出才显示，不挂载空闲隐藏行为。首页／频道等仍用原 OverlayScrollChrome 自动隐藏。

- 音质选择标签为“起播目标音质”，保留原 `request` 数据契约和优先级/回退算法，不把该值误称为不可降级的最低音质。

## 参考布局与资源

- 保留 ui-design 的既有布局，以 meowfilm-server 的浅色表单、绿色操作与选中态为配色依据，保留现有 WPF 栈和 App 字体，不用网页替代原生界面。
- 开启开关保持绿色；暂不可编辑时降低控件强度但不改成关闭灰色。下拉菜单只对悬停/键盘当前项浅绿高亮，已选值在收起框显示，不重复用固定选中底色。
- `SettingsTheme.xaml` 只在设置子树中提供语义色与控件样式。普通正文 14 DIP、次级信息 12 DIP、分区标题 16 DIP；按钮约 32 DIP，下拉框约 34 DIP。
- 普通文本使用 `TextFormattingMode=Display` 与 `TextRenderingMode=Auto`，保留动态系统消息字体、布局取整、像素对齐、高对比与自动化名称。设置页、音源设置页、目录、播放列表、入口卡片和影视视图取消整页强制灰度；独立 seek 提示也使用此策略。`Auto` 允许 WPF 按实际目标表面选择抗锯齿，不设置 `ClearTypeHint` 强行穿透透明合成。
- 入口卡片的预览渐变、文字透明度与位移动画，以及影视评分阴影／海报缩放保留原效果；这些合成区域交给 WPF 自动选择渲染，无需把普通标题或整页锁定为灰度。歌词遮罩与详情页的专用策略由对应歌词呈现 owner 记录。
- 分类按文字自然宽度与固定间距排列，高 44 DIP；窄窗口在分类栏自身横向滚动，不平均挤压标签。方向键、Home、End 使用原生焦点导航。分区上下内边距 12 DIP、标题行高 24 DIP、标题与内容间隔 8 DIP。
- 连续内容最大宽 1248 DIP，栏目标题始终在上，内容填满下方宽度；不保留宽屏左侧标签空栏。歌曲／歌单搜索、普通／空间音质和歌词／封面三组双面板在容器宽度低于 544 DIP 时纵向堆叠。
- 歌曲搜索／歌单搜索、音质／空间音频、歌词／封面以分区标题加左右两块等宽面板平铺，间距 24 DIP；面板组宽度小于 544 DIP 时上下堆叠。外观已统一到通用类别，预设色使用下拉选择，自定义色使用同行 HEX 输入框与笔形色盘按钮，颜色编辑器支持键盘。
- 歌词与封面两个列表共用现有元数据平台偏好，拖动或开关任一列表都写入同一原生设置。
- 账号表格使用独立平台与账号列，不显示平台数量或平台筛选，始终列出全部平台；末项不重复绘制分割线。五个平台使用随包发布的官方 Logo，来源与转换记录见 `LICENSES/NOTICE.md`。
- 用户头像只属于账号列，加载中或缺失时不用平台 Logo 垫底。三平台账号、会员摘要、资料刷新与退出确认的身份／generation 边界见 `music-native-accounts.md`；酷我、咪咕只展示公共目录状态。
- 菜单与确认浮层使用不透明底色、紧凑动作和明确层级；下拉框保留原生键盘行为。焦点与高对比状态使用系统语义颜色，次级文字为满足对比度做必要调整。
- 页面只保留标题、控件、业务内容、状态和确认；操作结果及错误沿统一 `NoticeOutlet` 发布，不插入解释或教程。

## 原生优先列表

- `SettingsPriorityList` 呈现歌曲搜索、歌单搜索、音质、空间音频、歌词及封面顺序。行高 52 DIP，抓手 36×36 DIP 绘制三条横线，开关为 32×18 DIP；列表不显示序号。以下移动与拖动规则仅适用于这些优先列表，不用于音源管理。
- 优先级等普通设置列表由整页滚动；展开下拉框、音源管理及固定高 264 DIP 的错源列表保留内部滚动。错源框在空、少量、多量记录时高度稳定，不限制记录数量。
- 标题工具栏不再提供上移／下移或“启用”标题。每行按名称、开关、右侧三横线手柄排列；手柄的Alt+上下原生路由命令与拖动复用同一移动请求，首末边界、在途写入和拖动期间禁止不合法移动。列表共用圆角卡片和行分隔线，hover/选中不遮挡分隔线。
- `SettingsReorderDrag` 只由抓手启动。选择行与开关不排序；拖动时原行隐藏，浮动行跟随指针，以浮动行中心越过相邻行中线决定目标，被越过的行以 150 ms 平滑让位（关闭动画或高对比时直接到位）；不绘制插入标记，不提前修改业务集合。
- 释放时重新命中最终坐标，并核对外层滚动裁剪后的可见区域，将目标位置转换为当前条目；一次手势最多调用一次既有原生 `MoveSearchPlatformAsync`、`MoveQualityAsync` 或 `MoveMetadataPlatformAsync`。保存、CAS 与失败后的权威状态恢复仍由原生 owner 负责。
- 抓手保留 Alt+上／下键盘移动。取消、隐藏、卸载、禁用、尺寸／主题变化、集合替换或顺序变化退休旧手势；迟到释放不能消费旧插入位置。
- 浮动位图、原行显示状态、让位变换、Adorner 和边缘滚动计时器与手势一起释放，不跨页面保留。

## 音源管理契约

- `MusicSourcesSettingsView` 在同一管理列表列出三内置平台及已安装脚本；类型区分内置、本地、网络，取决于真实导入方式而非脚本 homepage。全部已启用源均可参与当前歌曲的统一播放候选，各自的真实管理 API 和状态归属保持独立。
- 官方内置源为网易云 `wy`、QQ `tx`、酷狗 `kg`，各自独立持久化启停；设置经原生 owner 的 `music.officialSources.settings.get/save` 读写，不与脚本安装状态或歌词／封面元数据设置共用字段。
- 官方源开关是官方音频来源准入策略：关闭的平台不得进入官方自动候选，也不得通过手动录音选择或直接调用官方音频解析绕过。门禁由原生候选与音频 RPC 执行，不依赖客户端隐藏或仅更新视图状态；关闭内置平台不限制已启用脚本的同平台能力，也不改变账号操作、通用搜索、歌词或封面行为。禁用脚本不得参与候选。
- 脚本源通过真实的 `music.sources.*` 管理接口持久化安装、编辑、启停、更新、回退、检测和移除；原生只适配选中文件快照，经 stage 上传交给公共 `music@0.8.0` 模块。公共模块是安装事实、源码与 guest KV 的唯一 writer，只使用新格式目录，不读取、迁移或删除旧原生安装数据，见[公共脚本契约](../runtime/music-script-runtime.md)。本地导入支持多选 `.js` 文件，网络导入只接受 HTTPS 且拒绝重定向，二者共用 16 MiB 单脚本资源上限；不设固定安装数量上限。导入不等于启用或执行，公共宿主由 App 启动。
- 音源管理只管理各源及其启停，不保存全局来源类型或平台目标。列表选中状态只决定管理操作的对象；播放按现有音质顺序、兼容录音、已确认偏好及各源权限统一选择，不增加音源排序或类型模式控件。
- 播放器中的“查看更多”只展示当前选源会话缓存，显式加载更多才推进剩余候选；手动选源、换音质不改写队列歌曲身份或全局默认。候选发现、选择和恢复契约见 [统一音源与录音选择](music-official-selection.md)。
- 同一列表中的内置平台开关和脚本条目均显示其真实 owner 状态和操作结果；文件选择、网络下载、检查失败及安装失败不能被视图内存状态伪装为成功。
- 音源管理不设筛选栏，列表保留独立滚动；最小窗口仅缩减页边距，不收紧列表行，保留可见首行及内部滚动。
- 表格列为选择框、启用、名称（下方版本）、类型、健康状态、五平台胶囊和固定操作。检测、编辑、更新、删除直接呈现；内置项仅检测可用，其余操作禁用占位。多选支持批量检测和确认后删除，启停与健康状态互不替代。
- 检测只对声明平台取固定样本链接，不下载音频或改变播放来源；平台通过为绿、失败为红、未测及不支持为不同灰色状态。编辑只改名称和网络地址，稳定安装身份不变；本地更新重新选文件，网络更新使用保存地址，编辑浮层保留回退入口。
- 表头随列表横向滚动，窄窗口可滚动到全部行内操作；纵向滚动保持表头可见。
- “错源管理”查看歌曲×来源×平台的持久排除，可从完整当前队列选择真实歌曲身份手动添加或主动恢复；恢复重新开放该来源的候选，不触发播放或启用来源。

## 对话框与音质菜单

- `DialogPlacement` 是 Desktop 的公共窗口居中机制。添加错源、搜索高级设置、登录/退出、音乐源编辑、影视编辑/确认与音源选择按整个窗口内容区居中，窗口移动/缩放重定位，所属控件隐藏/卸载或窗口关闭时退场。系统文件选择器沿用 OS；调色盘、下拉框及播放器功能菜单仍采用锚点定位。
- 底栏音质标记固定 72 DIP 宽，短名居中；常态内容与匹配状态逻辑不变。音质使用 WPF ContextMenu/MenuItem 的子菜单布局和键盘/鼠标生命周期，自适应文本宽度，保留原一级档位顺序。空间类型只在二级菜单显示，名称复用设置名称，sony360 显示“360全景音频”。
- 顶部“查看更多”打开独立“音源选择”对话框：当前播放音源信息、内部滚动候选与加载操作。打开只投影当前会话、不发解析；加载更多/切换继续调用原 owner，关闭取消扩展，换曲或视图卸载关闭浮窗。同曲重开后显式加载可重新发起被取消的发现，成功发现仍在会话内复用，不自动重试普通失败。没有新增匹配、缓存或音质持久化策略。

## 验证边界

本节记录覆盖契约与测试归属；原生测试执行结果单独记录，不以本文作为通过证据。

- 音源管理 UI 覆盖三内置平台与已安装网络源在同一列表中呈现、独立启停、混合启用与权威状态重读；管理条目选择不改变播放候选范围，手动录音选择只作用于对应歌曲。测试归属为 `MusicSourcesSettingsTests.cs` 与 `MusicOnlineTests.cs`。
- 官方设置持久化覆盖缺省全开且读取不写入、`wy/tx/kg` 独立启停及全关、保存后重读与 owner 重启恢复，以及同职责未知 CAS 结算；测试归属为 `MusicOfficialSourcesPolicyTests.cs`。`MusicSourcesSettingsTests.cs` 覆盖设置页读写真实 owner、重载后反映权威状态。
- 官方候选与音频原生门禁覆盖自动候选过滤，以及手动录音选择和直接官方音频解析无法绕过关闭状态；关闭内置平台仍允许已启用脚本提供同平台录音，同时验证开关不改变账号、搜索、歌词与封面行为。门禁测试归属为 `MusicOfficialSelectionTests.cs`。`MusicOfficialAudioTests.cs`、`MusicOfficialStandardTests.cs` 保留为现有音频解析、音质与授权基线。
- 脚本源覆盖本地多选、真实 `music.sources.*` 安装及后续管理、HTTPS 下载拒绝重定向、网络和本地内容共用检查安装流程，以及 16 MiB 含边界值。适配与 UI 测试归属为 `MusicOnlineTests.cs`、`MusicScriptIntegrationTests.cs`、`MusicNativeScriptTests.cs`、`SelectedFileSnapshotTests.cs` 和 `MusicSourcesSettingsTests.cs`；公共下载、存储、检测契约由 `tests/windows-music-script.test.mjs` 覆盖，不保留原生第二套目录与下载器测试。
- 原生 UI 回归覆盖锚点、末段置顶、页头标题与类别切换、两块平铺、优先列表尺寸与移动、让位拖动、整页滚轮、开关、键盘、高对比、取消／资源释放，以及账号和偏好消费者；布局用例位于 `MusicSettingsLayoutTests.cs`。

## 账号文件入口

“账号”分区标题右侧保留一个原生次级“导入导出”按钮，菜单为“导入账号”“导出账号”，可访问名称与标签一致，延续 Settings 样式。文件和批次行为遵循[共同账号文件契约](../common/music/account-transfer.md)，原生实现见[账号文件传输](music-native-accounts.md#账号文件传输)。

文件选择、保存和一次性跳过／覆盖／取消选择由原生对话框承载。界面只持有不透明文件／owner 计划，逐平台结果完成后通过原有 `AccountStatus` 通知出口一次汇总；不把账号秘密、文件路径或原始异常加入页面。无账号时不打开保存对话框，不生成空文件。设置隐藏、卸载或切换至音源时取消并排空当前传输，退休结果不回填旧页面；用户保存的目的文件不由页面删除。
