# Desktop 接线契约

Desktop 只拥有原生 WPF 壳、导航/历史、设置展示、窗口及界面请求协调；不创建账号、存储、Node 或播放器。唯一 App 通过 AppHost 注入当前能力与公共页面。`IDesktopModule` 是既有能力契约名，不代表可启动的领域产品或模式切换。

- 只有一套统一侧栏、内容入口、设置入口和 App 页头。`ShellWindow` 持有窗口标题、系统按钮、导航／搜索请求及其 owner；`DesktopPageHeader` 是可独立复用的贡献呈现组件，拥有标题、插槽、动作的视觉布局、源订阅及操作生命周期。壳将同一返回／搜索控件树交给组件的 `Navigation` 区域，不复制控件或搜索状态。当前页面通过 `IDesktopHeaderSource` 提供标题、有类型操作和内容插槽，普通能力主视图的搜索准入用于登记全局搜索 owner。
- 普通页头与独立窗口 caption 共用 64px 高度，内容区不再叠加额外顶部偏移；侧栏正文使用 8px 顶距。公共组件以实际测量的导航／标题／插槽宽度和剩余空间排列左右区域，保留既有间距与右侧动作位置，不在壳里按业务页面分派布局或用固定搜索宽度偏移定位动作。播放队列和通知按同一高度保持在页头下方。
- 页头贡献绑定组件持有的展示代次和取消边界。切页、设置、关闭或换源时先撤销旧操作准入、订阅与插槽；卸载时释放这些资源，重新加载读取当前贡献并建立新代次。已访问能力的内容树隐藏保留不延长其页头生命周期，壳按展示切换显式退休页头，不等待内容树卸载；通过不透明位置恢复历史同样经过请求的页头代次边界。源事件在 UI dispatcher 上核对源和代次，切走再返回同一源也拒绝旧事件；同源刷新保留同一插槽实例及其编辑／焦点状态，替换的动作项不能再执行。动作触发页面切换后由页面请求自己的生命周期接管，旧页头令牌和迟到完成不能覆盖新标题、操作或状态。
- 设置页的标题显示在返回按钮右侧，其内容插槽紧随标题，不使用右侧页头操作区；所有普通内容区都直接衔接紧凑页头，不再叠加额外顶距。
- `DesktopHeaderContribution.Slot` 继续接受页面自有的任意 WPF 结构；附加的 `SlotPlacement` 属性支持 `Automatic`／`Leading`／`Trailing`，构造参数及解构保持不变。默认值兼容已有消费者：显示标题时插槽紧随标题，否则在右侧动作前。页面可自行组合标签、筛选或多行内容并选择插槽位置，组件不读取页面身份。组件调用方以 `headingFallback` 选择显示标题，普通页面的标题继续只更新窗口及内容无障碍名称，不新增可见标题。设置集成通过 `PageHeaderHost` 访问其标题／插槽，不在窗口保留旧布局名称的兼容别名。
- 搜索框只存在一份。壳保留最近一个在普通主视图声明搜索可用的能力作为搜索 owner；影视等无搜索能力页面及普通公共页继续显示该搜索框，提交后进入 owner 的既有搜索结果，Shell 历史可返回原业务页面。设置及从设置进入的设置型公共页隐藏并禁用搜索。草稿按实际搜索 owner 与其 route/search 键隔离；请求失败、取消、返回及跨 owner 切换恢复对应草稿，不把一个全局字符串发送给当前无搜索页面。
- 能力 View、SettingsView、PlayerView 仍由其 owner 持有，不因导航重建。壳在首次访问时挂载能力主视图，设置视图在首次打开时挂载；已访问的主／设置树切换时仅隐藏，返回直接显示原树，保留控件、选择和滚动。未访问能力不挂载、不初始化业务。隐藏表面的图片监听、动画、分页及业务读取由对应组件／领域 owner 停用，壳拒绝非当前能力的普通导航意图；播放器仍按独立 owner 准入。普通公共页退出即卸载可视树。需要保留转场或分页状态的表面由能力主视图内部持有，不把公共页留作隐藏 chrome。
- 普通页面只有一个固定底部 `PlayerHost`。壳保留最近一个提供非空 `PlayerView` 的能力作为播放器 owner：切到不提供播放器的影视能力或普通公共页时继续挂载同一实例，切到提供新播放器的能力时才替换 owner；owner 后续替换或撤回 `PlayerView` 时同步刷新。设置及从设置进入的设置型公共页只隐藏播放器和关闭详情／队列，不销毁播放状态，离开设置后恢复同一实例。
- 完整播放器页与播放队列由当前播放器 owner 的 `IDesktopGlobalSurfaceSource` 提供，可在影视等其他普通业务页及普通公共页上打开；播放器发起的已声明音乐路由也可从这些页面返回其 owner。设置展示期间拒绝播放器浮层和播放器导航。普通底栏、详情和队列复用同一播放身份、队列、进度事务和播放引擎，不维护第二套播放状态。
- 播放器页整体挂在 `PlayerDetailHost`，覆盖窗口全部布局行。首次入场先以 `Hidden` 挂载完成布局，等待能力的激活准备完成（当前封面、取色、歌词与读取位置，失败保留明确状态）才开始整个表面的滑入；准备取消或旧回执不能启动入场。其详情、底部播放条及窗口 chrome 随同一个表面滑入／收回，图像持有至实际卸载，不在动画完成后补齐。详情页底栏不显示重复的小唱片及其占位，普通页封面入口保留。普通页面侧栏、右侧内容和底栏在下方保持挂载、尺寸及样式，退出恢复原页面，不挪用其底部控件。页面退出退休自身拖动和弹层；播放器页的窗口 chrome 只提供收起、最小化、最大化／还原和关闭，设置通过收起后普通页面的统一入口进入。
- 频道横向分页和播放器详情可在各自视图内部保留滚动、歌词、筛选、焦点和转场状态，不建立第二套普通页面菜单或页头。
- Navigation 在 UI dispatcher 修改，route 在能力内唯一；内部事件绑定实际订阅实例，隐藏/关闭/旧展示代次的意图拒绝，不依赖全局总线。
- 显式导航／搜索成功且未取消后，壳通过必需的 `IDesktopModule.CaptureNavigationLocation()` 捕获 owner 不透明字符串，与原请求的 Value/IsSearch 一起保存；同 query 的本地／在线搜索由 owner 位置区分。后退通过必需的 `RestoreNavigationAsync(location, cancellationToken)` 原样交回位置，不调用显式 `SearchAsync`／`NavigateAsync`。历史只保存能力、原请求和非空位置，不复制控件树；计划允许位置尚未捕获，但提交历史或后退缺失位置必须报错，不兼容回放。壳不解释 owner 字符串，后退仍以原 query/IsSearch 恢复搜索草稿；领域 owner 检验保留状态、账号及数据有效性，已退役的旧关键词不承诺永久驻留。显式搜索／侧栏导航保持原提交语义。恢复与其他请求共享串行、取消、超时、重试和迟到回执所有权。
- 请求按真实能力串行，30 秒是有界观察而非终止底层任务的证明；取消、超时、替换不能让旧回调覆盖新展示。失败保留重试和必要原生通知，不把异常内容/凭据塞进页面。
- Shell 发起的初始化、导航和搜索若抛出错误，由 Shell 唯一上报；能力通过 `IDesktopModule.OperationErrorText` 只提供固定、脱敏业务错误文本，不同时发布自身通知。能力控件自行处理并结算的操作仍由其原生通知出口拥有；新的 Shell 请求撤销上一模块操作状态及迟到通知准入。存储格式错误明确失败并保留原始数据。
- 当前内容以推荐路线 `catalog-home` 开始；初始化恢复 App 必需的侧栏曲库、设置和当前队列。“我的”分组右侧的创建动作打开能力主视图内的歌单浮层，不创建第二个窗口；收藏和自建歌单详情不显示平台账号或录音身份选择。自建歌单的重命名／删除仍由实际详情页向唯一 Shell 页头提供有类型操作，收藏详情不提供页头操作；歌曲添加目标通过歌曲上下文菜单选择。
- 公共页的受控导航核对实际注册实例、可见状态、route 和操作代次；当前 App 不装配下载管理页面、导航或后台任务。
- 窗口只观察 AppHost 的真实两阶段关闭结果。超时/失败保留窗口与确认；强制清理不冒称保存成功，取消准备只有实际成功后才恢复业务。首次 `ShutdownCompletion` 不能用来无条件退出。
- `PrepareForRender()` 只挂载视图并支持 STA 离屏检查，不 Show、不初始化业务。

资源为 `/MeowFilm.Desktop;component/Theme.xaml`。样式覆盖焦点、键盘、悬停、按下、取消、禁用、卸载、高对比、减少动画与缩放。能力可覆盖明确语义色，不复制未知资源或按领域名分支。通知经 NoticeOutlet/NoticeStack，不添加解释性文字。

页面底色只有一层：普通页面由窗口背景提供，侧栏、内容区和底部 `PlayerFrame` 不铺底色；播放器页由其根视图提供当前封面派生背景（高对比时为系统窗口色），详情与自有底部播放控件透明。播放控件只通过 `Capability.Player.*`（前景、正文、次要正文、悬停、按下、进度轨道）适配所在底色，播放器页仅为自身底部控件替换这一组；弹层是独立浮层，保留自己的表面色。

`MeowFilm.OverlayScrollViewer` 复用 `OverlayScrollChrome.Enabled/Active`，不承载业务分派。普通模式只有滚轮、滚动键、纵向平移或所属纵向滚动条操作实际改变位移时才激活；模板内 viewer 的输入准入由其 `TemplatedParent` 接收。页面悬停、普通焦点、程序恢复位移、内容／视口变化和嵌套滚动不激活。空闲 900ms 后在 160ms 内淡出，重新滚动撤销旧淡出；所属 thumb 捕获鼠标期间保留可见与拖动，释放后重新计时。高对比始终显示系统文字色 thumb，减少动画时直接隐藏；卸载或停用撤销输入准入、计时、动画及所属 thumb 捕获，重新加载只恢复订阅、不恢复旧活动。

壳与正文直接动态引用 `SystemFonts.MessageFontFamilyKey`，跟随 Windows 当前界面字体，不写死字体名称或打包字体文件；图标保留专用符号字体。壳普通文字使用 Display 文本排版、Auto 抗锯齿和布局／设备像素对齐，保留 PerMonitorV2。公共页头继承这组文字属性；不强制 ClearType 穿透透明表面，也不通过透明文字或整体缩放模拟字体样式。Shell 不设置局部强制灰度例外：队列／通知阴影等合成表面由 WPF 的 Auto 选择适用渲染方式，业务遮罩区的局部例外由其呈现 owner 负责。侧栏只让导航项接收键盘焦点，项级焦点轮廓保留；搜索输入与真实搜索按钮共享圆角字段，公共 `TextBox` 模板只消费控件自身一次 `Padding`，搜索框用左侧内边距为按钮保留空间，不在 `PART_ContentHost` 再叠加相同间距。`Ctrl+F`、Enter 与按钮提交仍走同一壳入口。普通色彩使用平面背景和轻量分隔，高对比模式恢复系统前景、背景及侧栏边线，窗口外轮廓仍只由 DWM／WindowChrome 持有。

首页操作验证优先在独立 STA 中对真实控件使用 `IValueProvider`／`IInvokeProvider` 和路由事件。需要 Loaded／可视源时使用不带 `WS_VISIBLE`、带 `WS_EX_NOACTIVATE` 的测试 `HwndSource`；不显示或激活产品窗口，不使用 `SendInput`、系统键盘／鼠标注入或鼠标捕获。样式示意的合成内容不能作为可交互产品窗口交付；真实上游、桌面交互和离屏组件验证分别记录。
