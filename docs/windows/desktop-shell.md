# Desktop 接线契约

Desktop 只拥有原生 WPF 壳、导航/历史、设置展示、窗口及界面请求协调；不创建账号、存储、Node 或播放器。唯一 App 通过 AppHost 注入当前能力与公共页面。`IDesktopModule` 是既有能力契约名，不代表可启动的领域产品或模式切换。

- 只有一套统一侧栏、内容入口、设置入口和 App 页头。页头视觉树、返回、搜索、标题、操作样式、焦点及无障碍层级只由 `ShellWindow` 持有；当前页面通过 `IDesktopHeaderSource` 提供标题、搜索准入、有类型操作和内容插槽。
- 页头贡献绑定当前展示代次和取消边界。切页、设置、关闭或被替换时先撤销旧操作准入与插槽；动作触发页面切换后由页面请求自己的生命周期接管，旧页头令牌和迟到事件不能覆盖新标题、操作或状态。
- 搜索框只存在一份。草稿按实际能力 owner 与 route/search 键隔离；请求失败、取消、返回及跨 owner 切换恢复对应草稿，不把一个全局字符串发送给新页面。
- 能力 View、SettingsView、PlayerView 仍由其 owner 持有，不因导航重建。壳只挂当前能力的一棵主／设置可视树；切换能力时卸载旧树，返回时重新挂回原实例。普通公共页退出即卸载可视树。需要保留转场或分页状态的表面由能力主视图内部持有，不把公共页留作隐藏 chrome。
- 普通页面只有一个固定底部 `PlayerHost`，只挂当前能力的 `PlayerView` 实例；当前能力不提供播放器时宿主为空，不回退到旧 owner。完整播放器页由 `IDesktopGlobalSurfaceSource` 提供，包含详情和自有底部播放控件；两处控件复用同一实现、同一播放身份、队列、进度事务和播放引擎，不维护第二套播放状态。
- 播放器页整体挂在 `PlayerDetailHost`，覆盖窗口全部布局行，其详情、底部播放条及窗口 chrome 随同一个表面滑入／收回。普通页面侧栏、右侧内容和底栏在下方保持挂载、尺寸及样式，退出恢复原页面，不挪用其底部控件。页面退出退休自身拖动和弹层，从播放器进入设置先收回播放器页。
- 频道横向分页和播放器详情可在各自视图内部保留滚动、歌词、筛选、焦点和转场状态，不建立第二套普通页面菜单或页头。
- Navigation 在 UI dispatcher 修改，route 在能力内唯一；内部事件绑定实际订阅实例，隐藏/关闭/旧展示代次的意图拒绝，不依赖全局总线。
- 请求按真实能力串行，30 秒是有界观察而非终止底层任务的证明；取消、超时、替换不能让旧回调覆盖新展示。失败保留重试和必要原生通知，不把异常内容/凭据塞进页面。
- Shell 发起的初始化、导航和搜索若抛出错误，由 Shell 唯一上报；能力通过 `IDesktopModule.OperationErrorText` 只提供固定、脱敏业务错误文本，不同时发布自身通知。能力控件自行处理并结算的操作仍由其原生通知出口拥有；新的 Shell 请求撤销上一模块操作状态及迟到通知准入。存储格式错误明确失败并保留原始数据。
- 当前内容以推荐路线 `catalog-home` 开始；初始化恢复 App 必需的侧栏曲库、设置和当前队列。收藏及具体歌单的新建／重命名／删除是实际页面向唯一 Shell 页头提供的有类型操作；歌曲添加目标通过歌曲上下文菜单选择。
- 公共页的受控导航核对实际注册实例、可见状态、route 和操作代次；当前 App 不装配下载管理页面、导航或后台任务。
- 窗口只观察 AppHost 的真实两阶段关闭结果。超时/失败保留窗口与确认；强制清理不冒称保存成功，取消准备只有实际成功后才恢复业务。首次 `ShutdownCompletion` 不能用来无条件退出。
- `PrepareForRender()` 只挂载视图并支持 STA 离屏检查，不 Show、不初始化业务。

资源为 `/MeowFilm.Desktop;component/Theme.xaml`。样式覆盖焦点、键盘、悬停、按下、取消、禁用、卸载、高对比、减少动画与缩放。能力可覆盖明确语义色，不复制未知资源或按领域名分支。通知经 NoticeOutlet/NoticeStack，不添加解释性文字。

`MeowFilm.OverlayScrollViewer` 复用 `OverlayScrollChrome.Enabled/Active`，不承载业务分派。普通模式只有滚轮、滚动键、纵向平移或所属纵向滚动条操作实际改变位移时才激活；模板内 viewer 的输入准入由其 `TemplatedParent` 接收。页面悬停、普通焦点、程序恢复位移、内容／视口变化和嵌套滚动不激活。空闲 900ms 后在 160ms 内淡出，重新滚动撤销旧淡出；所属 thumb 捕获鼠标期间保留可见与拖动，释放后重新计时。高对比始终显示系统文字色 thumb，减少动画时直接隐藏；卸载或停用撤销输入准入、计时、动画及所属 thumb 捕获，重新加载只恢复订阅、不恢复旧活动。
