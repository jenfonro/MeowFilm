# Desktop 接线契约

Desktop 只拥有原生 WPF 壳、导航/历史、设置展示、窗口及界面请求协调；不创建账号、存储、Node 或播放器。唯一 App 通过 AppHost 注入当前能力与公共页面。`IDesktopModule` 是既有能力契约名，不代表可启动的领域产品或模式切换。

- 只有一套统一侧栏、内容入口、设置入口和 App 页头。`ShellWindow` 持有窗口标题、系统按钮、导航／搜索请求及其 owner；`DesktopPageHeader` 是可独立复用的贡献呈现组件，拥有标题、插槽、动作的视觉布局、源订阅及操作生命周期。壳将同一返回／搜索控件树交给组件的 `Navigation` 区域，不复制控件或搜索状态。当前页面通过 `IDesktopHeaderSource` 提供标题、有类型操作和内容插槽，普通能力主视图的搜索准入用于登记全局搜索 owner。
- 普通页头与独立窗口 caption 共用 64px 高度，内容区不再叠加额外顶部偏移；侧栏正文使用 8px 顶距。公共组件以实际测量的导航／标题／插槽宽度和剩余空间排列左右区域，保留既有间距与右侧动作位置，不在壳里按业务页面分派布局或用固定搜索宽度偏移定位动作。播放队列和通知按同一高度保持在页头下方。
- 页头贡献绑定组件持有的展示代次和取消边界。切页、设置、关闭或换源时先撤销旧操作准入、订阅与插槽；卸载时释放这些资源，重新加载读取当前贡献并建立新代次。已访问能力的内容树隐藏保留不延长其页头生命周期，壳按展示切换显式退休页头，不等待内容树卸载；通过不透明位置恢复历史同样经过请求的页头代次边界。源事件在 UI dispatcher 上核对源和代次，切走再返回同一源也拒绝旧事件；同源刷新保留同一插槽实例及其编辑／焦点状态，替换的动作项不能再执行。动作触发页面切换后由页面请求自己的生命周期接管，旧页头令牌和迟到完成不能覆盖新标题、操作或状态。
- 设置页的标题显示在返回按钮右侧，其内容插槽紧随标题，不使用右侧页头操作区；所有普通内容区都直接衔接紧凑页头，不再叠加额外顶距。
- `DesktopHeaderContribution.Slot` 继续接受页面自有的任意 WPF 结构；附加的 `SlotPlacement` 属性支持 `Automatic`／`Leading`／`Trailing`，构造参数及解构保持不变。默认值兼容已有消费者：显示标题时插槽紧随标题，否则在右侧动作前。页面可自行组合标签、筛选或多行内容并选择插槽位置，组件不读取页面身份。组件调用方以 `headingFallback` 选择显示标题，普通页面的标题继续只更新窗口及内容无障碍名称，不新增可见标题。设置集成通过 `PageHeaderHost` 访问其标题／插槽，不在窗口保留旧布局名称的兼容别名。
- 搜索框只存在一份。App 装配 `IDesktopSearchPage` 时，壳通过其 `Targets`／`SubmitAsync` 将不透明目标与关键词送到同一公共结果页；页头 `SearchTargetId`／`SearchContextId` 只提供上下文默认值，不含业务分派。仅页面／结果分类变化自动联动目标，普通刷新不覆盖手选；手选不提交、不改输入。未装配公共搜索页的消费者保留原搜索 owner 入口。设置及从设置进入的设置型公共页隐藏并禁用搜索。模块草稿按 owner 与 route/search 隔离；公共搜索页单独保留未提交草稿与 `Query`，播放返回不会把它写入原模块草稿。
- `IDesktopSearchPage.ContentOwner` 允许应用将 owner 原有视图投影进公共页，进入时从原主宿主解除，`Deactivate` 时归还；没有第二份控件树。该 owner 在公共页内仍可发出其普通内容导航，离开后的返回恢复公共页。壳保存最初模块的不透明位置与历史深度，退出搜索时恢复原页，而非其被投影的内部搜索位置。具体四分类与影视／音乐编排属于 Capabilities 的[统一结果页](film-search.md)，Desktop 不依赖业务类型。
- 能力 View、SettingsView、PlayerView 仍由其 owner 持有，不因导航重建。壳在首次访问时挂载能力主视图，设置视图在首次打开时挂载；已访问的主／设置树切换时仅隐藏，返回直接显示原树，保留控件、选择和滚动。未访问能力不挂载、不初始化业务。隐藏表面的图片监听、动画、分页及业务读取由对应组件／领域 owner 停用，壳拒绝非当前能力的普通导航意图；播放器仍按独立 owner 准入。普通公共页退出即卸载可视树。需要保留转场或分页状态的表面由能力主视图内部持有，不把公共页留作隐藏 chrome。
- 普通页面只有一个固定底部 `PlayerHost`。壳保留最近一个提供非空 `PlayerView` 的能力作为播放器 owner：切到不提供播放器的影视能力或普通公共页时继续挂载同一实例，切到提供新播放器的能力时才替换 owner；owner 后续替换或撤回 `PlayerView` 时同步刷新。设置及从设置进入的设置型公共页只隐藏播放器和关闭详情／队列，不销毁播放状态，离开设置后恢复同一实例。
- 完整播放器页与播放队列由当前播放器 owner 的 `IDesktopGlobalSurfaceSource` 提供，可在影视等其他普通业务页及普通公共页上打开；播放器发起的已声明音乐路由也可从这些页面返回其 owner。设置展示期间拒绝播放器浮层和播放器导航。普通底栏、详情和队列复用同一播放身份、队列、进度事务和播放引擎，不维护第二套播放状态。
- 播放器页整体挂在 `PlayerDetailHost`，覆盖窗口全部布局行。首次入场先以 `Hidden` 挂载完成布局，等待能力的激活准备完成（当前封面、取色、歌词与读取位置，失败保留明确状态）才开始整个表面的滑入；准备取消或旧回执不能启动入场。其详情、底部播放条及窗口 chrome 随同一个表面滑入／收回，图像持有至实际卸载，不在动画完成后补齐。详情页底栏不显示重复的小唱片及其占位，普通页封面入口保留。普通页面侧栏、右侧内容和底栏在下方保持挂载、尺寸及样式，退出恢复原页面，不挪用其底部控件。页面退出退休自身拖动和弹层；播放器页的窗口 chrome 只提供收起、最小化、最大化／还原和关闭，设置通过收起后普通页面的统一入口进入。
- 频道横向分页和播放器详情可在各自视图内部保留滚动、歌词、筛选、焦点和转场状态，不建立第二套普通页面菜单或页头。
- Navigation 在 UI dispatcher 修改，route 在能力内唯一；内部事件绑定实际订阅实例，隐藏/关闭/旧展示代次的意图拒绝，不依赖全局总线。
- 显式导航／搜索成功且未取消后，壳通过必需的 `IDesktopModule.CaptureNavigationLocation()` 捕获 owner 不透明字符串，与原请求的 Value/IsSearch 一起保存；同 query 的本地／在线搜索由 owner 位置区分。后退通过必需的 `RestoreNavigationAsync(location, cancellationToken)` 原样交回位置，不调用显式 `SearchAsync`／`NavigateAsync`。历史只保存能力、原请求和非空位置，不复制控件树；计划允许位置尚未捕获，但提交历史或后退缺失位置必须报错，不兼容回放。壳不解释 owner 字符串，后退仍以原 query/IsSearch 恢复搜索草稿；领域 owner 检验保留状态、账号及数据有效性，已退役的旧关键词不承诺永久驻留。显式搜索／侧栏导航保持原提交语义。恢复与其他请求共享串行、取消、超时、重试和迟到回执所有权。
- 可选 `IDesktopNavigationRetention` 接收 UI dispatcher 上的不透明位置集合：实际 history、当前模块／设置返回位置、当前公共页／返回公共页的 origin，以及在途或可重试的后退目标。隐藏模块的陈旧 `Current` 和不可达公共页的旧 origin 不算导航入口。owner 另外保留自己当前选择的资源，并自行释放既非当前选择也无导航入口的状态；壳不解析位置、不决定领域缓存、也不改变原 history 深度或恢复语义。
- 请求按真实能力串行，30 秒是有界观察而非终止底层任务的证明；取消、超时、替换不能让旧回调覆盖新展示。失败保留重试和必要原生通知，不把异常内容/凭据塞进页面。
- Shell 发起的初始化、导航和搜索若抛出错误，由 Shell 唯一上报；能力通过 `IDesktopModule.OperationErrorText` 只提供固定、脱敏业务错误文本，不同时发布自身通知。能力控件自行处理并结算的操作仍由其原生通知出口拥有；新的 Shell 请求撤销上一模块操作状态及迟到通知准入。存储格式错误明确失败并保留原始数据。
- 当前内容以推荐路线 `catalog-home` 开始；初始化恢复 App 必需的侧栏曲库、设置和当前队列。“我的”分组右侧的创建动作打开能力主视图内的歌单浮层，不创建第二个窗口；收藏和自建歌单详情不显示平台账号或录音身份选择。自建歌单的重命名／删除仍由实际详情页向唯一 Shell 页头提供有类型操作，收藏详情不提供页头操作；歌曲添加目标通过歌曲上下文菜单选择。
- 公共页的受控导航核对实际注册实例、可见状态、route 和操作代次；当前 App 不装配下载管理页面、导航或后台任务。
- 窗口只观察 AppHost 的真实两阶段关闭结果。超时/失败保留窗口与确认；强制清理不冒称保存成功，取消准备只有实际成功后才恢复业务。首次 `ShutdownCompletion` 不能用来无条件退出。
- `PrepareForRender()` 只挂载视图并支持 STA 离屏检查，不 Show、不初始化业务。

资源为 `/MeowFilm.Desktop;component/Theme.xaml`。样式覆盖焦点、键盘、悬停、按下、取消、禁用、卸载、高对比、减少动画与缩放。能力可覆盖明确语义色，不复制未知资源或按领域名分支。通知经 NoticeOutlet/NoticeStack，不添加解释性文字。

应用菜单使用 `MeowFilm.ContextMenu`／`MeowFilm.MenuItem`：根菜单与子菜单共用圆角、阴影留白及 `MeowFilm.FloatingSurface`；动态子项的局部样式须 `BasedOn` 公共项。模板保留富内容 Header、访问键、图标、快捷键文字、普通可勾选项和 WPF 子菜单键盘逻辑。音质仅以公共项派生当前背景与字重，不另建模板或画勾。Shell 对自身及 Owner 链归属该 Shell 的窗口中的 WPF 自动编辑菜单及其内部派生项目只应用外观，不新建、删减或替换剪贴板、拼写／IME 项及 CommandTarget；原生默认菜单没有提供的操作也不自行增加；不接管无 Shell owner 的独立窗口。

底栏空白使用 `PlayerSurfaceInput` 配对同一轮左键 Down/Up，按下时记录活跃窗口及浮层／队列状态；按钮、滑条等不通过此准入。所属窗口和已打开浮层的 HWND hook 观察 `WM_MOUSEACTIVATE` 的左键触发消息与原生按下，鼠标激活窗口的那一轮只激活；右键／中键激活不占用后续左键。关闭层不使本轮重新准入，不使用延时冷却。队列事实由 Shell 以继承附加属性提供；已活跃窗口中按下底栏空白关闭队列并消费该轮。隐藏取消资格，卸载注销 InputManager 和 HWND hook。合成消息与离屏路由测试只证明适配和状态契约，不证明真实桌面捕获／激活消息实序。

队列外壳四角圆角且保留阴影溢出空间，内层 `QueueHost` 单独按圆角几何裁剪内容；矩形 `ClipToBounds` 不承担圆角裁剪。行高、虚拟化、播放和删除动作保留，整行悬停／键盘焦点显示浅色底与封面播放图标，高对比使用系统窗口／高亮色，当前歌曲另以字重识别。

全应用不提供普通文字悬停提示，包括按钮说明、歌名／片名全称、截断简介、音源信息和禁用内容说明；仅保留进度条的时间预览。控件的无障碍名称、菜单、内容预览和真实操作错误通知不受影响。

普通页面由窗口提供应用渐变背景，侧栏叠加白色40%层与右分隔线，内容区和底部 `PlayerFrame` 保持透明；播放器页由其根视图提供当前封面派生背景（高对比时为系统窗口色），详情与自有底部播放控件透明。播放控件只通过 `Capability.Player.*`（前景、正文、次要正文、悬停、按下、进度轨道）适配所在底色，播放器页仅为自身底部控件替换这一组；弹层是独立浮层，保留自己的表面色。

`MeowFilm.OverlayScrollViewer` 复用 `OverlayScrollChrome.Enabled/Active`，不承载业务分派。普通模式只有滚轮、滚动键、纵向平移或所属纵向滚动条操作实际改变位移时才激活；模板内 viewer 的输入准入由其 `TemplatedParent` 接收。页面悬停、普通焦点、程序恢复位移、内容／视口变化和嵌套滚动不激活。空闲 900ms 后在 160ms 内淡出，重新滚动撤销旧淡出；所属 thumb 捕获鼠标期间保留可见与拖动，释放后重新计时。高对比始终显示系统文字色 thumb，减少动画时直接隐藏；卸载或停用撤销输入准入、计时、动画及所属 thumb 捕获，重新加载只恢复订阅、不恢复旧活动。

壳与正文直接动态引用 `SystemFonts.MessageFontFamilyKey`，跟随 Windows 当前界面字体，不写死字体名称或打包字体文件；图标保留专用符号字体。壳普通文字使用 Display 文本排版、Auto 抗锯齿和布局／设备像素对齐，保留 PerMonitorV2。公共页头继承这组文字属性；不强制 ClearType 穿透透明表面，也不通过透明文字或整体缩放模拟字体样式。Shell 不设置局部强制灰度例外：队列／通知阴影等合成表面由 WPF 的 Auto 选择适用渲染方式，业务遮罩区的局部例外由其呈现 owner 负责。侧栏只让导航项接收键盘焦点，项级焦点轮廓保留；搜索输入与真实搜索按钮共享圆角字段，公共 `TextBox` 模板只消费控件自身一次 `Padding`，搜索框用左侧内边距为按钮保留空间，不在 `PART_ContentHost` 再叠加相同间距。`Ctrl+F`、Enter 与按钮提交仍走同一壳入口。普通色彩使用应用渐变背景和轻量分隔，高对比模式恢复系统前景、背景及侧栏边线，窗口外轮廓仍只由 DWM／WindowChrome 持有。

首页操作验证优先在独立 STA 中对真实控件使用 `IValueProvider`／`IInvokeProvider` 和路由事件。需要 Loaded／可视源时使用不带 `WS_VISIBLE`、带 `WS_EX_NOACTIVATE` 的测试 `HwndSource`；不显示或激活产品窗口，不使用 `SendInput`、系统键盘／鼠标注入或鼠标捕获。样式示意的合成内容不能作为可交互产品窗口交付；真实上游、桌面交互和离屏组件验证分别记录。

## 通用外观与主题

- AppHost 注入 `IDesktopAppearance`，壳在模块设置类别之前提供“通用”。通用页不伪装成业务模块；业务通过 `IDesktopGeneralSettingsSource` 分别贡献外观、首页数据源、缓存控制内容，壳仅负责区域切换，设置返回仍恢复最初页面且不重放导航。
- `AppAppearance` 独占原生文档 `app.appearance.v1`，严格字段为 `{schema:1, themeColor:"#RRGGBB"}`。缺失只采用默认、不写盘；损坏或未知版本不覆盖，通知并允许重新读取。保存使用读取指纹 CAS，失败后权威重读、不重放写入；已接受写入在 App 关闭前实际排空，取消关闭可恢复准入。该 namespace 不开放给脚本桥。
- `MeowFilm.Brush.AppBackground` 只属于壳的普通页面背景。默认六段纵向渐变为 `#E6F3FB/#EAF3F7/#F7F7F3/#E9ECEF/#DBE3EA/#D3DDE6`，位置 `0/.18/.38/.60/.80/1`；自定义色按各层固定权重着色，保留浅底与中性过渡，不铺纯色。侧栏使用白色40%层与细边线；普通页主操作为绿色，错误、删除、收藏心形及平台标识可保留语义红。
- 全屏音乐播放器与影片播放页仍拥有独立背景资源，不读取 AppBackground；底栏背景/进度仍跟随歌曲或固定播放器配色，主播放按钮使用绿色。高对比仍优先系统资源。
- `FloatingSurface`、`ItemHover`、`ItemSelected`、`InputSurface` 从同一 `ThemeColor` 派生浅色菜单／弹层、悬停、当前及搜索底色。AppHost 当前仅装配一个 Shell 和一个 appearance owner；同一 UI dispatcher 的重复 Theme 字典与脱离视觉树的 Popup 引用同一组颜色 Brush。Brush 的 Color 绑定到派生值，防止 WPF 模板／资源封存冻结后不能更新；未复制主题设置或遍历控件树。这不是同一 dispatcher 多个独立主题 owner 的契约。高对比由控件样式切到系统色。
- `SettingsScrollChrome.xaml` 仅用于设置页和其中列表，常显且不创建空闲计时器；普通页保留 `OverlayScrollChrome` 的原自动隐藏机制。

## 媒体快捷键设置

- AppHost 先加载 `AppMediaControlSettings`，再通过 `ShellWindow` 构造器末尾的 `mediaControls` 参数注入；壳只读 `MediaControls` 暴露同一 `IDesktopMediaControlSettings`，将其交给通用设置的“快捷键”区域和窗口附件。Desktop 设置不依赖音乐能力，不创建播放器或全局键注册。
- 原生文档独立为 `app.media-controls.v1`，严格字段为 `{schema:1, globalEnabled:true, systemMediaEnabled:true, bindings:[{action:"TogglePlayback",local:{key:"P",modifiers:2},global:{key:"P",modifiers:3}},…]}`。`action`／`key` 使用枚举名称，`modifiers` 使用 WPF `ModifierKeys` 位值；`null` 表示清除。八个动作各有一项，翻译的 `global` 必须为 `null`。不迁移或改写外观、音乐文档，不向脚本开放此命名空间。
- 默认两开关开启，彼此独立。应用内键依次为 `Ctrl+P`、`Ctrl+Left`、`Ctrl+Right`、`Ctrl+Up`、`Ctrl+Down`、`Ctrl+L`、`Ctrl+D`、`Ctrl+T`，对应播放／暂停、上一首、下一首、音量加、音量减、喜欢歌曲、打开／关闭桌面歌词、源译文显隐；前七项的全局键在应用内键上增加 `Alt`，翻译全局列不提供编辑。
- 缺失文档只采用默认值，不写盘。读取失败、损坏或未知版本撤销输入及编辑准入，保留原文档并通过 `NoticeOutlet` 通知，允许显式重新读取。保存按上次读取指纹 CAS；失败后权威重读，已接受写入的丢失回执可以恢复为成功，未接受的草稿不发布、不重放。偏好快照不可变；保存成功后才通知输入及系统媒体消费者。
- 通用页沿用原有 32px 左右边距和设置滚动条。“功能说明／应用内快捷键／全局快捷键”展示八行；按钮可通过键盘及自动化访问，录制期间消费候选键的按下、长按及释放，并在 WPF 输入预处理阶段隔断 Shell 固定导航。纯修饰键不提交；Esc 取消、Tab 离开、Delete／Backspace 清除。候选可即时保存并结束视觉编辑，但同一 `IsRecording` 保持至所消费的候选／控制键全部释放，期间不恢复全局注册；候选保存中保留输入按钮的焦点资格，避免控件禁用导致提前失焦。失焦、隐藏、卸载、窗口停用或显式取消输入会话均可立即释放该状态，保存中同样可清理。内部不同动作跨局部／全局重复、`Ctrl+F`、`Alt+Left`、裸 Esc／Space 均拒绝保存，同一动作共享局部／全局组合允许。冲突就地显示并通过通知反馈，键位始终恢复权威值。
- `IsRecording` 和 `GlobalErrors` 仅为运行时状态，不持久化。设置 UI 不探测、不推测占用；运行时附件以 `SetGlobalErrors` 发布真实注册结果，行内保留“热键被占用”或其他具体错误。重新检测只通过 `RequestRegistrationRefresh` 事件请求附件，设置未恢复、全局关闭或正在录制时不发出请求。
- 设置是 `AppShutdown.sharedParticipants` 的成员，准备关闭先撤销编辑、输入及录制准入，再等待已接受保存实际结算；取消准备可恢复准入，永久 Abort／Dispose 后不再恢复。启动失败同样由生命周期所有者排空设置后才释放存储。

`DialogPlacement.Centered` 为业务表单Popup提供窗口内容区居中、移动/缩放重定位和所属控件退场清理；其PlacementTarget仍用于上下文/焦点，不再决定表单位置。锚点菜单、调色盘不启用此机制。`ColorSelection`、设置下拉框和栏目间距资源由Desktop共用，业务设置页只负责提供选项和提交至各自owner。
