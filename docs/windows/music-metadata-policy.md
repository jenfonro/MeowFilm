# 音乐元数据偏好与本地歌词

## 所有权

- `MusicLibraryOwner` 是 `music.library.v1` 的唯一 writer。
- 元数据平台顺序、启用集合和本地歌词均属于当前曲库文档；设置页、歌词页、平台协议和脚本不能直接写保护存储。
- 普通设置、读取本地歌词和保存本地歌词不调用脚本服务。只有实际查询已启用洛雪音源时才进入脚本执行边界。
- 设置控件即时保存，没有“保存设置”或“重新读取设置”按钮，也没有独立服务端配置副本。

## 当前文档区域

`music.library.v1` 只接受 `MusicLibraryState.CurrentAreas` 和当前脚本存储 key。未知区域、重复 key、非当前 schema、损坏字段或关系错误使整份文档失败，且不会写回原数据。

元数据相关区域为：

```text
native-metadata-policy
native-local-lyrics
```

区域尚未创建时，owner 使用当前内存默认值，表示用户尚未修改该项。区域一旦存在就必须完整通过当前校验，损坏值不能退化为默认。

不兼容文档保持原样并明确失败。

## 元数据平台偏好

`native-metadata-policy` 的唯一当前形态为：

```json
{
  "schema": 1,
  "revision": 0,
  "platforms": ["wy", "tx", "kg", "kw", "mg"],
  "enabled": ["wy", "tx", "kg", "kw", "mg"]
}
```

- `platforms` 必须是五个平台的完整无重复排列。
- `enabled` 必须是无重复子集，可以为空。
- `music.metadata.settings.get` 返回当前权威设置。
- `music.metadata.settings.save` 必须提交准确 `ifRevision`、完整 `platforms` 与 `enabled`；成功后 revision 加一并立即生效。
- revision 冲突、待确认写入或格式错误不会通过额外刷新、延时重试或影子设置掩盖。
- 平台顺序同时约束歌词和封面元数据选择，但不改变音频播放来源优先级。
- 播放器起播复用歌曲当前封面，同曲候选增加保留仍被策略允许的已选 URL；只有缺图或加载失败才继续选择。显式变更平台顺序或启用集合重新按新策略选择，失败保存期间仍按现有权威确认流程处理，见[原生公共图像](artwork.md)。

## 歌词选择

自动歌词读取顺序为：

1. 当前歌曲已明确关联的本地歌词；
2. 按 `platforms` 顺序遍历 `enabled` 中的精确录音；
3. `wy`、`tx`、`kg` 使用原生官方歌词协议；
4. `wy` 原生结果为空，或当前录音属于 `kw`、`mg` 时，按安装顺序依次尝试实际已启用的同平台脚本歌词能力；`tx`、`kg` 不进入脚本路径。

每个平台最多读取当前歌曲已有录音中的两条，不能按标题搜索另一首歌，不能跨平台替换录音或调用未启用脚本。读取安装列表不启动脚本，执行歌词时才按需顺序激活；当前安装无歌词或不支持歌词时才继续下一项。关闭的元数据平台不会从缓存、显示快照或脚本结果重新进入本次查询。

`MusicLyricApplication` 对同一当前请求合并在途操作，并用策略代次、平台代次、歌曲身份和取消令牌围住结果。设置、账号、脚本源集合或歌曲变化会使旧缓存与旧回执失效；关闭等待已准入工作真实结束。

## 本地歌词导入

本地歌词链为：

```text
显式文件选择
→ 原生只读快照
→ 用户确认关联
→ 当前时间轴解析
→ MusicLibraryOwner CAS
→ 当前歌曲显示
```

文件入口只接受 `.lrc`、`.qrc`、`.yrc`、`.txt`：

- 最大 256 KiB、65,536 个 UTF-16 字符；
- 接受严格 UTF-8，可带 BOM；UTF-16 LE/BE 必须带 BOM；
- 拒绝 ANSI 猜测、损坏编码、控制字符、UNC、设备路径、硬链接、重解析点及读取期间变化；
- 不扫描目录、不执行文本、不保存所选路径或文件名。

`music.lyrics.local.save` 只允许保存当前队列正在播放歌曲的准确身份。换曲、离页、关闭或旧读取晚到不能关联到新歌曲。

## 本地歌词区域

`native-local-lyrics` 的唯一当前形态为：

```json
{
  "schema": 2,
  "items": [
    {
      "songKey": "<64 位摘要>",
      "songId": "<当前歌曲 ID>",
      "contentHash": "<64 位摘要>",
      "lines": []
    }
  ]
}
```

- 最多 64 首、区域最多 2 MiB、单项最多 256 KiB。
- `songKey` 唯一并绑定当前歌曲显示身份；`contentHash` 绑定导入文本。
- 保存的是解析后的纯时间轴，不保存凭据、媒体 URL、请求头或文件能力；逐字仅保存真实时间，当前格式不含 timing 标签。不兼容旧 schema，不迁移或删除原文件。
- `music.lyrics.local.get` 只读取精确歌曲；`save` 原子替换该歌曲内容；`remove` 只删除该精确关联。
- 全局歌词关闭时不显示本地或在线歌词，但不会删除本地内容。

## 取消、提交和错误

- 文件选择或确认取消不写入。
- CAS 准入前允许取消；准入后以真实提交结果为准，不能把取消当作回滚。
- `REVISION_CONFLICT`、`PENDING_WRITE`、`COMMIT_UNKNOWN`、`CORRUPT_STORAGE` 和限额错误都必须保留其实际语义。
- 页面只显示必要状态或错误；持久状态由唯一 owner 决定。
