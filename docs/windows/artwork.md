# 原生公共图像

唯一 AppHost 创建一个 `ArtworkService`，通过 WPF `ArtworkScope` 继承属性注入能力视图。`IArtworkLoader.AcquireAsync`、可释放租约和 `ArtworkImage` 不识别业务领域，不使用全局默认服务；未注入不发网。

当前消费者是目录/歌单卡片、歌曲封面及播放器背景。当前歌曲只按已保存元数据平台策略选择精确录音已有的公开封面；不按标题猜另一个版本，不读取未保存草稿，不改变实际播放或歌词来源。

资源边界：单响应4MiB、缩略图最长边512、原图维度16384且总像素32M、共享解码缓存最多64项／32MiB。
不设置全局、同主机或 pending 请求数量额度。同 URL 共享在途 flight，消费者独立取消，最后消费者离开才取消物理读取；关闭等待全部真实读取结束。
缓存仅管理可复用图像，容量不足时淘汰；页面租约独立持有图像，不因旧图仍显示而拒绝新图。服务按 URL 索引有效租约持有的条目，即使从 LRU 淘汰，再次取得也返回同一解码图像，不重复 HTTP/解码。最后一个租约释放即移除该索引；索引不延长无人持有条目的生命，也不改变 LRU 容量。已完成但仍有等待者的 flight 保留到最后等待者退出，避免缓存淘汰与租约交付之间的重复读取。关闭清空服务索引，外部尚未释放的租约仍可读取自身图像并安全释放。
请求原生直连，禁止默认Cookie／代理，
逐跳校验地址及HTTPS降级，连接固定到已校验的公共DNS地址。无可执行SVG或外部文件解析。
缓存容量不是实测App内存保证，WIC／Skia 原生内部开销及View引用另外记录。

普通缩略图进入可见范围才取得租约；即将呈现的完整表面可用 `ArtworkImage.PrepareForPresentationAsync` 显式取得准备租约，先完成图像加载与取色，再开始入场。该租约由表面 owner 持有至实际卸载，动画移出窗口不清图；取消准备立即释放，换 URL/scope 取消旧请求并只接纳最新回执，不为任意隐藏页面预取。
加载失败保留简短错误状态；网络、超时等临时失败可显式重试，格式不支持、坏图、资源超限或地址被拒绝不显示无效重试按钮。错误通过封面提示和无障碍状态提供，不挤占缩略图；不加入功能说明或占位解释。生产只读公开图片，
账号／受保护封面需要将来明确注入的专属适配，不偷偷继承系统或平台登录态。

同一已解码缩略图提供整图原色、受限播放器色和顶部可见区域色；顶部样本保留平均透明度并通过 `HasTopPalette` 区分有效像素。业务视图可在明确的顶部文字保护区域使用上游装饰图并向下淡出，不让不透明装饰覆盖整张主图；装饰未加载、失败或顶部全透明时回退主图取色。这是两个显式图片地址，各自只读取一次，不触发内容详情。主图保留重试，纯装饰层可以关闭重复重试控件。已解码的本地资源图可通过公开的 `ArtworkImage.SamplePalette` 使用同一取色算法，不另行读取或解码。

当前格式为 PNG/JPEG/GIF/WebP 静态缩略图；损坏、超限、其他格式明确失败。PNG/JPEG/GIF 继续使用 WIC。WebP 由锁定的 SkiaSharp 及 Windows 原生库解码，随应用发布，不依赖用户安装 WIC 扩展；识别实际字节，支持有损、无损、透明与扩展容器，动画只读取合成后的首帧。先校验完整 RIFF 长度和原图尺寸，再直接解码到最长边 512 的缩略图，不为缩略图分配原图大小的输出像素。两条路径均从已读取字节创建冻结、独立的 BGRA 图像并释放解码资源，不把远端 URI 交给解码器隐式联网。保存元数据可离线读取，但图像缓存是内存缓存，不声称重开后完整离线。

网易云 `p1`～`p4.music.126.net`／`music.163.net` 的无查询数字 ID 静态图片在 HTTP 传输边界使用 `param=512y512` 请求缩略图；元数据和共享缓存仍使用原图片身份。保留原图的 PNG/JPEG/GIF 格式与透明度，避免先下载数 MB 原图再在本地缩小。其他域名、`obj/` 装饰资源及带未知/签名参数的地址不改写，不扩大现有字节/像素上限，也不在失败后自动回退原图。

普通控件所在页面暂时隐藏时保留已成功图像及取色；恢复继续使用原引用。普通缩略图移出可视区域则释放控件租约和取色，重新进入时优先从仍有效的缓存或其他活动租约复用同一解码图像；容量淘汰或无活动租约后的缓存未命中仍允许重新读取。没有需求的未完成读取取消，不接纳迟到结果。隐藏解除全局 `LayoutUpdated` 订阅，重新可见时恢复视口观察；不可见时不新取图，显式表面准备租约仍可按原契约加载。长列表真实回收触发 `Unloaded`，释放图像和取色、取消读取并解除订阅；换 URL/scope 同样释放旧资源。显式准备租约释放且图像不在视口时立即退役，不因普通页面保留而延长表面准备资源生命。
旧 URL/scope 的迟到租约释放而不显示，错误同样只属于当前请求；失败也是已完成的呈现状态，不等待动画结束才补齐。普通布局或切换 `ShowRetry` 不重发请求；可重试失败由用户显式操作重新访问，换地址／scope 或视图回收后再进入则按正常生命周期加载。账号/受保护图片不偷偷继承系统或平台登录态。
