# 原生公共图像

唯一 AppHost 创建默认 `ArtworkService`，通过 `ArtworkScope.SetLoader` 显式注入 WinUI 能力视图；音乐能力在自身作用域注入使用 `IArtworkByteCache` 的服务。WinUI 没有 WPF 的属性继承语义，`ArtworkScope` 沿当前 visual parent 查找最近的本地 owner；显式本地 `null` 阻断外层注入。owner 更新只通知其负责的后代，不越过其他显式作用域。`ArtworkService.AcquireAsync`、可释放租约和 `ArtworkImage` 不识别业务领域，不使用全局默认服务；未注入不发网。

`ArtworkImage` 是普通 WinUI `Grid`，内部图片、重试按钮、剪裁与页面处于同一可视树。`Source` 为 WinUI `BitmapSource`，各取色属性为 WinUI `Brush`；`Address`、`DisplayIdentity`、`Stretch`、`ShowRetry`、`AspectRatio`、`HasTopPalette`、准备租约及完成事件保持原有职责。`IArtworkLease.Image` 返回不可变的 `ArtworkPixels`：后台 Skia 解码／缩放使用 `SKMipmapMode.Linear` 预滤波直接落入原生非托管内存（`NativeMemory` + `SKPixmap`，零托管 LOH `byte[]` 分配，不创建中间 `SKBitmap` 或重复复制 `SKData`），对大于 80px 的图片一并产出小尺寸预滤波 mip 缓冲，并一次计算取色结果。首次呈现由该条目的 `GetSource(DispatcherQueue, renderedMaxPixels)` 在应用 UI 线程经 `IBufferByteAccess` 无锁直拷至共享 `WriteableBitmap`（含小尺寸预滤波 mip 图源，供底栏小黑胶等 `<= 96px` 槽位直接选用以消除 D3D11 单级纹理 >10× 下采样摩尔纹）并立即释放原生暂存缓冲；后续租约复用同一实例，不在每个控件重复解码，也没有第二个 UI 图片缓存 owner。借用的 `Source` 不得由消费者改写；XAML 图源不跨 UI 线程共享。

当前消费者是目录/歌单卡片、歌曲封面及播放器背景，以及影视海报和卡片。当前歌曲只按已保存元数据平台策略选择精确录音已有的公开封面；不按标题猜另一个版本，不读取未保存草稿，不改变实际播放或歌词来源。

音乐播放器由 `MusicCapability` 按队列 occurrence 与歌曲身份持有一份封面选择，迷你与全屏共用。起播优先复用歌曲已有且属于启用平台候选的封面；同曲候选增加、音源与音质变化时，只要当前 URL 仍在允许候选中便保留。已接受的跨平台录音快照可补充缺图；图片确实加载失败时才按保存的平台顺序尝试其他不同 URL，同一次选择不循环重试失败地址。候选耗尽保留错误与显式重试，成功重试后继续保留该图。切歌重建选择，明确修改元数据偏好重新应用策略，禁用平台不能从已接受快照重新进入。Windows SMTC 当前仅发布标题、播放状态与传输操作，不消费封面。

图片传输、完整字节读取及编码输入解码不设4MiB总量拒绝；缩略图最长边512、原图维度16384且总像素32M的解码预算保持。共享解码内存缓存按64MiB像素字节管理并以双向链表维护 O(1) LRU，不设图片条数上限；每像素按4字节实际解码尺寸计费（暂存原生 BGRA 缓冲在转为共享 `WriteableBitmap` 时即刻释放），AppHost默认服务的原生编码图片磁盘缓存按单项4MiB、总量256MiB管理，不设置用户配置。显式注入的 `IArtworkByteCache` 由消费领域管理持久化、有效期及清理epoch，同一服务不再另建默认磁盘缓存；两种编码缓存写入前均检查单项不超过 `MaximumCacheEntryBytes`（4MiB），更大的合法图片可显示并复用解码内存但不写编码缓存。内存清理不撤销已交付租约，旧flight不得重新填充内存或越过领域清理epoch。

共享服务最多同时执行4项实际读取、解码和原资源保存；等待中的不同URL只保留需求，不预读图片字节，请求超时从取得执行槽后开始。默认磁盘写也在该flight中等待真实完成，不在后台积压编码字节；取消和关闭等实际工作结束后才归还槽。这个边界不限制已交付图片租约或页面内容数量，64MiB仍只代表可淘汰的解码缓存，不是进程总内存上限。
不另设同主机或 pending 需求数量额度。同 URL 共享在途 flight，消费者独立取消，最后消费者离开才取消未完成物理工作；成功解码后等待可恢复持久写实际结束，再交付图像。退役 flight 的同键继任等待其实际完成后重新读取，不重叠读写；关闭等待读取、解码和落盘全部真实结束。
缓存仅管理可复用图像，容量不足时淘汰；页面租约独立持有图像，不因旧图仍显示而拒绝新图。服务按 URL 索引有效租约持有的条目，即使从 LRU 淘汰，再次取得也返回同一解码图像，不重复 HTTP/解码。最后一个租约释放即移除该索引；索引不延长无人持有条目的生命，也不改变 LRU 容量。已完成但仍有等待者的 flight 保留到最后等待者退出，避免缓存淘汰与租约交付之间的重复读取。关闭清空服务索引，外部尚未释放的租约仍可读取自身图像并安全释放。

默认服务读取顺序为活动租约／解码内存、编码磁盘、网络；内存命中不重新解码，磁盘命中只正常解码、不联网。内存淘汰和控件释放租约不删除磁盘副本，两层分别按最近使用淘汰。默认磁盘缓存保存上游原始编码字节，不重编码、不生成容器尺寸副本、不用Base64，也不进入 Node；音乐图片文件由同库关系索引管理。文件名是原图片身份的SHA-256，仅图片内容和使用时间落盘，不保存URL、请求头或凭据；原始业务图片引用及既有传输规格策略不变。音乐注入缓存沿用自身逐资源、容量及有效期策略，不复制进该目录。音乐图片持久化在等待串行写锁前限制在途128项、原始字节合计16MiB，只有取得写锁的单项才复制输入，取消、失败和完成均释放准入预算。

AppHost显式将`paths.Caches/artwork-v1`交给Artwork原生owner，不读取、迁移或自动清理旧缓存。`ArtworkDiskCache`直接在磁盘目录内自管容量与LRU：首用扫描并自动清扫上次异常残留的临时/坏文件，在内存维护预算和双向链表LRU，不读取图片或持久索引。读写与删除并发执行（仅首用扫描、`ClearAsync` 与关闭使用排空屏障），且均可取消；写入采用同目录 `.stage` 临时文件完整写入并原子替换，删除失败的条目保留至下次回收。只有完整读取、格式／尺寸校验及解码成功后才接纳；磁盘读取同样重新验证，坏图自动移除并回源。正常磁盘I/O失败按未命中或放弃持久化处理，不影响已成功网络图像交付；显式清空向调用方传播真实失败。关闭停止接纳、取消未完成工作并等待实际排空；现有用户数据清理流程在owner释放后删除Caches根目录，重开时创建新owner。有限容量不保证所有历史图片永不重取。

请求原生直连，禁止默认Cookie／代理，
逐跳只解析实际HTTP(S)地址，不按公网／私网／localhost／`.local`／端口或HTTPS转HTTP阻断访问；DNS与连接由默认`SocketsHttpHandler`处理，不筛选解析结果或限制候选地址数。合法URL userinfo用于该次请求的Basic Authorization，URL不设任意长度准入。无可执行SVG或外部文件解析。
缓存容量不是实测App内存保证，Skia 解码临时内存、原生内部开销、XAML 合成资源及活动 View 引用另外记录。

普通缩略图进入可见范围才取得租约；即将呈现的完整表面可用 `ArtworkImage.PrepareForPresentationAsync` 显式取得准备租约，先完成图像加载与取色，再开始入场。该租约由表面 owner 持有至实际卸载，动画移出窗口不清图；取消准备立即释放，换 URL/scope 取消旧请求并只接纳最新回执，不为任意隐藏页面预取。
加载失败保留简短错误状态；网络、超时等临时失败可显式重试，格式不支持、坏图、资源超限或地址语法错误不显示无效重试按钮。错误通过封面提示和无障碍状态提供，不挤占缩略图；不加入功能说明或占位解释。普通图片按其HTTP(S)地址读取；TMDB 稳定相对引用仍通过 AppHost 显式注入的字节读取口访问当前 runtime，该资源契约不构成公共HTTP的访问名单。账号／受保护封面不偷偷继承系统或平台登录态，真实上游401/403仍返回`ARTWORK_DENIED`。

同一已解码缩略图提供整图原色、受限播放器色和顶部可见区域色；顶部样本保留平均透明度并通过 `HasTopPalette` 区分有效像素。业务视图可在明确的顶部文字保护区域使用上游装饰图并向下淡出，不让不透明装饰覆盖整张主图；装饰未加载、失败或顶部全透明时回退主图取色。这是两个显式图片地址，各自只读取一次，不触发内容详情。主图保留重试，纯装饰层可以关闭重复重试控件。

当前格式为 PNG/JPEG/GIF/WebP 静态缩略图；损坏、超限、其他格式明确失败。全部格式通过已锁定的 SkiaSharp 及 Windows 原生库在后台解码，从实际字节识别格式；WebP 不依赖用户安装 WIC 扩展，支持有损、无损、透明与扩展容器，动画只读取合成后的首帧。先检查原图尺寸及容器完整性，输出最长边不超过512的预乘 BGRA 像素；WebP 直接按目标尺寸解码，JPEG 使用解码器支持的缩放，PNG/GIF 的必要原尺寸解码受32M原图像素边界约束，再缩小到目标尺寸。只有完整成功的像素结果进入同一缓存；解码结束释放 Skia 临时数据和图像，不将远端 URI 交给解码器隐式联网。原始编码字节仍按原策略落盘，不改成转码缓存。有效落盘图片可跨启动复用，有限缓存不代表完整离线。

解码器返回可用像素不单独证明文件尾完整。解码前按 PNG chunk 长度遍历到完整零长 `IEND`，JPEG／GIF 核对格式结束标记，WebP 核对完整 RIFF 长度；解码返回值必须是完整成功，不接纳 partial image。防止准确 HTTP 长度的缺尾图片成为成功缓存，不放宽格式或大小上限；相关运行期核对统一通过 `--debug` 模式进行。

网易云 `p1`～`p4.music.126.net`／`music.163.net` 的无查询数字 ID 静态图片在 HTTP 传输边界使用 `param=512y512` 请求缩略图；元数据和共享缓存仍使用原图片身份。保留原图的 PNG/JPEG/GIF 格式与透明度，避免先下载数 MB 原图再在本地缩小。其他域名、`obj/` 装饰资源及带未知/签名参数的地址不改写，保留现有像素解码预算，也不在失败后自动回退原图。

普通控件所在页面暂时隐藏时保留已成功图像及取色；恢复继续使用原引用。普通缩略图首次进入可视区域才准入读取；已经准入的当前图片在控件仍挂载期间保留请求、像素与取色，滚出再滚回不重新取得租约或绑定图片。未看过的离屏图片不读取。隐藏页面取消未完成的普通读取，成功结果继续保留；真实卸载或资源身份变化释放，不接纳迟到结果。沿实际祖先 `Visibility` 与 `XamlRoot.IsHostVisible` 判断呈现需求；视口由 `DesktopViewport` 消费 WinUI 的 `EffectiveViewportChanged`，仅在资源非空且尚未首次准入时订阅视口事件，一旦首次进入可视区域完成准入即注销 `EffectiveViewportChanged` 与 `SizeChanged` 订阅，使后续滚动不再对已加载控件逐帧派发 WinRT 回调或遍历祖先；不可见时不新取图，显式表面准备租约仍可按原契约加载并在释放时即时核对视口。长列表使用 `ArtworkItemsScope` 按数据项稳定身份与 `ResourceSlot` 持有首次准入的底层租约、进行中读取和像素／取色，通过 `ContainerContentChanging` 直接处理 `ListViewBase` 回收与重绑，不依赖一定触发 `Unloaded`；回收只解除视图借用，返回直接借用原结果。消费者显式提供 item identity 与资源描述符；集合增删改通知只核对受影响成员，移动不退休资源，只有完整重置或更换集合才重新核对成员；已准入 item 的属性通知只比较该项资源，离屏 URL／显示身份变化也立即退休旧资源，不预读新图。删除数据成员或列表真正卸载取消并释放对应资源；继承 loader 变化不会退休其他局部 loader owner。该 scope 只延长已有 lease 的数据项生命周期，不建立第二解码缓存。显式准备租约释放且图像不在视口时立即退役，不因普通页面保留而延长表面准备资源生命。
旧 URL/scope 的迟到租约释放而不显示，错误同样只属于当前请求；失败也是已完成的呈现状态，不等待动画结束才补齐。普通布局或切换 `ShowRetry` 不重发请求；可重试失败由用户显式操作重新访问，换地址／scope 或数据项退休后再进入则按正常生命周期加载；虚拟容器回收后复用同一失败结果，不自动重试。账号/受保护图片不偷偷继承系统或平台登录态。

`ArtworkImage.LoadCompleted` 仅通知当前仍有需求的请求成功或失败，携带对应地址；取消和过期回执不通知。音乐 owner 据此推进候选，公共图片控件不拥有音乐平台回退策略。同步完成的通知即使立即换址，也不覆盖新请求的准备任务。
