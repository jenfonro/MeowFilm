# Windows 影视播放页

`FilmCapability` 的隐藏路由 `film-playback` 在页头显示“播放页”。正式播放实现由 `FilmPlaybackRequest`／`FilmPlaybackPage` 投影真实 Node film 会话，`FilmPlaybackSession` 负责连接、事件、命令及原生媒体 attempt；智能选路、业务数据缓存与新增播放资料不在 WPF 重写，见[影视播放契约](../runtime/film-playback.md)。首页、栏目和搜索交接均传递准确目标／真实上下文，不只用影片 ID 构造示例。搜索交接只按[共同契约](../common/film/search.md)，本端实现见[影视搜索](film-search.md)；导航／搜索已接入正式会话，平台执行证据仍见下方验证边界。

页面初始卡片／元数据来自显式请求，后续详情、季集、来源、线路、文件与状态来自会话快照；缺失简介、导演、演员、推荐或剧集时保持空状态，不补样例或猜测播放 URL。浏览选择与正在播放的目标分别呈现，页面隐藏不等于媒体退出；命令和迟到事件须符合当前会话／attempt 身份。搜索原始选择与上下文的保持、更新及释放以共同契约为准，不在本文件新增另一套搜索更新接口。

关闭询问或取消不退休 App typed 系统媒体会话。仅 Shell 的准确入托盘隐藏保留已有实际 Film 输出、attempt、媒体通道和暂停进度；恢复不重开或双播，准备中没有实际输出则照旧取消并排空。普通影视离页或切换模块仍停止普通 native 输出，只有显式 PiP 可继续保留。托盘退出和其他真正退出均走原 preparation／disposal，等待实际原生输出和准确媒体回执排空，不以隐藏或保留 owner 代替关闭成功。

## 页面与交互

`FilmPlaybackView` 使用 WPF 原生控件与现有主题。上方左侧是 16:9 媒体输出区，海报或剧照不作为真实视频帧证据；右侧标题、年份／地区／季集数、评分／类型、播放和收藏均在信息区居中排列。页面及信息区透明透出 Shell 的共享应用画布，不再铺海报、叠加海报遮罩或派生环境色，也没有独立实色卡片或描边。剧照与推荐海报仍按原图比例 `UniformToFill` 显示在各自卡片内，不拉伸或猜测比例；视频像素区及视频浮窗保留黑底。

播放器控件按服务器版桌面前端布置在视频画面内部：进度条下方分左右胶囊；左侧依次为播放／暂停、上一集、下一集、静音（悬停展开音量）和时间，右侧按实际上下文显示当前网盘、画质、换源、片源错误、画中画、设置及全屏。设置内是六档倍速（0.5／0.75／1／1.25／1.5／2）与默认／16:9／4:3 比例，不再在画面外排列控制按钮。宽度不足依次收起网盘、画质、换源、片源错误、画中画，恢复宽度后还原；设置和全屏始终保留。最小画中画等极窄尺寸下，两胶囊等比例收小以保留间距，不覆盖时间或按钮。菜单打开只读取当前快照，不搜索／请求详情，媒体替换时收起旧菜单；网盘标准名由运行器归一，未识别线路不由客户端猜别名。浏览某站点列表不改变正在播放目标的智能模式。

WPF 内容通过原生 `VideoView.Content` 的前景窗口承载，避免普通 WPF 叠层被 HWND 覆盖。全屏／画中画移动同一原生 surface 和同一套控件，不新开播放实例；返回页面先解除前景窗口的旧宿主，再关闭旧窗口。前景控件显式继承页面滚动视口裁剪，隐藏、滚动和离页不留下悬空控件。Windows 外部播放器与 mpv 进程／IPC 调用链已移除。

鼠标进入／移动显示底栏；播放且非加载／缓冲、无打开菜单或键盘控件焦点时，静止 2200ms 后收起，离开画面立即收起。暂停、准备中或菜单展开时保持可操作。画面单击延迟 220ms 切换播放，双击只切换全屏；空格播放／暂停、左右键跳转 5 秒，控件自身键盘输入不被截走。进度拖动或进度条键盘调整只预览，释放才提交；失焦／捕获丢失取消，旧媒体身份不能跳转新片源。网盘／画质选择、换源和片源错误沿用准确业务命令；片源错误按服务器直接提交当前 attempt 的屏蔽与重匹配，忙碌时不重复提交，不再弹二次确认。倍速／比例失败恢复上次实际设置。

初始加载、搜索、取址与原生准备在画面中央显示当前阶段文字和细条；细条是离散业务阶段，不表示下载百分比。原生缓冲只显示等待环，不将 libVLC 的 cache 百分比当作下载范围。短视频开关位于信息区播放按钮旁，不在播放器底栏或设置内；滑动切集仍作用于视频画面，预取状态由该开关提示。点映开关保留在页外选集工具行。

站点来源、网盘来源、点映、必要的原始目录入口、横向／列表切换和选集左右导航位于同一工具行，季度仍独立展示。站点来源下拉弹层底部的“加载更多”继续搜索尚未完成的来源；打开菜单不请求数据，操作不改变当前来源、网盘或季度，请求中与搜索加载时禁用重复操作。季度投影优先使用运行器给出的可信 `doubanSeasons`，否则使用标准 `seasons`，不把豆瓣原始关联 subject 列表当成季度坐标；本端不匹配或归并分季。

普通页面恢复继续由运行器检查当前资料或目录是否过期／缺失。“重新取址”位于画内设置菜单，只重新获取准确当前／失败文件的地址，不变成换源；没有输出且存在可重试项时，画面中央另提供同一恢复操作，正常视频不被该按钮覆盖。操作失败仍通过原通知组件报告。

简介默认只显示居中的“简介”按钮，正文完全收起、不占空间；点击后展示完整简介并变为“收起简介”，再次点击收回空间。简介、导演与演员左对齐。正文在共享应用画布上滚动；窄窗口的信息区随内容增长，展开或滚动简介均不创建局部背景。

信息区内容超出时，只在被截断的上下边缘渐隐。内容宽度达到 840px 时左右排列并保持等高，信息较长时在信息区内滚动；更窄的窗口上下排列。该宽度指 Shell 侧栏之外的内容区域，默认 1110px 窗口使用左右布局，860px 最小窗口使用上下布局。

播放、选集、换源、画质与目录操作提交真实会话命令，准入和错误以当前状态为准；无有效会话不发播放，不显示虚构进度。心形收藏是可键盘操作的 ToggleButton，空心／实心及“收藏／已收藏”反映同一个 `IsFavorite` 状态；名称随之切换为“收藏 片名／取消收藏 片名”。收藏图标与文字使用正文色，在共享应用画布上保持可读性。收藏通过原生 `FilmLibrary` 的 `film.library.v1` 文档持久提交，失败不伪装成功；它不属于 Node 新增的历史／人工匹配／屏蔽／偏好库。

存在真实剧集时，选集默认横向图文卡片，仅显示来源实际提供的剧照、序号／集名、时长及简介。列表模式一行一集，保留相同信息并显示更长简介。选集卡、列表行和相关推荐静止时没有底色与边框；悬停或键盘焦点时复用首页影视卡片的 `CardMotion`、`FilmHoverShade` 与 `FilmPlayMark`：整块轻微放大（卡片与推荐约 1.03，列表行约 1.01 并淡入柔和底色），图片额外放大，图片底部加深，播放标记位于图片区域中央。悬停反馈不改变当前集，也不触发播放。当前集在剧照左上角显示“▶ 当前”徽标，并提供“当前”无障碍状态。按钮可切换布局，当前集以会话快照为事实来源，切换布局不改变当前集；返回横向时定位到当前集。横向选集及底部相关推荐支持翻页按钮、Shift＋滚轮、PageUp／PageDown 和 Home／End，普通滚轮保留页面纵向滚动。

底部相关推荐仅来自真实元数据，具备准确目标的条目才能提交下一次播放页请求，不打开固定本地推荐样例。布局、简介展开与滚动属于原生页面状态；当前目标、播放位置和 attempt 属于会话／媒体 owner，收藏以原生资料库为准，不由导航缓存授予权限。首页和栏目页仍复用各自原视图和滚动宿主。

页面背景由 Shell 的 `MeowFilm.Brush.AppBackground` 唯一持有，沿用默认浅蓝到近白渐变及全局用户自定义色；影片、海报、空海报及滚动不会改变该画布。影视专属海报取色、颜色缓存、氛围转换和信息区背景图片路径已删除，正文与次要文字对共享浅色画布保持不低于 4.5:1 的对比度。系统字体及共享焦点样式保留；文字使用 Display + Auto，由 WPF 按实际表面选择抗锯齿，不整页强制灰度。高对比模式隐藏播放区装饰图片，选集与推荐改为 2px 系统描边（当前集使用 Highlight），恢复系统文字和背景色。没有伪造播放进度的定时器；悬停动画由 `CardMotion` 驱动，减少动画或高对比时直接切换。普通远程剧照与海报卡继续通过 `ArtworkImage` 的可见性、取消与缓存生命周期；通用图片采样仍由 `ArtworkImage` 提供，不再用于影视页面背景。全屏音乐播放器与小说阅读器的独立画布及用户配色保持不变。鼠标点击后按钮保留键盘焦点，按 `CardMotion` 的“悬停或焦点”规则保持高亮，直至焦点离开。

## 正式数据与历史预览素材

正式播放模型以真实元数据与会话结果为准，不生成“第一季 12 集”、固定演员／时长或推荐关系。历史预览模型与旧入口已移除，正式导航使用准确 metadata、聚合或原始单源请求；不存在用预览内容填补缺失数据的回退。

历史剧照复用用户指定 `ui-design` 中《漫长的季节》的素材，并不表示它们对应所选影片或真实单集；固定本地海报同样不是服务推荐结果，不用于填补正式会话缺失内容。

历史图片位于 `Film/Presentation/Assets/`，作为 WPF `Resource` 编译，可离线显示。19 张 JPEG 合计约 1.17 MiB。同目录 `sources.json` 记录每张图片的原地址、原始与派生尺寸、裁剪关系、大小及哈希。图片版权归原权利人，来源记录用于追溯；没有将其标注为自制或开放许可。自带图片只在固定的 App 资源目录下解析，外部海报仍进入公共图像服务。

## 验证边界

布局／交互断言只说明对应 UI，不证明真实 Node 数据、收藏持久化或媒体输出；首页、栏目与导航用例也不能代替正式媒体验证。业务、typed 媒体及合并后的原生导航／搜索接线已实现；C# 行为回归、App 编译与真实解码分别验证，实际执行范围以交付记录为准。Windows 私有 FFmpeg 解复用 DLL 的独立构建不能据此外推 Media C# 编译、整 App、真实视频帧、ClearKey、seek、撤权／关闭排空通过；内核划界见[原生媒体实现](media-playback.md)。本文件不声明账号收藏、其他平台或全格式兼容已验收。历史 270×405 海报放大会发软；截图验证不覆盖真实鼠标、显示器 DPI 或 Shell 合成。
