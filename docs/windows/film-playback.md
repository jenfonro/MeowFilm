# Windows 影视播放页

`FilmCapability` 的隐藏路由 `film-playback` 在页头显示“播放页”。正式播放实现由 `FilmPlaybackRequest`／`FilmPlaybackPage` 投影真实 Node film 会话，`FilmPlaybackSession` 负责连接、事件、命令及原生媒体 attempt；智能选路、业务数据缓存与新增播放资料不在 WPF 重写，见[影视播放契约](../runtime/film-playback.md)。首页、栏目和搜索交接均传递准确目标／真实上下文，不只用影片 ID 构造示例。搜索交接只按[共同契约](../common/film/search.md)，本端实现见[影视搜索](film-search.md)；导航／搜索已接入正式会话，平台执行证据仍见下方验证边界。

页面初始卡片／元数据来自显式请求，后续详情、季集、来源、线路、文件与状态来自会话快照；缺失简介、导演、演员、推荐或剧集时保持空状态，不补样例或猜测播放 URL。浏览选择与正在播放的目标分别呈现，页面隐藏不等于媒体退出；命令和迟到事件须符合当前会话／attempt 身份。搜索原始选择与上下文的保持、更新及释放以共同契约为准，不在本文件新增另一套搜索更新接口。

关闭询问或取消不退休 App typed 系统媒体会话。仅 Shell 的准确入托盘隐藏保留已有实际 Film 输出、attempt、媒体通道和暂停进度；恢复不重开或双播，准备中没有实际输出则照旧取消并排空。普通影视离页或切换模块仍停止普通 native 输出，只有显式 PiP／运行中的外播可继续保留。托盘退出和其他真正退出均走原 preparation／disposal，等待实际输出、外播进程和准确媒体回执排空，不以隐藏或保留 owner 代替关闭成功。

## 页面与交互

`FilmPlaybackView` 使用 WPF 原生控件与现有主题。上方左侧是 16:9 媒体输出区，海报或剧照不作为真实视频帧证据；右侧海报作为整个信息区的背景：标题、年份／地区／季集数、评分／类型、播放和收藏均居中叠在海报上。海报按原图比例居中覆盖，竖版、横版均不拉伸，不参与前景内容的高度测量；外部海报由 `ArtworkImage` 按解码后的实际比例 `UniformToFill`，不猜测比例。图片上叠加当前 Window 语义色的半透明遮罩，前景文字使用正文色，保持明暗主题下的可读性；信息区没有独立实色卡片或描边。

简介默认只显示居中的“简介”按钮，正文完全收起、不占空间；点击后展示完整简介并变为“收起简介”，再次点击收回空间。简介、导演与演员左对齐。图片覆盖信息区完整可视范围，正文在图片前方滚动；展开或滚动简介不会把图片变回独立顶部图框。窄窗口的信息区随内容增长，背景始终覆盖全部内容。

信息区内容超出时，只在被截断的上下边缘渐隐。内容宽度达到 840px 时左右排列并保持等高，信息较长时在信息区内滚动；更窄的窗口上下排列。该宽度指 Shell 侧栏之外的内容区域，默认 1110px 窗口使用左右布局，860px 最小窗口使用上下布局。

播放、选集、换源、画质与目录操作提交真实会话命令，准入和错误以当前状态为准；无有效会话不发播放，不显示虚构进度。心形收藏是可键盘操作的 ToggleButton，空心／实心及“收藏／已收藏”反映同一个 `IsFavorite` 状态；名称随之切换为“收藏 片名／取消收藏 片名”。收藏图标与文字使用正文色，在叠图背景上保持可读性。收藏通过原生 `FilmLibrary` 的 `film.library.v1` 文档持久提交，失败不伪装成功；它不属于 Node 新增的历史／人工匹配／屏蔽／偏好库。

存在真实剧集时，选集默认横向图文卡片，仅显示来源实际提供的剧照、序号／集名、时长及简介。列表模式一行一集，保留相同信息并显示更长简介。选集卡、列表行和相关推荐静止时没有底色与边框；悬停或键盘焦点时复用首页影视卡片的 `CardMotion`、`FilmHoverShade` 与 `FilmPlayMark`：整块轻微放大（卡片与推荐约 1.03，列表行约 1.01 并淡入柔和底色），图片额外放大，图片底部加深，播放标记位于图片区域中央。悬停反馈不改变当前集，也不触发播放。当前集在剧照左上角显示“▶ 当前”徽标，并提供“当前”无障碍状态。按钮可切换布局，当前集以会话快照为事实来源，切换布局不改变当前集；返回横向时定位到当前集。横向选集及底部相关推荐支持翻页按钮、Shift＋滚轮、PageUp／PageDown 和 Home／End，普通滚轮保留页面纵向滚动。

底部相关推荐仅来自真实元数据，具备准确目标的条目才能提交下一次播放页请求，不打开固定本地推荐样例。布局、简介展开与滚动属于原生页面状态；当前目标、播放位置和 attempt 属于会话／媒体 owner，收藏以原生资料库为准，不由导航缓存授予权限。首页和栏目页仍复用各自原视图和滚动宿主。

页面根底色透明，其后有一层固定在视口的氛围色：取海报平均色的色相与饱和度，明度固定在当前主题窗口色附近（浅色 0.935，深色 0.125），饱和度设上限，保证正文和次要文字对氛围色的对比度不低于 4.5:1。该层在顶部、左侧 48px 和底部渐变回透明，衔接 Shell 页头、侧栏与底部播放条的窗口色。没有海报主色时氛围层透明；外部海报移出视口释放后保留最后的有效颜色，换影片时随新海报更新。表面与文字沿用动态语义色、系统字体及共享焦点样式；文字使用 Display + Auto，由 WPF 按实际表面选择抗锯齿，不整页强制灰度。高对比模式隐藏播放区、信息背景的装饰图片和氛围层，选集与推荐改为 2px 系统描边（当前集使用 Highlight），恢复系统文字和背景色。没有伪造播放进度的定时器；悬停动画由 `CardMotion` 驱动，减少动画或高对比时直接切换。远程海报继续通过 `ArtworkImage` 的可见性、取消与缓存生命周期，取色复用 `ArtworkImage.SamplePalette`。鼠标点击后按钮保留键盘焦点，按 `CardMotion` 的“悬停或焦点”规则保持高亮，直至焦点离开。

## 正式数据与历史预览素材

正式播放模型以真实元数据与会话结果为准，不生成“第一季 12 集”、固定演员／时长或推荐关系。历史预览模型与旧入口已移除，正式导航使用准确 metadata、聚合或原始单源请求；不存在用预览内容填补缺失数据的回退。

历史剧照复用用户指定 `ui-design` 中《漫长的季节》的素材，并不表示它们对应所选影片或真实单集；固定本地海报同样不是服务推荐结果，不用于填补正式会话缺失内容。

历史图片位于 `Film/Presentation/Assets/`，作为 WPF `Resource` 编译，可离线显示。19 张 JPEG 合计约 1.17 MiB。同目录 `sources.json` 记录每张图片的原地址、原始与派生尺寸、裁剪关系、大小及哈希。图片版权归原权利人，来源记录用于追溯；没有将其标注为自制或开放许可。自带图片只在固定的 App 资源目录下解析，外部海报仍进入公共图像服务。

## 验证边界

布局／交互断言只说明对应 UI，不证明真实 Node 数据、收藏持久化或媒体输出；首页、栏目与导航用例也不能代替正式媒体验证。业务、typed 媒体及合并后的原生导航／搜索接线已实现；C# 行为回归、App 编译与真实解码分别验证，实际执行范围以交付记录为准。Windows 私有 FFmpeg 解复用 DLL 的独立构建不能据此外推 Media C# 编译、整 App、真实视频帧、ClearKey、seek、撤权／关闭排空通过；内核划界见[原生媒体实现](media-playback.md)。本文件不声明账号收藏、其他平台或全格式兼容已验收。历史 270×405 海报放大会发软；截图验证不覆盖真实鼠标、显示器 DPI 或 Shell 合成。
