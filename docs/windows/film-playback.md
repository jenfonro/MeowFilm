# Windows 影视播放页

`FilmCapability` 的隐藏路由 `film-playback` 在页头显示“播放页”。影视首页与栏目数据页卡片均通过 `OpenPlaybackAsync` 进入，保留原卡片的影片 ID、片名、海报与评分。播放页目前用于本地 UI 预览，不读取影片详情、不解析片源，不启动媒体引擎、脚本运行时或假播放计时。

## 页面与交互

`FilmPlaybackView` 使用 WPF 原生控件与现有主题。上方左侧是 16:9 剧照预览，右侧海报作为整个信息区的背景：标题、年份／地区／季集数、评分／类型、播放和收藏均居中叠在海报上。海报按原图比例居中覆盖，竖版、横版均不拉伸，不参与前景内容的高度测量；外部海报由 `ArtworkImage` 按解码后的实际比例 `UniformToFill`，不猜测比例。图片上叠加当前 Window 语义色的半透明遮罩，前景文字使用正文色，保持明暗主题下的可读性；信息区没有独立实色卡片或描边。

简介默认只显示居中的“简介”按钮，正文完全收起、不占空间；点击后展示完整简介并变为“收起简介”，再次点击收回空间。简介、导演与演员左对齐。图片覆盖信息区完整可视范围，正文在图片前方滚动；展开或滚动简介不会把图片变回独立顶部图框。窄窗口的信息区随内容增长，背景始终覆盖全部内容。

信息区内容超出时，只在被截断的上下边缘渐隐。内容宽度达到 840px 时左右排列并保持等高，信息较长时在信息区内滚动；更窄的窗口上下排列。该宽度指 Shell 侧栏之外的内容区域，默认 1110px 窗口使用左右布局，860px 最小窗口使用上下布局。

无片源时状态为“暂无片源”，播放器叠层与信息区胶囊播放按钮均禁用且提供对应的无障碍名称，不显示悬停说明或虚构的播放进度。选集仍可选择，更新当前集标题与预览画面。心形收藏是可键盘操作的 ToggleButton，空心／实心及“收藏／已收藏”反映同一个 `IsFavorite` 状态；名称随之切换为“收藏 片名／取消收藏 片名”。收藏图标与文字使用正文色，在叠图背景上保持可读性。当前只做会话内预览交互，不写入影视收藏库、不跨应用重启保存，也不发起网络请求。

选集默认横向图文卡片：每集包含剧照、序号／集名、时长及两行简介。列表模式一行一集，保留相同信息并显示更长简介。选集卡、列表行和相关推荐静止时没有底色与边框；悬停或键盘焦点时复用首页影视卡片的 `CardMotion`、`FilmHoverShade` 与 `FilmPlayMark`：整块轻微放大（卡片与推荐约 1.03，列表行约 1.01 并淡入柔和底色），图片额外放大，图片底部加深，播放标记位于图片区域中央。悬停反馈不改变当前集，也不触发播放。当前集在剧照左上角显示“▶ 当前”徽标，并提供“当前”无障碍状态。按钮可切换布局，当前集只有一个事实来源，切换布局不改变当前集；返回横向时定位到当前集。横向选集及底部相关推荐支持翻页按钮、Shift＋滚轮、PageUp／PageDown 和 Home／End，普通滚轮保留页面纵向滚动。

底部相关推荐使用海报及片名，点击打开相应影片的本地预览。`FilmCapability` 按影片 ID 保留页面模型，`CaptureNavigationLocation` 返回包含影片 ID 的位置；Shell 返回时恢复原影片、当前集、布局、简介展开与会话内收藏状态。切换影片时信息区回到顶部。首页和栏目页仍复用各自原视图和滚动宿主。

页面根底色透明，其后有一层固定在视口的氛围色：取海报平均色的色相与饱和度，明度固定在当前主题窗口色附近（浅色 0.935，深色 0.125），饱和度设上限，保证正文和次要文字对氛围色的对比度不低于 4.5:1。该层在顶部、左侧 48px 和底部渐变回透明，衔接 Shell 页头、侧栏与底部播放条的窗口色。没有海报主色时氛围层透明；外部海报移出视口释放后保留最后的有效颜色，换影片时随新海报更新。表面与文字沿用动态语义色、系统字体及共享焦点样式；文字使用 Display + Auto，由 WPF 按实际表面选择抗锯齿，不整页强制灰度。高对比模式隐藏播放区、信息背景的装饰图片和氛围层，选集与推荐改为 2px 系统描边（当前集使用 Highlight），恢复系统文字和背景色。无常驻动画或播放定时器；悬停动画由 `CardMotion` 驱动，减少动画或高对比时直接切换。远程海报继续通过 `ArtworkImage` 的可见性、取消与缓存生命周期，本地预览使用 WPF 资源图片，两者都通过 `ArtworkImage.SamplePalette` 的同一算法取色。鼠标点击后按钮保留键盘焦点，按 `CardMotion` 的“悬停或焦点”规则保持高亮，直至焦点离开。

## 占位数据与素材

`FilmPlaybackPreview` 是唯一预览数据入口。电影显示一段正片；剧集、动漫、综艺各显示第 1 季的 12 集示例；总集数从集合计算。除原卡片字段外，年份、地区、导演、演员、总简介、单集标题／简介／时长及推荐关系都是本地示例，可能不对应所选现实作品。后续接入数据源时需要整体替换这些示例。

剧照复用用户指定 `ui-design` 中《漫长的季节》的素材，并不表示它们对应所选影片或真实单集。相关推荐使用《隐秘的角落》《沉默的真相》《白夜追凶》《无证之罪》《开端》《狂飙》《漫长的季节》的本地公开海报，排除同名当前影片后取六部；它们是展示样例，不是服务推荐结果。

图片位于 `Film/Presentation/Assets/`，作为 WPF `Resource` 编译，可离线显示。19 张 JPEG 合计约 1.17 MiB。同目录 `sources.json` 记录每张图片的原地址、原始与派生尺寸、裁剪关系、大小及哈希。图片版权归原权利人，来源记录用于追溯；没有将其标注为自制或开放许可。自带图片只在固定的 App 资源目录下解析，外部海报仍进入公共图像服务。

## 验证边界

`FilmPlaybackTests` 覆盖选集、布局、当前集同步、无片源禁用、响应式布局及导航恢复，以及无边框磁贴与高对比描边、悬停放大与播放标记居中、当前集徽标与状态、海报等比覆盖整个信息区、居中叠图文字与首屏操作、简介按钮折叠／展开和返回恢复、收藏 UIA／键盘切换和按影片恢复、明暗主题在纯黑／纯白／无海报背景上的文字对比度、氛围色的视口固定与随影片更新；原有 `FilmHomeTests`、`FilmPresentationTests` 继续验证首页、栏目分页／筛选与入口跳转。高对比隐藏信息区海报和装饰遮罩，操作使用系统色，没有独立图框空位。本轮没有接入或验证真实视频流、真实影片详情、账号收藏／收藏持久化、播放记录及其他平台。已有 270×405 海报放大会发软；截图验证不覆盖真实鼠标、显示器 DPI 或 Shell 合成。
