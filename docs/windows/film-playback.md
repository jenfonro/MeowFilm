# Windows 影视播放页

`FilmCapability` 的隐藏路由 `film-playback` 在页头显示“播放页”。正式播放实现由 `FilmPlaybackRequest`／`FilmPlaybackPage` 投影真实 Node film 会话，`FilmPlaybackSession` 负责连接、事件、命令及原生媒体 attempt；智能选路、准确站点取址、业务数据缓存与新增播放资料不在原生呈现层重写，见[影视播放契约](../runtime/film-playback.md)。首页、栏目和搜索交接均传递准确目标／真实上下文，不只用影片 ID 构造示例。搜索交接只按[共同契约](../common/film/search.md)，本端实现见[影视搜索](film-search.md)；导航／搜索已接入正式会话，平台执行证据仍见下方验证边界。

页面初始卡片／元数据来自显式请求，后续完整作品资料来自 `workInfo.metadata`，季集、来源、线路、文件与执行状态分别消费对应会话投影；缺失简介、导演、演员、推荐或剧集时保持空状态，不补样例或猜测播放 URL。浏览选择与正在播放的目标分别呈现，页面隐藏不等于媒体退出；命令和迟到事件须符合当前会话／attempt 身份。搜索原始选择与上下文的保持、更新及释放以共同契约为准，不在本文件新增另一套搜索更新接口。

## 页面保留与读取恢复

共同展示、导航及恢复语义见[页面契约](../common/pages/data-requests.md#展示与执行生命周期)。
`FilmCapability.playbackPages` 以独立 `NavigationIdentity` 持有各入口的 `FilmPlaybackPage`，
Shell 位置为 `film-playback:<NavigationIdentity>`；历史恢复直接选择该实例。
`ReleaseUnreachablePages` 仅最终不可达页调用 `Release`，会话离页不再调用 `ReleaseDirectories`。
页面按来源结果、typed 线路、元数据来源及季度持有成功浏览展示切片、目录控件和滚动位置；
切片只含资料、目录读取结果与展示条目，不保存播放 stage、attempt、current 或整份实时快照。
已加载选择切回只恢复对应切片和控件，不发送浏览 RPC；每个来源／资料入口保留最后所选季度和线路。
未加载选择先同步进入 loading 并隐藏另一选择的内容，旧请求只更新所属切片，不能覆盖当前选择。
同内容只读重开及同身份、同文件内容的刷新失败保留成功展示；刷新错误只通过通知报告，原始目录与文件选择仍可用。明确新选择、冷读取失败、实际文件变化和成功为空按当前目录状态互斥呈现；失败保留的内部成功切片不授予旧文件操作权限。
相同目录内容由 `FilmEpisodeDirectory.Apply` 复用条目；`HasExecution`／`SnapshotFor`
独立决定实时忙碌状态、命令准入与媒体反馈。

`FilmView` 的 `SuspendPresentation` 只停止可见页面读取，不把临时设置或应用覆盖当作导航离开，也不因此停止已有播放。
真正导航离开由外壳调用 `LeaveNavigationAsync`，普通输出退休，显式 PiP 仍按媒体 owner 保留。
重新可见调用 `ResumePresentation`，有同页会话时恢复观察，否则 `OpenPageSessionAsync`
以 `restoreOnly:true` 重开。`CaptureRequest.Browsing` 保存来源结果、typed 线路、
元数据来源、季度及选中行的真实 `source` 指针，随单次 open 交给 Node 读取恢复，
不在客户端通过标题或多轮浏览命令重建目录。运行器恢复同样保留页实例和固定目标，
执行、来源授权及媒体回执仍核对实际 owner，协议见[读取恢复](../runtime/film-playback.md#读取恢复)。

Shell 的公共搜索页用 `Destination.PageId` 进入与播放相同的历史／前进分支；
已移除 `_returnPage`／origin 捷径。当前源码采用正常提交／恢复顺序，不表示
“搜索→播放A→推荐B”的真实窗口返回、前进及设置往返已验收。
公共晚到更新同样遵守[读取恢复限制](../runtime/film-playback.md#读取恢复)，
不因关联资料到达而自动播放／准备；定向契约检查不能替代真实窗口验收。

`snapshot.target` 表达当前准确播放目标，不充当全部展示类型。元数据页面选择站点文件后，即使其 `kind` 成为 `source`，本端仍按运行器给出的 `metadataSourceId`／`metadataSources` 投影资料 provider、电影／剧集布局、季度与推荐。同内容换文件／重新取址以接纳时已确认的内容类型和季集坐标决定是否承接实际进度，不能从标题或内容 ID 猜电影。重入沿用 `target` 保存真实元数据入口、`resumeTarget` 保存准确 source 的既有契约，无搜索 reference 或换运行器 owner 也不抹掉已证入口及可用资料／缓存；执行仍严格按 source 恢复，不重新变成智能播放。

元数据菜单逐行消费字符串 `id` 与已支持的 provider；未选坏行局部隔离，健康兄弟保序，不能阻断同一快照的主资料、后续 SSE 或媒体 attempt。非空 `metadataSourceId` 按字符串身份精确关联具有可消费 id／provider 的真实选中行，数字不转作字符串别名，也不能借菜单回退替换身份。菜单仍只在原始行变化时投影，投影未变不替换集合；目录保留与释放按页面、来源、typed 线路、元数据来源和季度管理，不随执行会话身份变化销毁。

关闭询问或取消不退休 App typed 系统媒体会话。仅 Shell 的准确入托盘隐藏保留已有实际 Film 输出、attempt、媒体通道和暂停进度；恢复不重开或双播，准备中没有实际输出则照旧取消并排空。普通影视离页或切换模块仍停止普通 native 输出，只有显式 PiP 可继续保留。托盘退出和其他真正退出立即请求停止输出并结束进程。页面离开、进程内重置和重新装配仍等待实际原生输出与准确媒体回执排空，见[App生命周期](app-runtime.md)。

原生准备失败传递受控异常的有限错误码，实际输出失败读取同一 `FilmPlayback.LastErrorCode`，以准确 attempt 的 `media.failed.code` 回报运行器；不发送异常正文或地址。`media.started` 只在同一 attempt 的真实首帧提交后反馈；终止观察者在真实 retire 后、状态清空前读取准确 scope／时钟，停止或关闭不得转发旧身份的终止事件，具体见[电影生命周期](media-playback.md#电影生命周期许可与验证边界)。最终原生错误优先于无关资料加载提示，候选过程失败不反复作为最终错误通知。目录状态与原生资源分别释放，handoff 的 discard 等待实际在途 commit 结束后才退休候选；停止路径的原生控制与释放共用现有命令锁。

业务命令阻挡提交时保留同一有效候选，待命令回执后重新准入；原生已停止／替换的候选则以 `MEDIA_SUPERSEDED` 结束并释放准确回执，不当作暂缓重试或失败片源。释放错误仍按实际错误保留。同内容交接采用确切 donor 的最新暂停／恢复状态，准备期间到达的用户控制不能被旧取址回执覆盖；不同内容不继承该状态。

浏览快照不能清除原生提交、执行或排空错误；显式恢复仍核验准确 attempt、实际 started／首帧提交及资源退休结果。Node 已确认 started 的同一 occurrence 不重复 commit／started。媒体通知按页面实际消费字段比较；普通来源浏览不会重挂 surface 或重发未变化的系统媒体状态，真实身份切换、首帧、撤权和结束仍正常处理。

## 页面与交互

`FilmPlaybackView` 使用 WinUI 原生控件与现有主题。上方左侧是 16:9 媒体输出区，海报或剧照不作为真实视频帧证据；右侧只有一套 `MetadataContent`，固定顶对齐，不在长短内容、展开简介或演员换行之间切换第二套树。标题、事实和操作组仍可在各自行内水平居中，但整个信息组不再垂直居中。页面及信息区透明透出 Shell 的共享应用画布，不再铺海报、叠加海报遮罩或派生环境色，也没有独立实色卡片或描边。剧照与推荐海报仍按原图比例 `UniformToFill` 显示在各自卡片内，不拉伸或猜测比例；视频像素区及视频浮窗保留黑底。

播放器控件按服务器版桌面前端布置在视频画面内部：进度条下方分左右胶囊；左侧依次为播放／暂停、上一集、下一集、静音（悬停展开音量）和时间，右侧按实际上下文显示当前网盘、画质、换源、片源错误、画中画、设置及全屏。设置内是六档倍速（0.5／0.75／1／1.25／1.5／2）与默认／16:9／4:3 比例，不再在画面外排列控制按钮。宽度不足依次收起网盘、画质、换源、片源错误、画中画，恢复宽度后还原；设置和全屏始终保留。最小画中画等极窄尺寸下，两胶囊分为两行，不缩放普通文字，也不覆盖时间或按钮。菜单打开只读取当前快照，不搜索／请求详情，媒体替换时收起旧菜单；网盘标准名由运行器归一，未识别线路不由客户端猜别名。浏览某站点列表不改变正在播放目标的智能模式。

`FilmNativeMedia.View`、`FilmPlaybackPage.MediaView` 和目录 `Presentation` 均使用 `Microsoft.UI.Xaml.FrameworkElement`。正式 `FilmVideoSurface` 是包含 `SwapChainPanel` 的 WinUI Grid；页面把唯一 `PlayerOverlay` 直接赋给它的 `Content`，画面、控制条与外壳覆盖使用同一 XAML 呈现树。没有 picture child HWND、外置控制窗口、`LayoutUpdated` 追位、屏幕坐标换算或复制裁剪；滚动、尺寸和层叠由共同树处理。原始目录浏览由声明式 `Film/Presentation/Dialogs/FilmDirectoryDialogView.xaml(.cs)` 经 `DesktopModalHost.ShowDialogAsync` 居中呈现。

页面加载后即挂载稳定 surface，不等待 `HasOutput` 才挂载；未挂载时不使用 parking 窗口。页面使用共享 `AspectRatioDecorator` 在布局测量中确定 16:9 画面尺寸，浮窗期间保留同尺寸的页面占位，避免内容高度坍塌改变浏览位置。实际 Loaded／XamlRoot 可见性与提交等待、尺寸／合成缩放、swapchain 绑定和资源退休由 Media owner 负责。全屏／画中画移动同一 `PlayerFrame`、surface 和控件树，不新建播放实例、不重发媒体 commit；PiP 继续保留显式媒体 owner，关闭浮窗把同一树归还页面。真实缩放连续帧、应用覆盖及 HDR 输出分别记录验证结果。Windows 外部播放器与 mpv 进程／IPC 调用链不在本实现内。

鼠标进入／移动显示底栏；播放且非加载／缓冲、无打开菜单或键盘控件焦点时，静止 2200ms 后收起，离开画面立即收起。暂停、准备中或菜单展开时保持可操作。画面单击延迟 220ms 切换播放，双击只切换全屏；空格播放／暂停、左右键跳转 5 秒，控件自身键盘输入不被截走。进度拖动或进度条键盘调整只预览，释放才提交；失焦／捕获丢失取消，旧媒体身份不能跳转新片源。网盘／画质选择、换源和片源错误沿用准确业务命令；片源错误按服务器直接提交当前 attempt 的屏蔽与重匹配，忙碌时不重复提交，不再弹二次确认。倍速／比例失败恢复上次实际设置。

初始加载、搜索、取址与原生准备在画面中央显示当前阶段文字和细条；细条是离散业务阶段，不表示下载百分比。暂停由 `FilmPlayback.IsPaused` 消费内核确认的 state，不能用请求值推断。原生缓冲由同一内核快照确认，等待环不以“请求过暂停”遮蔽，也不将内核队列或设备 padding 当作下载范围。短视频开关位于信息区播放按钮旁，不在播放器底栏或设置内；滑动切集仍作用于视频画面，预取状态由该开关提示。点映开关保留在页外选集工具行。

站点来源、网盘来源、点映、必要的原始目录入口和横向／列表切换位于同一工具行，季度仍独立展示。选集翻页按钮位于卡片轨道左右两侧，复用影视首页的白色圆形按钮样式；到达边界时隐藏不可用方向，卡片全部放得下时两侧均隐藏。站点与视频／网盘弹层的可见主体固定为实际控件宽度，选项单行省略，不由长文字撑宽。初始或未取得站点 detail 时，视频／网盘入口保留但禁用并显示加载态；失败保留控件的失败状态并通过统一通知报告，不把错误文字插入选集布局，旧文件不可操作。成功为空显示“无可用视频源”，不插入占位来源或未解析的假文件。已取得线路菜单时即可选择，只读取实际选中线路。菜单保留运行器返回的非空线路标签：接管后显示标准分享名，关闭接管时保留脚本原名；不同分享不被平台名称覆盖。播放器内的网盘选项继续按 provider 展示平台名。收到实际来源与选中身份后准确选中，不按同名去重。同名站点附真实条目标题区分，缺站点名时使用真实条目标题。站点来源下拉弹层底部的“加载更多”继续搜索尚未完成的来源；打开菜单不请求数据，操作不改变当前来源、网盘或季度，请求中与搜索加载时禁用重复操作。季度投影优先使用运行器给出的可信 `doubanSeasons`，否则使用标准 `seasons`，不把豆瓣原始关联 subject 列表当成季度坐标；本端不匹配或归并分季。

信息区“播放”提交既有 `play` 动作，作用于 Node 当前正式播放目标，不从本地浏览目录推断目标；不因已有输出变成暂停旧媒体，也不按本地 pending 提前吞掉请求。相同目标的重复动作仍交 Node 幂等；等待命令回执时阻止原生准备提交，仅权威快照中的替换决定退休旧 pending。播放器按钮、画面单击、空格和系统暂停／继续只控制当前实际媒体，无输出时不代替页面起播。来源、资料、线路与季度切换本身只浏览，不切流、不撤销 pending 原生准备。选集、电影候选与原始文件统一提交 `select.target`，携运行器给出的完整 `playbackTarget` 及所选 `metadataSourceId`，不先同步 Node 浏览游标、不再发送坐标式或仅 candidateId 的选集命令。未加载目录需要调整资料／来源／季度时，仍使用既有 browse 命令，并等待实际读取结算，不猜测完成时间。

普通页面恢复继续由运行器检查当前资料或目录是否过期／缺失。“重新取址”位于画内设置菜单，只重新获取准确当前／失败文件的地址，不变成换源；没有输出且存在可重试项时，画面中央另提供同一恢复操作，正常视频不被该按钮覆盖。操作失败仍通过原通知组件报告。

恢复资格直接消费运行器的 `retryMediaAttemptId`，包括候选耗尽后的有效失败项。资料初始化失败时显示“重新加载”，调用 `browse.refresh`；此时没有媒体重试项，不发送无候选的 `media.retry`，加载期间不重复提供该操作。

顶部作品标题、海报、简介、演职员、评分、类型及推荐读取 Node 的完整 `workInfo.metadata`。主简介与总季集仅读取稳定作品投影，不随站点或资料视图切换，也不从当前文件数或站点简介填缺；未知总量不显示编造数字。收藏的 `EntryTarget` 和主字段同样来自稳定作品身份，不拿当前浏览条目替换收藏对象。

`FilmPreferences.MetadataViewProvider` 独立持久保存资料视图偏好，仅明确手选 TMDB／豆瓣视图时写入，默认 TMDB。本片只有其中一种时临时显示可用资料，不改保存偏好。站点菜单里的聚合入口与资料视图独立，选择 TMDB／豆瓣聚合站点不等于切换资料视图。成功目录按站点、typed 线路、资料来源及季度复用；可靠的资料关联撤销使对应缓存及在途读取失效，不借旧正式播放的 unavailable 状态拒绝健康目录选择。

简介默认只显示居中的“简介”按钮，正文完全收起、不占空间；点击后展示完整简介并变为“收起简介”，再次点击收回空间。简介、导演与演员左对齐。正文在共享应用画布上滚动；窄窗口的信息区随内容增长，展开或滚动简介均不创建局部背景。

信息区内容超出时由自己的 ScrollViewer 滚动；单树内容始终从顶部开始。内容宽度达到 840px 时左右排列并保持等高，信息较长时在信息区内滚动；更窄的窗口上下排列。该宽度指 Shell 侧栏之外的内容区域，默认 1110px 窗口使用左右布局，860px 最小窗口使用上下布局。

播放、选集、换源、画质与目录操作提交真实会话命令，准入和错误以当前状态为准；无有效会话不发播放，不显示虚构进度。心形收藏是可键盘操作的 ToggleButton，空心／实心及“收藏／已收藏”反映同一个 `IsFavorite` 状态；名称随之切换为“收藏 片名／取消收藏 片名”。收藏图标与文字使用正文色，在共享应用画布上保持可读性。收藏通过原生 `FilmLibrary` 的 `film.library.v1` revision 与共享 SQLite 独立关系行持久提交，失败不伪装成功；它不属于 Node 新增的历史／人工匹配／屏蔽／偏好库。

收藏按稳定 `target.Id` 作为独立行身份，主字段和来源／聚合成员身份保存为 typed columns 与子关系，没有原收藏 JSON 或任意嵌套扩展槽。读取和打开时解析实际消费的目标，核对行主键与 target 身份一致；合法完整替换或明确删除按请求的准确目标操作，不先解码将被弃用的旧业务值。无关行的增量写入保留坏兄弟，完整列表读取仍报告不可消费的目标。根当前身份、关系类型、事务与 revision 以及已受理写入的真实回执继续约束提交，不补造目标或猜测身份。新收藏只保存稳定目标及来源／聚合成员身份，不落盘搜索上下文、媒体地址或临时凭据。

会话的 cache/components/supplement 是可选展示投影，不是解析有效主资料的前置全对象门禁；不可消费的补充资料不参与展示，未知缓存状态不伪装 fresh，真实 cache 错误仍报告。补充资料只补显示缺口，不替换主目标、季集身份或实际媒体回执。

存在真实剧集时，选集默认横向图文卡片，仅显示来源实际提供的剧照、序号／集名、时长及简介。列表模式一行一集，保留相同信息并显示更长简介。电影候选海报保留144–176 DIP宽、2:3比例和原生文字布局。选集卡、列表行和相关推荐静止时没有底色与边框；悬停或键盘焦点时复用首页影视卡片的 `CardMotion`、`FilmHoverShade` 与 `FilmPlayMark`：整块轻微放大（卡片与推荐约 1.03，列表行约 1.01 并淡入柔和底色），图片额外放大，图片底部加深，播放标记位于图片区域中央。悬停反馈不改变当前集，也不触发播放。当前集在剧照左上角显示“▶ 当前”徽标，并提供“当前”无障碍状态。按钮可切换布局，当前集以会话快照为事实来源，切换布局不改变当前集；横向与纵向分别恢复该目录先前的浏览位置。横向选集复用音乐首页的共享 `Shelf`：按可用宽度调整完整卡片数量，卡片宽在240–336 DIP之间变化，剧照保持16:9比例；336×189为最大剧照尺寸，参照Windows浏览器中Emby电视剧选集的约242×136至331×186像素剧照，文字保留公共字号并原生重排，不随视口整体缩放，翻页及缩放后按整卡对齐，末页不露半张卡片，并只生成视口附近的卡片。横向选集及底部相关推荐支持翻页按钮、Shift＋滚轮、PageUp／PageDown 和 Home／End，普通滚轮保留页面纵向滚动。

播放页按来源、typed 线路、元数据来源与季度保留已加载目录的展示项、控件和浏览位置；首次成功读取才建立，切走不销毁，切回不发送浏览 RPC。运行器仍是资料有效性的唯一 owner，原生不建立第二套 TTL 缓存；来源撤权约束后续执行，真实成功内容更新或页面最终释放才更新／释放对应展示，详见[页面保留](#页面保留与读取恢复)。播放进度、取址、候选失败等快照不替换未变化的选集、来源和推荐集合；条目按 Node `businessId` 复用，季度、文件与相关推荐原样携带 `playbackTarget`，图片、文字与选中态只通知变化字段。纵向选集使用不超过页面视口高度的独立滚动宿主和WinUI ListView／ItemsStackPanel，横向继续使用 Shelf；保留资料不等于无限保留离屏容器或图片租约。

底部相关推荐仅来自真实元数据，具备准确目标的条目才能提交下一次播放页请求，不打开固定本地推荐样例。布局、简介展开与滚动属于原生页面状态；当前目标、播放位置和 attempt 属于会话／媒体 owner，收藏以原生资料库为准，不由导航缓存授予权限。首页和栏目页仍复用各自原视图和滚动宿主。

页面背景由 Shell 的 `MeowFilm.Brush.AppBackground` 唯一持有，沿用默认浅蓝到近白渐变及全局用户自定义色；影片、海报、空海报及滚动不会改变该画布。影视专属海报取色、颜色缓存、氛围转换和信息区背景图片路径已删除，正文与次要文字对共享浅色画布保持不低于 4.5:1 的对比度。系统字体及共享焦点样式保留；普通文字统一为系统 Normal 字体，由 WinUI 按实际表面呈现。高对比使用系统背景和文字资源，选集与推荐改为 2px 系统文字色描边，当前集仍保留非颜色的“当前”徽标与无障碍状态。没有伪造播放进度的定时器；悬停动画由 `CardMotion` 驱动，减少动画或高对比时直接切换。普通远程剧照与海报卡继续通过 `ArtworkImage` 的可见性、取消与缓存生命周期；通用图片采样仍由 `ArtworkImage` 提供，不再用于影视页面背景。全屏音乐播放器与小说阅读器的独立画布及用户配色保持不变。鼠标点击后按钮保留键盘焦点，按 `CardMotion` 的“悬停或焦点”规则保持高亮，直至焦点离开。

## 正式数据与历史预览素材

正式播放模型以真实元数据与会话结果为准，不生成“第一季 12 集”、固定演员／时长或推荐关系。历史预览模型与旧入口已移除，正式导航使用准确 metadata、聚合或原始单源请求；不存在用预览内容填补缺失数据的回退。

历史剧照复用用户指定 `ui-design` 中《漫长的季节》的素材，并不表示它们对应所选影片或真实单集；固定本地海报同样不是服务推荐结果，不用于填补正式会话缺失内容。

历史图片位于 `Film/Presentation/Assets/`，按 WinUI 打包内容通过 `ms-appx:///MeowFilm.Capabilities/Film/Presentation/Assets/` 解析，可离线显示。19 张 JPEG 合计约 1.17 MiB。同目录 `sources.json` 记录每张图片的原地址、原始与派生尺寸、裁剪关系、大小及哈希。图片版权归原权利人，来源记录用于追溯；没有将其标注为自制或开放许可。自带图片只在固定的 App 资源目录下解析，外部海报仍进入公共图像服务。
