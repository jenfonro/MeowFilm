# Windows 影视播放页

`FilmCapability` 的隐藏路由 `film-playback` 在页头显示“播放页”。影视首页与栏目数据页卡片均通过 `OpenPlaybackAsync` 进入，保留原卡片的影片 ID、片名、海报与评分。播放页目前用于本地 UI 预览，不读取影片详情、不解析片源，不启动媒体引擎、脚本运行时或假播放计时。

## 页面与交互

`FilmPlaybackView` 使用 WPF 原生控件与现有主题。上方左侧是 16:9 剧照预览，右侧以低透明度海报为背景，呈现标题、年份／地区／季集数、类型、评分、导演、演员和可展开的简介。内容宽度达到 840px 时左右排列并保持等高，信息较长时在信息区内滚动；更窄的窗口上下排列。该宽度指 Shell 侧栏之外的内容区域，默认 1110px 窗口使用左右布局，860px 最小窗口使用上下布局。

无片源时状态为“暂无片源”，播放按钮禁用且提供对应的无障碍名称和提示，不显示虚构的播放进度。选集仍可选择，更新当前集标题与预览画面。

选集默认横向图文卡片：每集包含剧照、序号／集名、时长及两行简介。列表模式一行一集，保留相同信息并显示更长简介。按钮可切换布局，当前集只有一个事实来源，切换布局不改变当前集；返回横向时定位到当前集。横向选集及底部相关推荐支持翻页按钮、Shift＋滚轮、PageUp／PageDown 和 Home／End，普通滚轮保留页面纵向滚动。

底部相关推荐使用海报及片名，点击打开相应影片的本地预览。`FilmCapability` 按影片 ID 保留页面模型，`CaptureNavigationLocation` 返回包含影片 ID 的位置；Shell 返回时恢复原影片、当前集、布局与简介展开状态。首页和栏目页仍复用各自原视图和滚动宿主。

页面根底色透明，表面与文字沿用动态语义色、系统字体及共享焦点样式。高对比模式隐藏播放区及信息背景的装饰图片，恢复系统文字和背景色。无常驻动画或播放定时器；远程海报继续通过 `ArtworkImage` 的可见性、取消与缓存生命周期，本地预览使用 WPF 资源图片。

## 占位数据与素材

`FilmPlaybackPreview` 是唯一预览数据入口。电影显示一段正片；剧集、动漫、综艺各显示第 1 季的 12 集示例；总集数从集合计算。除原卡片字段外，年份、地区、导演、演员、总简介、单集标题／简介／时长及推荐关系都是本地示例，可能不对应所选现实作品。后续接入数据源时需要整体替换这些示例。

剧照复用用户指定 `ui-design` 中《漫长的季节》的素材，并不表示它们对应所选影片或真实单集。相关推荐使用《隐秘的角落》《沉默的真相》《白夜追凶》《无证之罪》《开端》《狂飙》《漫长的季节》的本地公开海报，排除同名当前影片后取六部；它们是展示样例，不是服务推荐结果。

图片位于 `Film/Presentation/Assets/`，作为 WPF `Resource` 编译，可离线显示。19 张 JPEG 合计约 1.17 MiB。同目录 `sources.json` 记录每张图片的原地址、原始与派生尺寸、裁剪关系、大小及哈希。图片版权归原权利人，来源记录用于追溯；没有将其标注为自制或开放许可。自带图片只在固定的 App 资源目录下解析，外部海报仍进入公共图像服务。

## 验证边界

`FilmPlaybackTests` 覆盖选集、布局、当前集同步、无片源禁用、响应式布局及导航恢复；原有 `FilmHomeTests`、`FilmPresentationTests` 继续验证首页、栏目分页／筛选与入口跳转。本轮没有接入或验证真实视频流、真实影片详情、账号收藏、播放记录及其他平台。
