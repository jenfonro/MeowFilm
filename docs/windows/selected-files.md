# Windows 显式选择文件快照

`MeowFilm.Platform.Files` 将用户通过原生文件选择器明确选择的普通本地文件复制为一次性内存快照。它不授予目录访问、不保存源路径、不建立文件监听，也不向 Node 暴露文件系统。

## 公共入口

| 入口 | 扩展名 | 最大字节 | 结果 |
| --- | --- | ---: | --- |
| `SelectedJsonSnapshot` | `.json` | 8 MiB | 原始字节、SHA-256、文件名 |
| `SelectedScriptSnapshot` | `.js` | 16 MiB | 原始字节、SHA-256、文件名 |
| `SelectedLyricSnapshot` | `.lrc`、`.qrc`、`.yrc`、`.txt` | 256 KiB | 严格解码文本、SHA-256、文件名 |

JSON 与脚本入口只创建字节快照；脚本快照与公共 ScriptHost 使用同一个 16 MiB 单脚本源码上限，读取和后续原生导入入口均提前拒绝超限输入，不把历史 512 KiB 门槛当成兼容条件。脚本 owner 随后执行严格无 BOM UTF-8、源码字节完整性和安装事务校验，不提取域名授权名单或按源码哈希补网络 origin。歌词接受 UTF-8，或带 BOM 的 UTF-8／UTF-16；最多 65536 个字符并拒绝非法控制字符。

## 路径与文件边界

- 输入必须是明确扩展名的普通本地绝对路径。
- 拒绝 UNC、设备路径、映射网络驱动器、reparse point、hardlink、目录、特殊文件和危险路径组件。
- 路径最多 4096 个 UTF-16 字符、128 个组件、每组件 255 个字符。
- 读取期间固定并复核卷、文件身份、链接数、长度、最后写入时间和当前位置。
- 文件占用、替换、截断、增长或属性改变均明确失败，不返回部分快照。
- 读取工作不在 UI context 执行；取消只在有界系统调用之间协作，不伪装成强制终止任意 OS 调用。

结果只包含调用方拥有的内容、规范小写 SHA-256 和 basename；绝不返回完整路径。异常只有固定枚举，不包含路径、payload 或内部异常。

调用方完成解析或传输后负责清理敏感字节；歌词入口在解码后清零原始缓冲。
