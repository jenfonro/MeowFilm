# Windows 显式选择文件快照

`MeowFilm.Platform.Files` 将用户通过原生文件选择器明确选择的普通本地文件复制为一次性内存快照。它不授予目录访问、不保存源路径、不建立文件监听，也不向 Node 暴露文件系统。

## 公共入口

| 入口 | 扩展名 | 结果 |
| --- | --- | --- |
| `SelectedScriptSnapshot` | `.js` | 原始字节、文件名 |
| `SelectedLyricSnapshot` | `.lrc`、`.qrc`、`.yrc`、`.txt` | 严格解码文本、SHA-256、文件名 |

脚本入口只创建字节快照，不设置业务字节配额。脚本原始字节经完整 HTTP 上传，由公共运行器校验严格 UTF-8（允许开头 BOM）及安装事务；客户端不计算传输摘要、不拆分源码，也不按源码哈希补网络 origin。歌词接受 UTF-8，或带 BOM 的 UTF-8／UTF-16，并拒绝非法控制字符，不设置内容字符数配额。快照仍受 .NET 数组可表示长度（`int.MaxValue`）和实际内存约束。

## 路径与文件边界

- 输入必须是明确扩展名的有效本地路径（经 `Path.GetFullPath` 规范化并核对扩展名）。
- 不存在、无权限、文件被独占占用或 I/O 异常均映射为固定枚举失败，不返回部分快照。
- 读取工作不在 UI context 执行，使用异步流式读取并支持协作式取消。

结果只包含调用方拥有的内容和 basename；歌词另外保留其原生业务使用的规范小写 SHA-256，脚本快照不计算摘要。绝不返回完整路径。异常只有固定枚举，不包含路径、payload 或内部异常。
