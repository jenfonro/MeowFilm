# 个人目录与目录页面契约

共同规则分别见[页面数据请求](../common/pages/data-requests.md)、[播放来源、队列与自动续播](../common/music/playback-sessions.md)和[平台客户端上下文](../common/music/platform-client-context.md)。本文件只补充 Windows 页面入口、投影和实际交互契约。

## 页面归属

- 个人歌单、每日推荐、私人 FM、相似歌曲、专辑、心动推荐和队列推荐均属于同一个 Windows App 的目录能力，不是独立产品或第二套导航壳。
- `MusicCapability` 是页面状态 owner；`MusicCatalogView`、`MusicDiscoveryView` 和 `MusicRecordView` 只投影当前状态并转发用户意图。
- 页面不持有账号 Cookie、平台请求、曲库写入或播放引擎。

## 当前入口

| 用户入口 | 原生命令 | 约束 |
| --- | --- | --- |
| 个人歌单 | `music.catalog.personalPlaylists` | 明确平台、分页、账号代次 |
| 歌单详情 | `music.catalog.playlist` | 原 locator 和 snapshot，不猜私有权限 |
| 每日推荐 | `music.catalog.daily` | 网易云当前账号，按可见入口读取 |
| 私人 FM | 预览 `music.catalog.fm`；播放 `music.recommendations.start {kind:fm}` | 首页恢复本机同账号上次选择，首次 DEFAULT；频道明确 mode／submode／ruleId／tabTagId 原样保留 |
| 相似艺人／歌曲 | `music.recommendations.start {kind:similar,sourceType,sourceIds}` | 使用真实艺人／歌曲种子；共享网易 ID 可用 |
| 专辑 | `music.catalog.album` | 使用明确 album id，不按标题搜索 |
| 首页／云喜欢心动 | `music.recommendations.start {kind:heartbeat,platform:wy,entry:favorites,songId?}` | 首页带展示曲，平台解析同账号真实喜欢上下文 |
| 播放器当前曲心动 | `music.recommendations.start {kind:heartbeat,platform:wy,entry:current,songId,playlistId,seedEntryId}` | 仅已传播的官方账号歌单上下文，普通网络歌单不开放 |
| 单曲推荐 | `music.recommendations.start {kind:queue,platform:wy,seedEntryId,restore}` | 搜索自动候选 restore=false；歌单主动进入 restore=true |

## 状态与交互

- 页面状态按 `idle/loading/content/empty/error/cancelled` 区分；已有内容刷新时保留内容，但不能启动第二条并行加载链。
- 正常启动已在主窗口构造前读取本地账号、首页来源与首页快照；首次进入设置页复用已知本地账号状态，不再把账号占位 `unknown` 当作首页卡片失效。首页恢复、后台更新及单份展示的边界见[首页启动与展示快照](music-catalog.md#首页启动与展示快照)。
- 卡片主体、播放按钮和栏目级翻页按钮分别拥有命中区域。页面模型必须按卡片类型决定进入详情或直接播放，不能让所有卡片共用一种行为。
- 栏目级悬停和翻页按钮由栏目容器持有，指针从卡片移到按钮时不得丢失可见状态。
- 入口卡片统一白色标题与轻微的顶部同色渐变，标题位于所有遮罩之上；说明区固定两行高，单行文字在第二行。有歌曲列表时悬停将说明与歌曲整体上移，第三首下方只留正常内边距，展开遮罩与底栏复用柔和代表色；无列表入口只淡入普通歌单共用的图片遮罩及独立播放按钮，不移动说明。装饰遮罩均不参与命中。测量与取色规则见[目录与频道](music-catalog.md#视觉与文本)。
- 每日推荐保留上游有效的 `dayOfMonth`（1–31）和包含歌曲信息的完整 `subtitle`，折叠／展开均保持同一文案，不从本地日期或歌曲标题编造日历、文案。
- 页面切换、筛选、账号变化和关闭会取消相关请求代次；被取消或过期的结果不更新卡片、选择或错误状态。首页展示独立于账号位置缓存，账号变化时保留最后成功内容；非首页继续检查会话、成员快照及有效期。
- 新发布的个人入口只在显示条件满足时出现。保留的首页卡片可以来自之前的成功展示，点击私有入口时必须取得当前权威账号；本地账号读取尚未完成时等待同一次读取，不能把未读取状态当成无账号或另开初始化。无账号、无权限、空结果和协议错误分别呈现，不用公共推荐或旧展示中的私有歌曲批次替代个人数据。
- 私有动作的明确认证失效通过统一通知／浮窗报告，不清空整页；真实失败账号租约撤销后触发合并的游客首页更新。网络与单资源权限错误保留账号和展示，游客更新失败不循环重试。

## 播放与保存

- 卡片播放和保存通过目录 `prepare`／`commit` 接到唯一曲库和队列 owner。
- 点击某一首时同时核对目标歌曲身份和队列版本；用户在准备期间产生新播放意图会撤销旧动作。
- 首页后台更新期间，公开歌单仍按卡片 `platform/id` 读取并准备完整成员；普通展示替换与追加不撤销已捕获的播放意图。私有入口重读当前账号资源，既有成员身份、完整分页、准备 token 和队列 CAS 校验继续保留。
- 页面离开只清理页面请求和未提交动作，不停止已经由全局播放器接管的当前媒体。
- 目录 prepare／commit 传播平台已经验证的 `heartbeatAccountId` 到条目 `heartbeatPlaylistId/heartbeatAccountId`；当前曲心动资格检查真实账号、来源与共享网易身份，不按本地收藏或浏览页面推断。云喜欢按钮依据 owned favorites 动作，普通歌单不出现任意歌曲心动菜单。
- 仅缺登录时保留有资格的来源入口，操作通过共享账号观察提示登录；已知网易账号与条目官方上下文不一致时不显示心动入口，账号读取结算同步刷新来源菜单动作身份。

## 全局播放器与候选

- `MusicPlayerView.ModeButton` 位于上一曲左侧，统一显示特殊模式与列表／单曲／随机（1／3／2）；菜单顺序、图标、选中项和恢复资格遵循共同契约，不另设来源／续播按钮。
- 漫游的“切换频道”打开应用内容内的四主模式与四列 43 场景浮层，外侧点击只关闭且不穿透，切换 App 保留；场景键、系统字体、高对比与原滚动条保持。频道配色跟随播放器，底部不放来源文字行或独立频道按钮。
- 底部菜单同按钮关闭、异按钮切换（含队列），迟到音质加载不能重开旧菜单；频道浮层打开时下层点击只关闭频道。
- `PlaybackFmMode/Scene/RuleId/TabTagId` 来自已提交 snapshot，目录草稿不改变频道显示。切频道在途／失败保持已提交项；来源替换、账号变化、隐藏和卸载会使旧动作失效。
- 推荐启动先登记指令代次，再等待同一次共享账号读取；取消／返回或新指令使旧启动失效，不取消其他调用者的账号观察。搜索直接播放在 Open 前绑定该 occurrence／播放 epoch，真实首次 Started 后才异步准备首批；Open 完成不等于开播。尚未 Started 的失败、来源替换、账号或媒体所有权失效会退休该意图；已 Started 后暂停保留候选资格。PlayNext 与循环变化不使有效 preview 失效。
- 只有搜索直接单曲播放自动建立候选；普通首页、歌单、单首普通队列和浏览搜索不推断推荐身份。候选在 `MusicQueueView` 独立于 QueueList 展示，以 session id／candidateId 调用 choose；点击整批入队并选择目标。队列候选区保留实际歌曲、重试和未知提交核对，移除独立续播控件，不保留成功／退出专用状态块。
- 全局循环、来源恢复、候选保留和自动续取遵守共同契约；平台请求、存储及事务实现见[原生持续推荐](music-recommendations.md)。真实失败经现有 Status／NoticeOutlet，正常操作仅更新控件及队列。

## 请求与预览

Windows 预览卡片的前三行由已有批次／成员页投影；栏目发布时按入口类型补齐缺失摘要，不由悬停或聚焦触发。分页、初始化单飞、订阅并发及退休规则见[目录与频道](music-catalog.md)。

## 每日推荐详情与风格编辑

默认／风格推荐都使用歌曲表详情容器及已有单曲菜单、播放全部、所选歌曲、队列与批次保存消费者，切换推荐和编辑不会自动替换播放队列。默认页提供风格入口；风格页在播放区下显示服务确认的标签胶囊，点击展开不推移歌曲表的 Popup 动态分组。标签按钮与频道共享 `Music.FilterTag` 样式，分类、已选项及草稿由独立风格状态管理，不写频道 `CatalogTags/selectedTag`。

分类及顺序来自服务。每次打开创建账号绑定的编辑器；只允许同一分类内的非空唯一标签，切分类清除旧类草稿，无本地猜测数量上限。确认前取消、外点或 Esc 关闭不写入，换页退休草稿；批次保存与重新读取位于更多菜单，窄窗口页头保留播放和一个分支切换入口。确认准入即冻结草稿、撤销旧批次动作资格并只提交一次；此后仅关闭浮层不等于取消写入，同一页面代次和账号下仍接收写入结算与真实回读；`Confirmed` 只代表写回执，只有 `Readback` 更新当前歌曲和胶囊，匹配回读才关闭编辑器。`Unknown` 或写已确认而缺少回读时撤销旧歌曲动作资格、阻止再次确认，保留“重新读取”核对入口，不自动重试；账号／页面切换退休旧草稿及页面发布，不能取消已准入写入或声称回滚；保存结算再次退休该账号的风格快照；若同账号已回到风格页，退休当前读取和旧成员后接收真实回读，缺少回读则清除返回期间的旧选择并等待重新读取，不重放写入。其他页面／账号不接收回执，之后返回须重新读取。

默认与风格推荐保留各自有效页面快照，真实分类与已选标签随对应快照恢复；保存只退休风格旧快照／在途读取，不影响默认推荐返回缓存。

组件用例将代表数据的歌单、默认日推、展开筛选页输出到 `TestWorkspace.ResultsRoot/windows-native/playlist-pages-*.png`，供原生视觉核对；这些离屏绘制证据不代表真实账号服务验收。
