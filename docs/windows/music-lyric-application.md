# 原生歌词应用链契约

## 所有权

- `MusicLyricApplication` 负责一次歌词查询的来源选择、合并请求、缓存、账号代次和关闭。
- `INativeMusicLyrics` 负责网易云、QQ、酷狗等固定平台的精确录音协议；普通官方歌词不依赖 Node。
- `MusicLibraryOwner` 是本地歌词、最后一份展示快照和歌词／封面平台策略的唯一持久 owner。
- `MusicCapability` 的歌词 presentation 维护当前歌曲的唯一歌词集合／读取、显示行、手动预览、滚动状态和用户操作；完整播放器和桌面歌词都是消费者，不创建第二播放器或查询 owner。

## 当前查询顺序

1. 核对当前歌曲和录音身份。
2. 若当前歌曲有明确本地歌词关联，读取并解析本地内容。
3. 否则按当前歌词平台策略查询启用平台；每个请求使用精确平台 id，不按标题猜录音。
4. `wy` 原生结果为空，或当前录音属于 `kw`、`mg` 时，从脚本 owner 读取实际启用安装，按安装顺序逐个尝试同平台歌词能力；`tx`、`kg` 始终只用官方协议。
5. 返回结果统一转换为原文、翻译、音译、行时间和可选逐字时间轴。

显式来源只查询该来源。自动查询也必须满足账号、平台启用、录音兼容和当前代次；不能因某平台失败无界扩散请求。

`music.lyrics.lookup` 只接受必填 `song` 和可选 `sourceKey`；脚本安装由应用编排读取，不由调用方指定。读取安装列表和详情不启动脚本；只有实际歌词请求按需激活当前待尝试的安装。已知不提供对应歌词能力的安装直接跳过，空结果或 `CAPABILITY_UNAVAILABLE` 才继续下一项，取消、权限、存储和协议错误保留失败语义。

## 缓存与代次

- 成功查询按歌曲、录音、策略和账号代次缓存；空结果和错误不缓存。
- 同一身份的并发订阅者共享一个底层 flight，但各自可取消；最后一个订阅者离开也不取消已派发的底层读取；服务继续完成，官方结果填充现有录音缓存；脚本歌词只合并同安装/代次/录音的在途调用，不新增内容缓存，也不在已退出页面继续尝试下一安装。关闭/账号或策略失效仍取消并排空。
- presentation 订阅取消即可结算且不能发布迟到行；这不代表底层读取已经结束。同录音的新订阅可复用仍在途的官方读取。脚本停用或内容更新则由应用 owner 提升查询代次，新代次可独立发起有效读取；旧 presentation 不因旧物理请求尚未结束而保持挂起。
- 脚本 owner 的新歌词读取和播放取消不终止其他已准入歌词；脚本源修改、授权失效或服务关闭仍围住并终止全部相关读取。
- 缓存数量、字节数和 TTL 有界，读取不续期。
- 账号、歌词平台策略、脚本源集合、歌曲或录音变化会提升代次；旧结果不能进入新缓存或当前页面。源变更由应用 owner 失效查询，presentation 同时取消旧请求并将源变更 revision 纳入恢复去重身份。
- 关闭等待底层查询实际结束，不通过定时延迟或额外刷新掩盖未结算请求。

## 持久展示与本地歌词

- `music.lyrics.display.get/save` 使用`music.recording-presentation.v2` 多曲缓存，按稳定 songID／时长指纹保存歌词及已解码封面，不保存 URL、请求头、凭据、文件路径或脚本授权。读取在业务库锁外进行，读取失败或不可解码视为未命中，回锁后复核当前歌词和元数据策略。保存即时更新内存，由独立 owner 顺序持久化；磁盘失败不进入业务 CAS／pending，关闭实际排空读写。
- `music.lyrics.local.get/save/remove` 使用 `native-local-lyrics` schema 2 当前格式，并核对歌曲身份与关联代次。
- 手工本地歌词属于业务数据：缺失区域表示没有数据；未知字段、错误身份或损坏内容使业务文档明确失败并保留原始字节。展示缓存不参与整库解码和业务提交。
- 已保存展示只用于当前页面快速恢复；明确刷新仍执行当前准入查询，旧快照不能冒充刷新成功。

## 播放与交互

- 当前媒体的低频真实位置驱动行选择并校准逐字高亮，不为每帧创建业务通知。`MusicLyricList` 是歌词视口的呈现 owner，保留原生 `ListBox` 的像素滚动和回收虚拟化。
- 滚轮／方向和翻页键浏览只预览视口中线命中或最近的真实歌词，播放 tick 不覆盖预览；只有中线的“播放此处”才提交一次 seek，原暂停时沿用恢复播放语义。正文没有选句行为或逐行播放按钮。连续滚轮累计未完成的目标距离。
- 选曲、换源会失效旧歌词读取并取消手动预览；关闭详情、隐藏到托盘或卸载取消其预览及恢复计时，重新显示直接跟随当前行，只有完整播放器和桌面歌词均关闭才退订共享读取。旧手势或迟到回复不能操作／发布到新媒体。
- 暂停、播放、跳转和恢复均绑定当前播放 occurrence，不能仅按 song id 判断。
- 完整播放器右侧和桌面工具栏的歌词校正共用 `MusicCapability.LyricOffsetSeconds`：`+0.5s` 延后、`-0.5s` 提前，`LyricPositionSeconds = PositionSeconds - LyricOffsetSeconds` 同时用于活动行和真实逐字呈现，不 seek 音频、不重写源时间。预览时间和确认 seek 反向换算为 `row.Time + offset` 并按媒体可用范围夹取；呈现时钟本身可为负，不截断真实词的进度。校正属于当前播放曲目／录音及歌词来源的会话状态；切歌、换录音、换歌词来源或更换本地歌词归零，音质切换、暂停和歌词视图重开不清零，不永久记录每首歌偏移。
- 两处校正按钮均采用透明底、细描边圆形与环形箭头矢量图标，延后为回退、提前为前进；按参考样式中心显示小号 `5`，实际步长仍为 0.5 秒，不使用纯文字加减按钮。悬停提示与无障碍名称保留准确的提前／延后 0.5 秒说明，图标随控件状态与高对比系统色变化。
- 播放器详情只呈现歌词、逐字高亮、手动预览及“播放此处”；不提供歌词工具齿轮或刷新、来源选择、导入／移除本地歌词浮层。本地歌词、来源选择与持久展示契约保持不变。
- 详情文字跟随 Windows 系统字体并使用 `Display + Auto`；歌词在固定、裁剪的视口内使用 `Grayscale`，视口以实际高度设置绝对坐标渐隐，中央 80% 完全不透明，仅上下各 10% 衰减至边缘。遮罩不挂在滚动内容上，不随首末行、留白或滚动 extent 移动；预览框与按钮不参与渐隐。遮罩需要中间透明合成面，不能假定文字下方是不透明像素并强制 ClearType；普通标题、元数据和底栏继承 Auto。无需 Ideal，歌词宽度与原生 Display 排版、DPI 共同计算。
- 首尾留白属于首尾真实歌词行的滚动范围，不作为 `ItemsPresenter` 外边距占用视口；不插入占位歌词，也不关闭虚拟化。自动跟随以实际行中心和完整视口的固定 50% 计算阅读位置，暂停／恢复不改变锚点、留白或文字度量；相同行目标不会因持续进度或 `CanConfirmLyricPreview` 通知重启动画。换行、集合变更、播放 occurrence 与视口几何变化才使目标失效。自动回归一次定位原生像素 offset，然后用 ItemsPresenter 的 WPF 平移过渡，位移不超过原生缓存的一页；远目标只实现目标附近的容器，不先跳到目标再退回逐帧滚动。首句在前奏就居中但不提前高亮；首尾留白扣除半行实际高度。手动滚动即显固定中部完整圆角框，无横线和重复正文，停止后将原正文／译文平滑吸附入框，吸附不 seek、不重启四秒计时。手动输入保持四秒跟随暂停，超时没有新媒体 tick 也恢复；确认预览仍走现有 seek／resume 链。
- 首尾身份由当前 `Lyrics` 集合派生为 `FirstLyric`／`LastLyric`，集合增删、重排、替换与重置通知受影响的边界；行边距只按实际条目引用比较，不把 `AlternationIndex` 当完整列表行号，也不复制歌词状态。长列表验证检查实际实现数量、容器回收、首尾往返与换歌后边界。
- 全屏内容顶部预留 88 DIP，右侧标题另留 18 DIP；唱片与唱臂作为同一画布同比缩放，最大呈现高度 560 DIP，不放大源画布。歌词正文／译文与标题、元数据及标签左对齐；预览框左侧留白中的 24 DIP 圆角小胶囊合并播放图标与 `mm:ss` 时间，正文不因预览显隐移位；窗口缩放换行后按最终行几何校准吸附，点击仍只走既有“播放此处”准入。
- 完整播放器激活时封面和歌词独立启动，Shell 立即呈现基础界面，不等待读取结算；Shell 取消激活 token 撤销该次等待并取消封面准备，歌词读取仍按 `NeedsLyrics` 保留或退订。歌词一次发布完整行快照，并通知完整播放器和桌面当前行／译文消费者。

## Windows 桌面歌词与媒体动作

- `AttachDesktopLyricsOwner(Window, Action? activate)` 显式连接主窗口生命周期及唤醒回调。App 将回调接入 Shell 既有 `RestoreFromTray()`，统一恢复隐藏到托盘、最小化和先前最大化状态，不另建主窗口。音乐能力持有至多一个桌面歌词窗口；底栏“收藏到歌单”右侧的系统字体“桌”按钮与 `ExecuteMediaShortcutAsync(ToggleDesktopLyrics)` 操作相同状态，关闭窗口即时同步普通／完整播放器按钮。
- 底栏保留 80 DIP 总高和窗口居中的播放控制；来源模式与普通方式统一在中央播放模式入口；右侧保留音质、收藏到歌单、“桌”、音量和更多，不另放来源／续播或私人 FM 控件。桌面歌词开关沿用 `Capability.Player.Foreground`、活动强调、禁用及高对比系统色，并将同一前景绑定到“桌”字，避免回退成黑色。全屏歌词右侧把两个 0.5 秒校正按钮和译文按钮分组；译文按钮复用 iOS `PageIcon.translation` 图形及共享 `ShowLyricTranslation` 状态，不发起歌词请求、不 seek 或重置校正。1110／860 宽度下右侧控制保持在实际视口内、进度命中区之外，各控制命中区域不重叠。
- 窗口置顶、不进任务栏，`ShowActivated=false`，并设置 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`、拒绝鼠标激活；歌词面可拖动，八个原生边缘／角命中区域支持独立调整宽高。单行实际可见歌词块在可用区域居中；译文开关关闭或源译文为空时不保留空轨道。单行／双行切换不覆盖用户手动调整的窗口尺寸。传入主窗口只用于定位和 `Closed` 生命周期，不设置 WPF `Owner`，因此主窗口最小化不隐藏桌面歌词，不通过 `Application.Current` 查找所有者。
- 非悬停时背景 alpha=0，只有文字及其细描边；未锁定且可见时用低频光标位置观察整个矩形，悬停显半透明底与工具栏，隐藏、锁定、关闭停止观察。工具栏整体居中，依次为唤醒主程序、歌词延后／提前 0.5s、上一首／播放暂停／下一首、设置、锁定、关闭；桌面校正按钮只保留环形图标和中心 `5`，无圆形描边。菜单和颜色编辑期间保留悬停态；菜单复用 `MeowFilm.ContextMenu/MenuItem`，自定义颜色通过短生命周期可聚焦窗口承载既有 `ColorSelection/ColorPicker`，取消只丢弃草稿。
- 锁定为 layered 歌词 HWND 设置 `WS_EX_TRANSPARENT`，包括有字形像素在内都交由系统命中下层窗口；不是 WPF `IsHitTestVisible=false` 或同线程 `HTTRANSPARENT`。独立不激活的解锁 HWND 常显于居中工具栏原锁定按钮位置，并随移动、尺寸和 DPI 消息以屏幕物理坐标重定位；先确保解锁可用才进入穿透，解锁先恢复主 HWND 输入。关闭释放浮层、捕获、观察与两个 HWND。
- `IsLyrics` 仍只表示完整播放器详情；内部 `NeedsLyrics` 表示模块未停止且任一歌词消费者活跃。选曲、来源变更、元数据平台保存与账号权威操作结算按此需求恢复现有读取。关闭一处不取消另一处；最后一处关闭取消读取并提升请求代次。
- 显式导入本地歌词仍可在未打开歌词消费者时填充行；导入等待期间最后消费者关闭，沿既有 CTS／epoch 屏蔽迟到恢复。本地移除实际结算后仅在仍需歌词时恢复读取，不因移除回复迟到而重新启动已关闭的读取。
- 桌面窗口使用当前播放 occurrence 的校正后 `LyricPositionSeconds` 与 `ActiveLyricIndex`，不跟随详情的手动预览。无媒体显示“未在播放”，等待首行显示“前奏”，空结果显示“暂无歌词”，读取和错误保留真实状态；不建立第二媒体时钟或重复歌词集合。
- 单行显示当前一句原文；双行使用固定上左／下右轨道轮流接唱，另一轨预显下一句，尾句不凭空补行。每句可附小号源译文，最多两句原文与两条附属译文。长句只缩放适配；普通 LRC 用普通色，有真实词时段才复用 `MusicLyricList/MusicLyricWordView` 的原生高亮时钟及缓存字形。固定默认普通浅粉 `#FFB5C5`、逐字浅金 `#FFF2A8`，两色独立设置并保留深色细描边；不跟随封面取色。高对比切换同步歌词、解锁、菜单和颜色编辑窗口，文字改用系统色。
- `ToggleTranslation` 只切换源站已有 `Translation` 的可见性，完整播放器与桌面歌词共享 `ShowLyricTranslation`，初始为 true。关闭译文不更改原始文本、音译、逐字或行时间，不发起翻译服务；无源译文不生成内容。仅单／双行和两配色经 `native-desktop-lyrics` 保存，沿用 revision CAS 和对应权威重读，失败不安装草稿。译文显隐、桌面开关、锁定与窗口位置均不跨重启持久化，普通关闭重开为未锁定。
- 准备关闭立即关闭桌面及解锁 HWND、取消读取并封住新媒体动作；取消关闭准备可使用仍有效的显式主窗口创建新 HWND，恢复当次位置／锁定及解锁入口，不能重新打开已关闭实例。Owner 关闭、Abort 与 Dispose 清除恢复意图并解绑 `Closed`，最终关闭还排空既有读取。
- `ExecuteMediaShortcutAsync(MediaShortcutAction)` 只分派已确认的八项动作：播放／暂停、上一首、下一首、音量 ±5（沿用 0–100 夹取并 `SaveVolumeAsync`）、当前曲本地喜欢及既有同步、桌面歌词开关、源译文显隐。mini 不在动作契约中；未准入／失败走现有 `Status` 通知，不另建后台业务通道。
- 完整播放器实际可见且业务准入时，裸 Space 走同一 `TogglePlaybackAsync`；详情预览路由消费首次、长按重复和配对 KeyUp，阻止焦点按钮默认 Space 点击。文本编辑、密码、可编辑组合框和菜单／Popup 输入不接管，普通页面不增加裸 Space。
- `MusicLyricOffsetTests`、`MusicDesktopLyricSettingsTests`、`MusicDesktopLyricsInteractionTests`、`MusicDesktopLyricsTests` 与 `MusicMediaActionTests`、`MusicPlayerKeyboardTests` 覆盖校正、偏好、主题／译文开关、桌面几何、尺寸与资源边界；跨进程 fixture 用系统 `WindowFromPoint` 核对真实字形／空白命中下层另一进程与独立解锁命中，再以该目标的定向消息核对接收，不注入全局输入，也不将定向消息声称为物理鼠标投递。`ShellWindowStartupSizeTests` 覆盖按 2560×1440 物理像素比例换算、DPI 与最小尺寸。`MusicLyricDisplayTests` 按既有订阅取消／底层共享契约验证结算、旧行不发布和精确请求次数，不以 presentation 任务是否挂起判断物理排空；排空由真实应用 owner 及底层生命周期用例验证。视觉用例通过 `GeneralAppearanceTests.SavePreview` 在配置的 `MEOWFILM_SETTINGS_PREVIEW_ROOT` 输出底栏、桌面单双行及长句的 96／144／192 DPI PNG。合成路由／离屏窗口不是物理键盘、鼠标拖动、多显示器或媒体真实输出验收。

## Windows 逐字呈现接口与生命周期

`MusicPlayerDetailView` 在列表上集中绑定以下 DP，不在每个词上绑定业务进度：

| `MusicLyricList` 输入 | `MusicCapability` 来源 | 语义 |
| --- | --- | --- |
| `Position: double` | `LyricPositionSeconds` | 当前 occurrence 的真实位置减去用户歌词校正，seek 与校正都通过此输入校准 |
| `IsPlaying: bool` | `IsPlaying` | 暂停移除时钟并显示真实样本；恢复重新建立呈现时间基准 |
| `PlaybackRate: double?` | `AcceptedPlaybackRate` | 仅使用当前媒体已接受的倍速；null 或非法值不推算，不使用请求值 `PlaybackRate` 代替 |
| `PresentationKey: string` | `PlaybackPresentationKey` | occurrence 身份变化立即移除旧时钟，再使用同批最新绑定值重建 |

- 模块负责样本及 accepted rate 的身份一致性。列表合并同一 Dispatcher 批次内的输入变化；它不请求播放、不写模块状态，也不测量或声称已验证媒体实际输出倍速。
- 当前 `NativePlayback` 没有 buffer 状态通知。若真实媒体停滞且仍报告 `IsPlaying=true`，没有新 Position 事件本身无法区分缓冲与样本间隔，呈现会继续外推至后续词边界；下一份真实位置、暂停或身份变化会重新校准。此机制没有覆盖真实缓冲时长，不以任意超时推测媒体暂停。
- `MusicLyricWordView` 仅在文本、字体、语言、方向、排版模式或 DPI 变化时用 `FormattedText` 整形，缓存原生 `GlyphRun` 绘制树、尺寸及可动画裁剪几何；颜色／高对比变化只替换已有字形的画刷。WPF `RectAnimation` 直接推进保留的高亮裁剪，无 `CompositionTarget.Rendering`、自建帧定时器或每帧 FormattedText。
- 列表缓存由布局、滚动与回收决定的视口词集合，纯播放样本不重复扫描几何；仅给实际视口内（平移期间为该段动效扫过的范围）、当前时间落在词时段内的词挂高亮动画；完成词、未来词、扫过范围外的缓存页和卸载词不持有高亮动画。列表至多持有一个用于下一个词开始／结束边界的 WPF `Clock`，完成事件交接高亮，即使没有新的媒体样本也能跨词；此边界时钟不绑定属性，没有逐帧属性写入或业务回调。
- 隐藏／卸载停止词与边界时钟并取消排队刷新；再次显示使用最新样本。容器回收、字体与布局变化会重新核对视口；未知倍速、高对比或系统减少动画模式只更新真实样本。独立使用 `MusicLyricWordView.Position` 仍显示有界静态进度并提供完整自动化文本。
- `MusicLyricAnimationTests` 覆盖框架推进、暂停／恢复、seek、accepted rate、身份、隐藏／卸载、边界交接、实际回收、高对比，以及重复居中请求的原定时长和取消；`MusicUiTests` 覆盖持续 200ms 样本下居中、手动／预览四秒恢复及既有首尾／首开非阻塞契约。代码用例的 HWND 与计时断言不替代真实媒体、物理 DPI 或 GPU 帧时间验证。

## 格式与错误

- 本次结果含有效原始逐字时间才启用卡拉 OK；普通 LRC 不生成估算词。完整播放器仍以当前行强调，桌面普通 LRC 始终使用用户普通色，不整句套用逐字高亮色。模式由当前加载结果确定，不存在后台补取逐字后自动升级的流程；不保留 timing 来源标签或旧数据兼容／迁移。
- 增强 LRC 的真实词起点可由下一真实标记或显式句尾衔接；行级末尾可用歌曲总长定位，但最终词没有真实结束边界时 duration 为 0，在真实起点直接完整高亮，直到歌曲结束／切歌，不创建歌曲总长驱动的词动画。
- LRC、YRC、QRC、KRC 解析使用有界字节、深度、行数、时间和 CPU 预算。真实词保留短于 50ms、零时长和负 offset 的区间；只有行的 seek 位置截为非负。
- 编码错误、压缩／加密错误、时间轴错误、身份不匹配和上游格式错误分别明确失败；按协议声明的编码和格式解码。
- 无歌词是正常空结果；权限、协议和业务存储错误不能降级为空结果，附属展示缓存读取失败只视为未命中。
