# 原生歌词应用链契约

## 所有权

- `MusicLyricApplication` 负责一次歌词查询的来源选择、合并请求、缓存、账号代次和关闭。
- `NativeMusicLyrics` 是共同 Node 歌词操作的薄适配，只消费通用原文、翻译和音译；平台请求、解密及字段转换归共同 Node owner，见[音乐平台运行器契约](../runtime/music-platform.md)。
- `MusicLibraryOwner` 拥有本地歌词和歌词／封面平台策略；可恢复歌词及公共图片字节由共享 `MusicPresentationCache` 持久保存，不嵌入歌曲仓库或队列。
- `MusicCapability` 的歌词 presentation 维护当前歌曲的唯一歌词集合／读取、显示行、手动预览、滚动状态和用户操作；完整播放器和桌面歌词都是消费者，不创建第二播放器或查询 owner。

## 当前查询顺序

1. 取用当前歌曲已有的真实平台来源定位。
2. 若当前歌曲有明确本地歌词关联，读取并解析本地内容。
3. 否则按当前歌词平台策略查询启用平台；每个请求使用精确平台 id，不按标题猜录音。
4. `wy` 官方结果为空，或当前录音属于 `kw`、`mg` 时，从脚本 owner 读取实际启用安装，按安装顺序逐个尝试同平台歌词能力；`tx`、`kg` 始终只用官方协议。
5. 返回结果统一转换为原文、翻译、音译、行时间和可选逐字时间轴。

显式来源只查询该来源。自动查询沿现有启用平台策略和已登记来源取用，不复验返回的录音身份，也不因缺少未使用资料提前要求账号；真实认证失败及当前操作代次隔离仍有效。

`music.lyrics.lookup` 消费必填 `song` 和可选 `sourceKey`；脚本安装由应用编排读取，不由调用方指定。读取安装列表和详情不启动脚本；只有实际歌词请求按需激活当前待尝试的安装。已知不提供对应歌词能力的安装直接跳过，空结果或 `CAPABILITY_UNAVAILABLE` 才继续下一项，取消、权限、存储和协议错误保留失败语义。

## 缓存与代次

- 官方成功查询按实际请求材料及平台代次缓存；空结果和错误不缓存，不保存或比较返回的身份回显。
- 同一身份的并发订阅者共享一个底层 flight，但各自可取消；最后一个订阅者离开也不取消已派发的底层读取；服务继续完成，官方结果填充现有录音缓存；脚本歌词只合并同安装/代次/录音的在途调用，不新增内容缓存，也不在已退出页面继续尝试下一安装。关闭/账号或策略失效仍取消并排空。
- presentation 订阅取消即可结算且不能发布迟到行；这不代表底层读取已经结束。同录音的新订阅可复用仍在途的官方读取。脚本停用或内容更新则由应用 owner 提升查询代次，新代次可独立发起有效读取；旧 presentation 不因旧物理请求尚未结束而保持挂起。
- 脚本 owner 的新歌词读取和播放取消不终止其他已准入歌词；脚本源修改、授权失效或服务关闭仍围住并终止全部相关读取。
- 缓存数量、字节数和 TTL 有界，读取不续期。
- 账号、歌词平台策略、脚本源集合、歌曲或录音变化使所属读取失效；旧结果不能进入新缓存或当前页面。局部歌词或策略失效只退休歌词自己的请求、缓存和呈现，不撤销共享平台会话或无关读取；真正账号撤销仍由账号及共同 client owner 执行。源变更由应用 owner 失效查询，presentation 同时取消旧请求并将源变更 revision 纳入恢复去重身份。
- 关闭等待底层查询实际结束，不通过定时延迟或额外刷新掩盖未结算请求。

## 持久展示与本地歌词

- `music.lyrics.display.get/save` 使用 `MusicPresentationCache`：展示歌词由 `LyricsCacheStore` 按永久 songId 保存在缓存库 `meowfilm-cache.sqlite3` 的共享强类型 SQLite 表 `cached_music_lyrics` / `cached_music_lyric_lines` / `cached_music_lyric_words` 并记录真实 sourceKey，图片按完整资源 URL 在 `resources-v1/music-images`（缓存库索引表 `cached_images`）保存一份原网络字节，不按歌曲保存解码封面副本。两类资源共用 128 MiB／30 天预算，实际播放才续期；没有请求头、凭据、文件路径或脚本授权。歌词只读取该歌曲的资源，在业务库锁外进行；回锁后核对期间完成的歌词保存，必要时只重读该歌曲，再处理当前歌词和元数据策略。读取失败或不可解码视为未命中。保存等待该资源实际写入，不排队整缓存快照；磁盘失败不进入业务 CAS／pending，关闭实际排空读写。定向清图片不删除歌词。
- `music.lyrics.local.get/save/remove` 使用 `native-local-lyrics` schema 1 当前格式，按永久 songId 保存 contentHash 与通用歌词行；写入在当前歌曲和操作归属下提交。
- 手工本地歌词属于业务数据：缺失区域表示没有数据；所选错误身份或损坏内容明确失败并保留原始字节，未消费字段不拒绝其他业务动作。展示缓存不参与整库解码和业务提交；歌词展示保存只投影真实时间／文本／逐词字段，未使用的 URL、Cookie 等输入不进入缓存。
- 已保存展示只用于当前页面快速恢复；明确刷新仍执行当前准入查询，旧快照不能冒充刷新成功。

## 播放与交互

- 当前媒体的低频真实位置驱动行选择并校准逐字高亮，不为每帧创建业务通知。`MusicLyricList` 是歌词视口的呈现 owner，保留WinUI `ListView` 的像素滚动和回收虚拟化。
- 滚轮／方向和翻页键浏览只预览视口中线命中或最近的真实歌词，播放 tick 不覆盖预览；只有中线的“播放此处”才提交一次 seek，原暂停时沿用恢复播放语义。正文没有选句行为或逐行播放按钮。连续滚轮累计未完成的目标距离。
- 选曲、换源会失效旧歌词读取并取消手动预览；关闭详情、隐藏到托盘或卸载取消其预览及恢复计时，重新显示直接跟随当前行，只有完整播放器和桌面歌词均关闭才退订共享读取。旧手势或迟到回复不能操作／发布到新媒体。
- 暂停、播放、跳转和恢复均绑定当前播放 occurrence，不能仅按 song id 判断。
- 完整播放器右侧和桌面工具栏的歌词校正共用 `MusicLyricsController.LyricOffsetSeconds`：`+0.5s` 延后、`-0.5s` 提前，`LyricPositionSeconds = PositionSeconds - LyricOffsetSeconds` 同时用于活动行和真实逐字呈现，不 seek 音频、不重写源时间。预览时间和确认 seek 反向换算为 `row.Time + offset` 并按媒体可用范围夹取；呈现时钟本身可为负，不截断真实词的进度。校正属于当前播放曲目／录音及歌词来源的会话状态；切歌、换录音、换歌词来源或更换本地歌词归零，音质切换、暂停和歌词视图重开不清零，不永久记录每首歌偏移。
- 两处校正按钮均采用透明底、细描边圆形与环形箭头矢量图标，延后为回退、提前为前进；按参考样式中心显示小号 `5`，实际步长仍为 0.5 秒，不使用纯文字加减按钮。悬停提示与无障碍名称保留准确的提前／延后 0.5 秒说明，图标随控件状态与高对比系统色变化。
- 播放器详情只呈现歌词、逐字高亮、手动预览及“播放此处”；不提供歌词工具齿轮或刷新、来源选择、导入／移除本地歌词浮层。本地歌词、来源选择与持久展示契约保持不变。
- 详情文字跟随 Windows 系统字体并统一使用常规字体与 WinUI 原生文字排版；全屏歌词的普通／逐字、译文／音译及加载／空态文字沿用自动渲染，不再局部强制灰度，也不保证消除所有像素台阶。歌词文字直接绘制，不经过整块透明度遮罩。固定、裁剪的视口通过独立同背景投影覆层实现上下各 10% 的边缘渐隐，中央 80% 不遮盖文字；渐隐使用视口本地 DIP 坐标，不随首末行、留白或滚动 extent 移动，预览框与按钮不参与。歌词宽度与 WinUI 原生排版、DPI 共同计算，不强制 ClearType 穿透透明表面。
- 首尾留白属于首尾真实歌词行的滚动范围，不作为 `ItemsPresenter` 外边距占用视口；不插入占位歌词，也不关闭虚拟化。自动跟随以实际行中心和完整视口的固定 50% 计算阅读位置，暂停／恢复不改变锚点、留白或文字度量；相同行目标不会因持续进度或 `CanConfirmLyricPreview` 通知重启动画。换行、集合变更、播放 occurrence 与视口几何变化才使目标失效。自动与手动滚动由 WinUI `ScrollViewer.ChangeView` 执行，以非中间态 `ViewChanged` 确认结束，再按实际歌词行做居中修正；虚拟化期间 extent／锚点变化可能调整最终 offset，不能等待旧绝对 offset 相等才结算。取消清除旧完成回调，连续请求只保留当前目标的完成权。首句在前奏就居中但不提前高亮；首尾留白扣除半行实际高度。手动滚动即显固定中部完整圆角框，无横线和重复正文，停止后将原正文／译文平滑吸附入框，吸附不 seek、不重启四秒计时。手动输入保持四秒跟随暂停，超时没有新媒体 tick 也恢复；确认预览仍走现有 seek／resume 链。
- 首尾身份由当前 `Lyrics` 集合派生为 `FirstLyric`／`LastLyric`，集合增删、重排、替换与重置通知受影响的边界；行边距只按实际条目引用比较，不把 `AlternationIndex` 当完整列表行号，也不复制歌词状态。长列表验证检查实际实现数量、容器回收、首尾往返与换歌后边界。
- 全屏内容顶部预留 88 DIP，右侧标题另留 18 DIP；唱片与唱臂作为同一画布同比缩放，最大呈现高度 560 DIP，不放大源画布。歌词正文／译文与标题、元数据及标签左对齐；预览框左侧留白中的 24 DIP 圆角小胶囊合并播放图标与 `mm:ss` 时间，正文不因预览显隐移位；窗口缩放换行后按最终行几何校准吸附，点击仍只走既有“播放此处”准入。
- 完整播放器激活时封面和歌词独立启动，Shell 立即呈现基础界面，不等待读取结算；Shell 取消激活 token 撤销该次等待并取消封面准备，歌词读取仍按 `NeedsLyrics` 保留或退订。歌词一次发布完整行快照，并通知完整播放器和桌面当前行／译文消费者。

## Windows 桌面歌词与媒体动作

- `AttachDesktopLyricsOwner(Window, Action? activate)` 显式连接主窗口生命周期及唤醒回调。App 将回调接入 Shell 既有 `RestoreFromTray()`，统一恢复隐藏到托盘、最小化和先前最大化状态，不另建主窗口。音乐能力持有至多一个桌面歌词窗口；底栏“收藏到歌单”右侧的系统字体“桌”按钮与 `ExecuteMediaShortcutAsync(ToggleDesktopLyrics)` 操作相同状态，关闭窗口即时同步普通／完整播放器按钮。
- 底栏保留 80 DIP 总高和窗口居中的播放控制；来源模式与普通方式统一在中央播放模式入口；右侧保留音质、收藏到歌单、“桌”、音量和更多，不另放来源／续播或私人 FM 控件。桌面歌词开关沿用 `Capability.Player.Foreground`、活动强调、禁用及高对比系统色，并将同一前景绑定到“桌”字，避免回退成黑色。全屏歌词右侧把两个 0.5 秒校正按钮和译文按钮分组；译文按钮复用 iOS `PageIcon.translation` 图形及共享 `ShowLyricTranslation` 状态，不发起歌词请求、不 seek 或重置校正。1110／860 宽度下右侧控制保持在实际视口内、进度命中区之外，各控制命中区域不重叠。
- 窗口置顶、不进任务栏，并设置 `WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW`、拒绝鼠标激活；歌词面可拖动，八个原生边缘／角命中区域支持独立调整宽高。窗口最小宽度由完整9按钮工具栏及边距确定；最小高度容纳工具栏、当前行轨道与真实源译文，双行模式容纳两条轨道，不允许缩到裁切歌词。切换样式只在当前尺寸小于新样式内容最小值时增高，优先保留底部位置，不因后续较短布局或无译文反复缩放。单行实际可见歌词块在可用区域居中；译文开关关闭或源译文为空时不保留空轨道。传入主窗口只用于首次默认定位和 `Closed` 生命周期，不设置主窗口 owner 关系，因此主窗口最小化不隐藏桌面歌词，不通过 `Application.Current` 查找所有者。
- 非悬停时背景 alpha=0，只有文字及其圆角矢量描边；未锁定且可见时悬停即显半透明底与工具栏，隐藏、锁定、关闭停止观察。工具栏整体居中，依次为唤醒主程序、歌词延后／提前 0.5s、上一首／播放暂停／下一首、设置、锁定、关闭；桌面校正按钮只保留环形图标和中心 `5`，无圆形描边。菜单和颜色编辑期间保留悬停态；菜单复用 `MeowFilm.ContextMenu/MenuItem`，自定义颜色通过短生命周期可聚焦窗口承载既有 `ColorSelection/ColorPicker`，取消只丢弃草稿。
- 桌面歌词窗口禁用 DWM 非客户区边框渲染与圆角（`DWMNCRP_DISABLED`／`DWMWA_COLOR_NONE`／`DWMWCP_DONOTROUND`），不使用 GDI `SetWindowRgn` 裁切窗口区域，避免切句触发矩形黑框闪烁或锯齿白边。窗口通过共享 `NativeBorderlessChildHost` 将隐藏标题栏子 HWND 归零，并对内容桥接子窗口安装 `WM_NCHITTEST` 子类化：未锁定时工具栏按钮保持 `HTCLIENT` 交互，8 个边缘／角走原生缩放命中码，其余歌词区域直接返回 `HTCAPTION` 由系统原生拖动，并屏蔽 `WM_NCLBUTTONDBLCLK` 防止双击最大化；无标题窗口通过 `WM_NCCALCSIZE` 保持全客户区。
- 锁定为 layered 歌词 HWND 设置 `WS_EX_TRANSPARENT`，包括有字形像素在内都交由系统命中下层窗口；不通过 XAML `IsHitTestVisible=false` 或同线程 `HTTRANSPARENT` 模拟穿透。独立不激活的解锁 HWND 常显于居中工具栏原锁定按钮位置，并随移动、尺寸和 DPI 消息以屏幕物理坐标重定位；先确保解锁可用才进入穿透。解锁恢复主 HWND 输入，关闭独立解锁窗口，再以 `HWND_TOPMOST | SWP_NOACTIVATE` 恢复歌词窗口在置顶窗口中的次序，不抢焦点。关闭释放浮层、捕获、观察与两个 HWND。
- `IsLyrics` 仍只表示完整播放器详情；内部 `NeedsLyrics` 表示模块未停止且任一歌词消费者活跃。选曲、来源变更、元数据平台保存与账号权威操作结算按此需求恢复现有读取。关闭一处不取消另一处；最后一处关闭取消读取并提升请求代次。
- 显式导入本地歌词仍可在未打开歌词消费者时填充行；导入等待期间最后消费者关闭，沿既有 CTS／epoch 屏蔽迟到恢复。本地移除实际结算后仅在仍需歌词时恢复读取，不因移除回复迟到而重新启动已关闭的读取。
- 桌面窗口使用当前播放 occurrence 的校正后 `LyricPositionSeconds` 与 `ActiveLyricIndex`，不跟随详情的手动预览。无媒体显示“未在播放”，等待首行显示“前奏”，空结果显示“暂无歌词”，读取和错误保留真实状态；不建立第二媒体时钟或重复歌词集合。
- 单行显示当前一句原文；双行使用固定上左／下右轨道轮流接唱，另一轨预显下一句，尾句不凭空补行。每句可附小号源译文，最多两句原文与两条附属译文。长句按可用宽度直接缩放 DirectWrite 字号按 1:1 DPI 重排，不用 `Viewbox` 拉伸位图；普通 LRC 用普通色，有真实词时段才按行内词区段驱动 GPU 逐字高亮。固定默认普通浅粉 `#FFB5C5`、逐字浅金 `#FFF2A8`，两色独立设置并保留深色圆角外描边；不跟随封面取色。高对比切换同步歌词、解锁、菜单和颜色编辑窗口，文字改用系统色。
- `ToggleTranslation` 只切换源站已有 `Translation` 的可见性，完整播放器与桌面歌词共享 `ShowLyricTranslation`，初始为 true。关闭译文不更改原始文本、音译、逐字或行时间，不发起翻译服务；无源译文不生成内容。单／双行、两配色及窗口几何经 `native-desktop-lyrics` 保存，沿用 revision CAS 和权威重读；几何保存在可选 `geometry` 子对象中，monitor 为显示器设备名，x/y 为相对该显示器工作区左上角的 DIP 偏移，width/height 为 DIP。旧数据没有几何时仍用默认尺寸与首次 anchor；存储的显示器已断开时恢复到主显示器工作区。屏幕边界变化使位置不可见时只做必要定位校正；超宽时将居中工具栏对齐到工作区，超高时保持工具栏贴近工作区上缘，不强制缩小用户尺寸。几何保存不覆盖布局／颜色，反向也然。译文显隐、桌面开关和锁定不跨重启持久化，普通关闭重开为未锁定。
- 用户移动／缩放手势结束后提交最后几何，不逐帧写存储；普通关闭立即退役桌面歌词消费者、取消最后消费者的读取，切换动作等待最终几何写入及HWND关闭，关闭等待期的再次打开意图在旧窗口释放后接续。几何在手势结束时提交，不依赖应用退出保存。进程内退役补交已捕获几何并关闭桌面及解锁HWND，清除再次打开意图并解绑 `Closed`；正常整进程退出由系统释放窗口。
- `ExecuteMediaShortcutAsync(MediaShortcutAction)` 只分派已确认的八项动作：播放／暂停、上一首、下一首、音量 ±5（沿用 0–100 夹取并 `SaveVolumeAsync`）、当前曲本地喜欢及既有同步、桌面歌词开关、源译文显隐。mini 不在动作契约中；未准入／失败走现有 `Status` 通知，不另建后台业务通道。
- 完整播放器实际可见且业务准入时，裸 Space 走同一 `TogglePlaybackAsync`；详情预览路由消费首次、长按重复和配对 KeyUp，阻止焦点按钮默认 Space 点击。文本编辑、密码、可编辑组合框和菜单／Popup 输入不接管，普通页面不增加裸 Space。
- 校正、偏好、主题／译文开关、桌面几何、尺寸、底栏与桌面歌词视觉状态、订阅取消与资源边界统一通过正常构建产物的 `--debug` 模式实跑核对（共同协议见[跨端 Debug 模式与调试接口](../common/debug-mode.md)，Windows 端实现见[Debug 模式实现说明](debug-mode.md)），借助 `/debug/v1/ui/state`、`/debug/v1/ui/content`、`/debug/v1/ui/action`（含 `desktop_lyrics` 控制）、`/debug/v1/ui/screenshot?window=desktop-lyrics` 及 `music-playback` / `music-library` 分类日志验证真实运行表现；不再保留或使用单元测试、跨进程 UI Automation 夹具或离屏预览导出测试。`--debug` 语义动作与窗口截图不替代物理键盘、鼠标拖动、多显示器或媒体真实输出验收。

## Windows 逐字呈现接口与生命周期

`MusicPlayerDetailView` 在列表上集中绑定以下 DP，不在每个词上绑定业务进度：

| `MusicLyricList` 输入 | 控制器来源 | 语义 |
| --- | --- | --- |
| `Position: double` | `MusicLyricsController.LyricPositionSeconds` | 当前 occurrence 的真实位置减去用户歌词校正，seek 与校正都通过此输入校准 |
| `IsPlaying: bool` | `MusicPlaybackController.IsPlaying` | 暂停移除时钟并显示真实样本；恢复重新建立呈现时间基准 |
| `PlaybackRate: double?` | `MusicPlaybackController.AcceptedPlaybackRate` | 仅使用当前媒体已接受的倍速；null 或非法值不推算，不使用请求值 `PlaybackRate` 代替 |
| `PresentationKey: string` | `MusicPlaybackController.PlaybackPresentationKey` | occurrence 身份变化立即移除旧时钟，再使用同批最新绑定值重建 |

- 模块负责样本及 accepted rate 的身份一致性。列表合并同一 Dispatcher 批次内的输入变化；它不请求播放、不写模块状态，也不测量或声称已验证媒体实际输出倍速。
- 音乐 `NativeAudioPlayback` 的实际播放时钟会扣除缓冲不足时补入的静音，但未向歌词层发布单独 buffer 状态。若真实媒体停滞且仍报告 `IsPlaying=true`，没有新 Position 事件本身无法区分缓冲与样本间隔，呈现会继续外推至后续词边界；下一份真实位置、暂停或身份变化会重新校准。此机制没有覆盖真实缓冲时长，不以任意超时推测媒体暂停。
- `MusicLyricWordView`（完整播放器歌词页）保留 WinUI `TextBlock` 的原生文字整形与布局，普通色和高亮色分别使用互补 Composition `InsetClip`（普通层裁左、高亮层裁右，RTL 互换），避免高亮边缘透出底色杂边；测量在原生文字布局后通过其自动 `Run` 的文本边界补回 `TextBlock.DesiredSize` 不包含的真实尾空格 advance，保留原文、RTL 及纯空格词，不给中文添加人工间距。高亮与普通裁剪由同一 `timeline` `ExpressionAnimation` 驱动，不逐帧写业务状态。文本、字体与尺寸变化校准当前呈现；普通颜色变化保留正在运行的高亮时钟，高对比或减少动画则遵循静态真实样本。词的完整文本同时作为自动化名称。
- 详情歌词行使用共享 `MeowFilm.ContentListItem` 作为无交互容器，只承载文字，不叠加原生列表的悬停或选中面；当前行与预览仍由歌词呈现 owner 管理。
- 桌面歌词（`MusicDesktopLyricLineView` 与 `MusicDesktopLyricTextView`）共用 Win2D `MusicDesktopLyricRenderer`：以单一 `CanvasTextLayout` + `CanvasGeometry.CreateText` 在 GPU 直接绘制整行实心圆角外描边（`DrawGeometry` + `FillGeometry`），再以灰度抗锯齿 `DrawTextLayout` 绘制同坐标填充层，避免 `RenderTargetBitmap` 回读、空心描边缝隙、词间描边叠压及透明底 ClearType 白边。逐字行使用单一 `CompositionPropertySet` + 分段线性 `ScalarKeyFrameAnimation` 驱动普通层与高亮层的互补 `InsetClip`，随播放位置、倍速与 seek 校准，不逐帧重绘位图。窗口根据行控件实际 `Row`／译文依赖属性变化计算内容边界，布局设置单独更新轨道，不保存第二份呈现元组。
- 列表缓存由布局、滚动与回收决定的视口词集合，纯播放样本不重复扫描几何；仅给实际视口内（平移期间为该段动效扫过的范围）、当前时间落在词时段内的词挂高亮动画；完成词、未来词、扫过范围外的缓存页和卸载词不持有高亮动画。列表至多持有一个用于下一个词开始／结束边界的 单次 `DispatcherQueueTimer`，到期后交接高亮，即使没有新的媒体样本也能跨词；此边界时钟不绑定属性，没有逐帧属性写入或业务回调。
- 隐藏／卸载停止词与边界时钟并取消排队刷新；再次显示使用最新样本。容器回收、字体与布局变化会重新核对视口；未知倍速、高对比或系统减少动画模式只更新真实样本。独立使用 `MusicLyricWordView.Position` 仍显示有界静态进度并提供完整自动化文本。
- 逐字推进、暂停／恢复、seek、accepted rate、身份交接、隐藏／卸载、容器回收、高对比以及手动预览四秒恢复均通过完整构建产物的 `--debug` 模式实跑结合日志与截图核对，不替代真实媒体、物理 DPI 或 GPU 帧时间验证。

## 格式与错误

- 本次结果含有效原始逐字时间才启用卡拉 OK；普通 LRC 不生成估算词。完整播放器仍以当前行强调，桌面普通 LRC 始终使用用户普通色，不整句套用逐字高亮色。模式由当前加载结果确定，不存在后台补取逐字后自动升级的流程；不保留 timing 来源标签或旧数据兼容／迁移。
- 增强 LRC 的真实词起点可由下一真实标记或显式句尾衔接；行级末尾可用歌曲总长定位，但最终词没有真实结束边界时 duration 为 0，在真实起点直接完整高亮，直到歌曲结束／切歌，不创建歌曲总长驱动的词动画。
- LRC、YRC、QRC、KRC 解析使用有界字节、深度、行数、时间和 CPU 预算。真实词保留短于 50ms、零时长和负 offset 的区间；只有行的 seek 位置截为非负。
- 上游编码、压缩／解密和必要字段转换失败由共同 Node 分类，原生只处理实际呈现时序及当前操作归属；不附加平台录音身份比较或返回回显门禁。
- 无歌词是正常空结果；权限、协议和业务存储错误不能降级为空结果，附属展示缓存读取失败只视为未命中。
