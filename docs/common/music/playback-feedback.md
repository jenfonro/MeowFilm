# 真实播放反馈

本契约定义双端播放事实、计量、来源归属和可靠性。来源会话见[播放来源与自动续播](playback-sessions.md)，录音资格见[智能播放](smart-playback.md)。平台协议、存储格式与系统生命周期分别见 [iOS 音乐能力](../../ios/music.md)和 [Windows 播放反馈](../../windows/music-playback-feedback.md)。

## 播放事实与平台准入

只有当前播放器实际开始的媒体才形成听音事实。读取队列、解析 URL、预加载、恢复位置以及接受播放命令都不是实际开播。共用 owner 负责一遍听音的身份、连续媒体观察和结束，再向各平台独立分发。

同一遍可反馈给多个具有可靠录音映射、已启用开关和有效账号的平台，音频交付方不独占反馈。各平台自行处理准入、协议、确认与失败；一个平台失败不能阻塞音频或其他平台。现有默认开关不变；本轮完善网易，保留 QQ／酷狗现有能力和各端安全边界。

资格成立前的区间不倒补。适配器的开始准入不统一等同于远端 ACK；网易本地持久准入与文件确认分离，等待上传回执不抹掉已具资格的真实听音。

## 计量与一遍身份

- 分别累计实际听音墙钟秒与媒体前进秒；使用单调时钟和当前媒体状态，倍速采用实际接受的速率。暂停、缓冲、seek、非法样本和资源切换间隙不补时。
- 未知曲长不阻断不要求曲长的平台。自然结束保留真实累计及结束事实，不用界面曲长或位置补齐整首。
- 一遍绑定队列 occurrence 和可信录音。成功换 URL、脚本、音质或交付方不拆遍；准备失败保留旧遍，准备期间仍在播放的旧音频可以继续计量。真正下一曲或重播建立新遍。
- 错源立即失效错误音频的计量并停止输出；替代录音不能继承旧音频的听音。
- 结束冻结原账号、录音、时间、来源、累计和原因。迟到开始或网络结果只能作用于原遍；撤销后的结果不能补发或污染新遍。

## 来源归属

来源随实际入队 occurrence 固定，映射补全和换音源不把当前浏览页面覆盖到旧遍。搜索保留真实关键词；远端集合 ID 必须属于目标平台，外平台集合不能冒充网易集合。

FM、相似、心动和推荐保留本次来源会话的模式、场景、种子、逐曲 `alg` 及上游真实来源。首次准入校验来源 proof；已经准入的来源随后退休，不抹去本遍冻结的结束事实。账号或设置撤销仍立即生效。无证据的 wire 字段省略，不伪造页面 refer、设备或推荐算法。

## 网易传输与有限待发

网易使用官方原生 `_plv`／`_pld` 的 NCBLv3＋Zstd 文件通道，不叠发旧 Weblog。事件保留原始发生时间；结束的 `time` 表示媒体累计秒，`realtime` 表示实际听音秒。具体序列化、来源映射、精确文件 ACK 和受控实测边界由端侧文档说明。

待发只保存必要事实、原始时间和原账号归属，不保存 Cookie 或 token。每遍先确认开始，再发送结束；开始结果未知时不能发送孤立结束。首字节可发送前持久化在途标记，缺少上游幂等证据时不重放未知结果或崩溃遗留的在途事件。只有能证明尚未发送且原授权仍有效的数据才恢复发送。

正常退出排空已准入的本地事实及防重标记，保留安全未发，不等待网络 ACK。关闭上报、登出或换账号取消并清除相应待发，不能转交新账号。启动、账号就绪及真实事件触发有界处理，不运行无限重试或业务轮询。保留期与容量是本地资源／隐私边界，不是听音计次阈值。

## 验证边界

验收覆盖实际播放到事件、来源与账号、序列化、传输、确认、撤销和恢复的完整链路。官方 APK 静态证据、脱敏真实包、合成组件测试、原生消费者运行和平台构建分别记录。文件被确认不证明排行次数或推荐模型已生效；不等待排行榜刷新、不重复上报试探效果。
