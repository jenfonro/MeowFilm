# 播放来源、队列与自动续播

本契约定义双端音乐入口、队列来源、循环和续播的业务语义；歌曲资料与音源选择另见[智能播放](smart-playback.md)，播放计量与上报见[真实播放反馈](playback-feedback.md)。端侧类型、存储和界面差异分别由对应端文档说明。

## 统一播放方式

- 播放方式通过同一个入口选择：当前来源的心动、漫游、相似或推荐模式按队列顺序播放并续取；列表循环、单曲循环、随机播放只播放现有队列。选择任意普通方式立即关闭续取，即使循环值未变；随机不支持续取。
- 进入或重新选择特殊模式，由播放业务 owner 一致设置列表顺序与续播开启，UI 不分两步拼接状态。循环的底层状态仍只有列表、单曲、随机；checkpoint 不保存或回滚循环设置。
- 队列来源区分普通列表、本地收藏／歌单、网络歌单、搜索、私人 FM、相似艺人、相似歌曲、推荐、心动。来源由建立队列的播放动作决定，不以当前页面或队列长度猜测。切到普通方式保留来源、种子和返回上下文，不等于退出。
- 播放模式按钮图标与菜单选中项表达实际方式：心动沿用心动元素，漫游／相似使用横向 ∞，推荐使用 sparkles；续播开启只选中特殊项，关闭后只选中普通项。没有独立 ∞ 按钮、续播开关或队列页续播控件。
- 心动菜单依次为“退出心动模式、心动模式、列表循环、单曲循环、随机播放”。漫游、相似没有退出项；推荐只有存在原队列 checkpoint 时提供退出，搜索单曲推荐没有返回项。普通来源的合资格当前曲可从同一入口进入推荐模式。
- Windows 模式菜单在漫游来源增加“切换频道”，相似不提供。菜单不再显示来源标题或“重试取歌”；真实候选、错误重试、未知提交核对保留在原有业务入口。
- iOS 保留全屏播放器顶部私人 FM 频道／场景入口，统一模式菜单不重复频道项。

## 进入与恢复

| 入口 | 队列行为 | 原队列恢复 |
| --- | --- | --- |
| 搜索直接点单曲 | 清空旧队列，仅加入点击曲；播放后异步准备推荐候选 | 无 |
| 私人 FM | 首次替换；同会话切频道先取成功，再追加并播放新批首曲 | 无 |
| 相似艺人／歌曲 | 进入及切换种子均替换队列 | 无 |
| 歌单主动单曲推荐 | 当前曲作为固定种子及首项，随后接推荐 | 有 |
| 首页心动 | 栏目展示曲作为首项，随后接心动结果 | 有 |
| 当前曲进入心动 | 保留当前条目、进度和播放／暂停状态，随后接结果 | 有 |

进入或切频道先取得可用结果再提交；失败保留旧队列及播放。翻页、浏览和打开菜单不改变播放来源，替换播放来源的动作才结束旧会话。

有恢复上下文的推荐／心动退出时，恢复原队列及来源，保留当前实际播放条目、音频实例、进度和暂停状态。例如 `ABC` 从 `B` 进入，播放 `E` 时退出，得到 `ABEC`，不重播 `E`，不带回其余临时推荐项。同一 occurrence 不重复插入，不把同录音的不同 occurrence 合并；空原队列仍保留当前曲。恢复不还原旧循环值。

## 私人 FM 与相似

- 首页私人 FM 恢复本机当前网易账号上次模式／场景，跨重启保存；首次 `DEFAULT`，账号之间不串用，不做跨端同步。
- FM／相似新会话进入对应特殊模式。FM 同会话换频道保留当前播放方式。
- 相似使用真实艺人／歌曲种子，不能冒充私人 FM，也不展示私人 FM 频道选择。
- 每日推荐／风格推荐是当前账号的有限歌曲批次，可采用歌单式列表呈现，但不因此获得普通云歌单身份或收藏资格，也不因“推荐”名称套入 FM。浏览、切分支和编辑风格不改变播放队列；明确播放时使用实际推荐批次与来源身份。

## 推荐候选与插队

- 单曲推荐始终使用最初点击／进入时的固定种子，不改成搜索词、结果第一条、当前推荐曲或插队曲。
- 搜索推荐准备不阻塞种子播放；真实候选列表保留展示。普通方式不自动并入候选，取到候选本身不能打断当前播放或改变播放方式。
- “下一首播放”只插入当前队列，不新建推荐、不改来源。搜索待推荐已有候选或请求仍在途时，都保留原种子与有效请求，用户指定的下一首优先。
- 待推荐尚未激活时，普通尾部追加撤销候选及其请求；这与“下一首播放”不同。推荐激活后插队／追加均不结束推荐。
- 切到普通方式、暂停／恢复和 seek 不撤销推荐来源。普通方式保留候选与种子，但不自动并入或续取；显式点击候选仍可进入已有候选，不因此开启续播，手动下一首只在已有队列中推进。
- 搜索建立的推荐没有进入前队列恢复项；歌单主动推荐有恢复项，但仍调用单曲推荐而非心动接口。

## 自动续取

- 仅特殊模式自动取歌，在实际播放到当前队列尾项时检查，不等尾项结束。`ABC` 播到 `C` 取回 `DE` 后成为 `ABCDE`，不抢当前播放；用户指定插队优先。
- 普通三方式不自动续取，也不自动并入已准备的候选；搜索单曲首次开播仍可异步准备首批预览，但该预览本身不启用续播。关闭后的迟到结果可以保留为候选／缓冲，但不能自动加入队列；选回特殊模式才在真实播放边界继续消费。
- 暂停／恢复、seek、元数据／界面刷新不创造新播放事件。同来源同游标的在途请求不并发重复；旧来源／账号响应不能更新新会话。
- 心动续批固定原始账号、真实喜欢歌单、进入种子 `startMusicId` 与入口类型，`songId` 推进为本次实际尾曲；首次种子的成员校验不施加到可能不属于喜欢列表的推荐尾曲。续取只追加，不重新进入或重建原队列 checkpoint。
- 请求未完成、失败、空结果、全重复或耗尽都不阻塞现有队列。失败不立即忙重试，结束游标不自动重发；已有真实错误恢复入口保留。
- 不保留随机续取抽签，不增加队列上限、冷却或概率设置。

## 平台资格与协议边界

- 本轮使用网易能力。已共享资料中的有效网易身份也可用，不限最初来源；不为显示菜单额外全平台补搜。不具备接口或身份／来源资格时不展示相应模式。
- 仅缺登录而其他资格满足时入口保留，操作时提示登录；按接口真实账号要求判断，不把所有模式一概视为免登录或需登录。
- 心动使用官方入口所属账号的真实网易歌单上下文，不写死通用歌单 ID。本次普通网络歌单样本被上游拒绝，不向其开放心动，但仍可按单曲资格进入推荐。本地收藏中的当前曲具有网易身份时可发起心动，由平台读取当前账号的真实喜欢歌单并核实成员；本地收藏标记本身不是进入依据。
- 首页心动和账号目录读取不依赖歌单同步开关；同步只控制同步行为。展示曲是首页快照的种子，同一账号同一快照重复点击不重选；刷新可以更新，账号切换必须使旧动作失效。卡片资源 ID、本地集合 ID 不作为远端喜欢歌单 ID。
- 首页栏目未给出种子时，在加载该首页快照时读取平台账号喜欢歌曲并确定种子；已有展示种子时不额外选曲。不能把本地融合收藏当作平台收藏成员证明，当前歌曲的心动资格仍需有效平台身份和平台歌单上下文。
- 固定单曲推荐使用已验证的场景推荐分页接口，不伪造搜索上下文；保持种子，消费服务端游标及耗尽状态。接受参数和返回不同结果不等于证明上游算法仅依赖种子。
- 推荐数据平台与实际播放音源脚本不同，不互相冒充；本轮不预建其他数据平台或跨端同步。

## 错误与验证

正常进入、退出、切换、取消和耗尽只通过控件及队列反映，不再有“已进入／已退出”模式横幅、状态块或成功 toast。真实失败／无法进入使用统一错误提醒，旧请求失败不能污染新来源；候选列表和必要入口不能因此删除。

测试从入口动作、公开队列／来源、播放连续性、真实请求参数与异步失效观察上述行为。协议实网、原生行为测试、UI 组件验证、编译和真机听音各自独立，不相互冒充。

## 顺序播放缓存

音乐取源成功后，当前播放只消费一份从起点顺序下载的文件。暂停不停止该下载；seek 只改变读取位置，未缓存位置等待原顺序下载，不发目标 Range、补洞或重启下载。缓冲条对应同一文件的真实连续前缀，只有真实 EOF、完整校验及原子提交成功才显示完整缓存。切歌允许取消未完成下载。

有效完整缓存优先于在线取源，URL 或会员到期不使已有文件失效；会员仅参与取得在线可播放音源，不另设客户端离线许可或命中后二次联网授权。实际资源明确的限制、完整性、账号作用域、用户排除与容量／时效淘汰继续有效。歌词、封面按稳定歌曲身份多曲保留，播放续期和音频淘汰／用户清理协调；单项损坏不删除其他健康内容。缓存仍可淘汰，不是永久下载库。
