# 歌单所有权与订阅关系

本契约区分自己维护的歌曲集合与网络歌单引用；端侧存储、接口和同步实现见 [Windows 曲库](../../windows/music-native-library.md)、[Windows 同步](../../windows/music-library-sync.md)和 [iOS 音乐](../../ios/music.md)。

## 内容所有者

- 自管集合包含本地自建歌单、收藏，以及音乐平台上本人创建且可写的歌单。沿用既有多平台融合、录音去重和歌曲排序；不能用“是否本地创建”判断远端歌单是否属于本人。
- 网络歌单由远端维护内容，本地只保存所属平台、真实歌单 ID、必要展示及订阅关系信息。收藏不为保存引用读取全部成员，不将成员复制成本地曲库内容；每次打开沿真实远端身份读取，失败保留引用而不是变成本地副本。
- 网络引用以平台和远端 ID 去重；同名不同 ID 或不同平台不合并。它不进入自管歌单的同名融合、歌曲补搜、跨平台建单、成员增删或排序。
- 网络详情保留播放、单曲收藏、下一首播放等只读内容动作，不提供修改原歌单名称、成员、顺序或删除原歌单的操作。外层歌单目录排序不在本契约范围。
- 不迁移旧完整成员副本、不猜旧远端 ID、不增加“复制成自有歌单”路径，也不据此清空用户其他数据。

## 收藏与平台同步

- 所属平台的歌单同步关闭时，收藏／取消收藏只管理本地网络引用。
- 同步开启且对应账号授权有效时，只同步该平台的订阅／退订关系，不向其他平台创建副本；取消收藏绝不调用删除远端歌单。
- 网易云、QQ 音乐、酷狗使用各自账号及订阅接口；酷我、咪咕仅提供本地引用，不预建其账号同步能力。
- 首次同步先读取官方目录，再协调已有本地引用；本地空表不是“退订全部”的意图。形成有效基线后，官方外部订阅变化与本地明确意图按先拉取、再融合、再回写处理。
- 未绑定账号时的取消只影响本地，不为以后绑定的账号保留退订意图；已绑定账号关闭同步期间的明确取消仍保留，重新开启后协调。删除后再次收藏是新的本地引用版本，旧操作不能取消新引用。
- 订阅关系复用现有同步协调器、文档所有者、CAS 和持久待确认操作，不新建另一同步定时器。本地保存成功不冒充官方订阅成功。
- 超时或未知写结果先读回核对，不盲目重放；取消、关闭同步、账号切换后的结果不能写入新账号状态或错误平台。

## 自管内容与首页心动

- 自管集合保持既有共同歌曲锚点、录音级去重、手工顺序优先；纯调序不变相增删成员或建单，拖动完成后才保存和同步。QQ 不支持的远端调序不通过删除重加模拟。
- 每个账号首次绑定先将平台收藏合并到本地，不因平台缺项删除本地，也不把未绑定时的本地取消传给新账号；再将本地完整集合中有该平台已确认身份的歌曲同步过去。不同平台的收藏可以互补，不伪造不存在的平台歌曲。
- 新绑定首次带回的歌曲覆盖该曲较早的取消意图，形成新的统一收藏结果；此前关闭同步的账号重新开启后也按新结果保留或补收藏，已经收藏时不重复请求。未被新绑定带回的取消不撤销；已有绑定的日常同步不反复取首次并集，新发生的取消仍生效，空基线也不等于首次绑定。
- 拉取未完整时不回写，仍遵守账号隔离、原子提交和未知结果围栏。
- 首页心动读取当前网易账号真实喜欢歌单，与是否开启同步无关；不以完成曲库同步或建立本地成员副本为前置。展示种子、队列替换与恢复见[播放来源与自动续播](playback-sessions.md)。
- 本地融合收藏中的当前曲须有网易歌曲身份才可发起心动；实际进入仍由平台核实当前账号的喜欢歌单及成员，不能将本地 `favorites` 当作远端歌单 ID 或成员证明。缺少资格或请求失败时保留原队列和播放。

## 验证边界

验证公开收藏／打开／编辑资格、订阅请求、同步读写隔离和失败取消行为。替身协议测试不代表真实账号已发生订阅；没有单独授权不以真实账号写入验证本契约。
