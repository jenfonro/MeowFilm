# 歌曲资料与智能播放

本契约定义搜索、资料复用、自动选源、手动选源和切换的共同语义。端侧接口、存储格式和资源预算分别见 [iOS 音源](../../ios/music-sources.md)、[Windows 选源](../../windows/music-official-selection.md)。

## 歌曲资料

- 每端由稳定音乐业务 owner 维护同一歌曲的录音资料和逐平台搜索证据。搜索、已读取的歌单／收藏资料及播放补搜向它归集，不因入口不同维护互不更新的匹配记录。
- 歌名、歌手归一化只用于索引；版本、时长和平台录音身份仍须兼容。不能将 Live、伴奏或不同录音合成一首。队列 occurrence、收藏成员和页面排序／展示快照不是匹配事实。
- 搜索记录实际平台、查询范围、账号上下文及物理检查时间。缓存命中沿用原时间；旧响应不能覆盖更新证据。精确歌曲查询的未命中可以抑制重复补查，宽泛关键词某页没有该歌曲不能证明平台没有该歌曲。失败和取消不是未命中。
- 歌单批量入队和资料归集不额外联网；只在当前歌曲确实需要候选时补搜。派发范围为歌曲映射与启用来源的平台／音质能力交集。
- 正确映射不按七天删除；只有内容级失败并且相关查询已满七天或没有有效检查时间时，才按需重查。网络故障、读取和正常播放不触发条件重查，也不刷新查询时间。
- 仅收藏及本地歌单成员的派生匹配资料落盘；临时搜索、浏览与队列资料保留在内存。搜索页缓存另负责关键词、页码和排序；音频文件及短期 URL 缓存也不是歌曲元数据。

## 自动与手动选择

- 自动播放从设置首选档开始，沿配置顺序向后跳过禁用项；当前档候选耗尽才降级。每档优先复用有效完整文件、URL 和会话结果。
- 播放器切换音质只作用于当前歌曲，不修改全局设置；锁档不降级。指定结果锁定 provider×平台×录音×音质，刷新链接或故障恢复不能暗换目标。
- 来源页是独立手动入口：启用脚本支持且录音相容的全部音质均可探索、显示、选择和续链，不受自动首选档、音质启用、排序或降级范围裁剪。192k、母带等有效声明不因端侧旧枚举而丢弃。
- 打开来源页只展示已获得结果；加载更多才探索未完成候选，不重发已成功请求。禁用脚本、持久错源、录音不符和授权限制仍先于请求。官方源仍遵守其启用与授权边界。

## 准备、提交与故障

- URL 返回不是切换成功。新媒体必须在独立静音输入完成可播准备、时长和准入检查、位置同步，才能一次提交媒体及新意图；不得先退役健康旧流再尝试回滚。
- 搜索、取链、准备、seek、取消或最终准入失败，只丢弃新候选，健康旧流和已提交意图不变。成功交接继承实时位置、最新暂停意图、倍速和音量；陈旧选择不能覆盖较新的用户操作。
- 若旧流 A 在待切 B 期间自身失败，保留 B 的现有搜索和准备，不重复搜索 B，也不同时启动 A 的恢复。B 成功则接管；B 失败后才按切换前已提交的 A 意图恢复。此时旧流已坏，不能承诺不断音。
- 换歌、停止、撤权和配置失效仍有各自的取消边界，不能以准备成功绕过。准备和查看列表不产生实际播放历史。

## 错源

- 报告“音源不对”立即停止错误输出并保留位置，再持久保存当前歌曲×provider×平台排除，优先缓存寻找同档替代。
- 无替代或保存失败均保持暂停，不回错误输入、不自动跳歌；保存失败如实报告。成功替代继承原暂停意图。
- 排除覆盖该来源全部音质，不随七天、清缓存或脚本更新消失；只能由用户主动恢复，恢复记录本身不开始播放。

## 验证边界

共同语义不要求底层播放器、缓存 TTL、预取和自动音质组内顺序完全相同。定向合成媒体和业务测试、平台增量编译分别提供证据；不能由此推断真实上游可用性、真机听感或全部编解码器已通过。
