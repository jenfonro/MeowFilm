# 设置保存回执与未知结果

本文件是两端已提交设置保存的结算和全局未知结果提示契约。普通读取与动作错误见[平台请求](platform-client-context.md)，本地原子提交和真实远端事务仍由各自 owner 负责。

- 提交前取消可停止操作；真实提交后，关闭页面只撤销页面发布资格，操作继续结算。不能把关页当作回滚、成功或失败，不向失效页面写状态。
- 回执确认为成功才更新提交事实；存储／传输不能确认结果时保留对应 owner 的全局 `COMMIT_UNKNOWN` 提示。未知不当作成功或失败，也不自动重试。
- 提示绑定具体设置与实际账号／存储范围，由稳定 owner 持有，复用现有全局错误呈现；不建立页面重放表或全局事件总线。
- 重开从权威持久状态读取，不沿用乐观值；打开页面、普通读成功、确认提示或无关操作成功均不清除未知结果。
- 同一范围、同一设置的后续明确保存成功，只清除它对应的旧未知提示。其他设置、其他范围及之后的新错误保留；晚旧 unknown 不复活已被后续成功清除的提示，晚旧 success 不清新 unknown。
- 一次流程包含本地设置保存和后续网络动作时，两份真实回执分别结算，不把网络未知冒充本地设置未知。没有未知回执的同步设置 API 不虚构异步事务。

端侧具体接线见 [iOS 音乐](../../ios/music.md#设置保存回执)、[Windows 设置呈现](../../windows/music-settings-presentation.md)。静态接线、组件测试、构建和真实 UI 结果分别记录；核心覆盖为提交后关页、迟到未知、重开读真实值、同项后续成功、范围隔离和不自动重试。
