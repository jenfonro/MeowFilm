# 原生设置存储与运行器通知

本文件规定普通设置的事实来源、离线读写、通知及在线回写边界，不统一界面或平台存储实现。端侧实际接线见 [iOS 存储](../ios/storage.md#影视设置)与 [Windows 原生设置](../windows/native-settings.md)；运行器的可选注入与独立入口见 [Runtime HTTP](../runtime/runtime-bridge.md#原生设置注入)。

## 事实来源与操作边界

- 普通设置由对应原生 owner 直接读取和保存唯一持久值；打开、编辑、保存、关闭后重开不以运行器连接或上游请求成功为前提。读取缺失采用该设置的默认值，不因读取而写空文档；损坏与存储失败不能冒充未配置。
- 保存先校验实际编辑字段；需要合并的文档通过原生事务及内容 CAS 提交。失败不发布成功值、不通知；过期提交不覆盖后来配置，未编辑字段按各自格式保留。原有同步 UserDefaults 偏好不因此新增文档或运行器通知。
- 本地提交成功与运行器应用成功是不同事实。页面不等通知、脚本装载、账号验证、歌词或其他网络工作结束才结算本地保存；后续业务错误沿该业务 owner 报告，不伪装成本地写入回滚。
- 原生拥有可编辑配置，不因此拥有脚本安装、源码、私有卷、执行状态或影视历史／人工匹配／屏蔽。音乐脚本与书源的安装管理、规则执行、扫码、验证、取址、缓存清理及真实同步仍按原业务 owner 执行，离线不可用不等于普通设置不可保存。
- 敏感配置经平台保护存储保存。运行器只取得执行所需的受信读取能力及内存快照，不持久写第二份明文配置；不向外部脚本开放原生文档、密钥或通道。

## 按块通知

| 设置块 | 内容 |
| --- | --- |
| `cat.sources` | 猫源来源意图、启用、聚合端口和网盘映射 |
| `pan.accounts` | 内置网盘账号凭据及记录 revision |
| `tmdb` | TMDB 凭据、基址、语言、地区及成人选项 |
| `douban` | 豆瓣 Cookie、基址及代理 |
| `film.rules` | 影视四组规则配置 |
| `film.preferences` | 智能播放、关键词、排序及 iOS 自动准备偏好 |

上述块由原生设置注入使用；通用、音乐、小说已经独立保存的原生设置不为凑齐通知而改成运行器配置。

- 真实本地提交后，仅异步发送块名，不携带设置值或凭据，不自动重试或建立离线补发队列。
- 未启动、已关闭或已失败时直接丢弃通知，不为保存启动运行器。已进入启动中的当前代次可在该次连接就绪后发送；代次失效则丢弃，不能由后来连接接收旧通知。
- 冷启动在建立业务 owner 前读齐最终配置；活跃通知使对应 owner 重读最新值，由其处理必要装载、取消、缓存失效与资源排空。
- 猫源保存来源改变后按最新意图加载／下载，不等独立“更新”动作。配置保存不冒充安装／ready，迟到工作不能覆盖后保存的来源。

## 在线取得凭据的安全回写

网盘扫码或自动刷新产生的新凭据仍由运行器取得，但通过仅限对应设置块的私密能力 CAS 回写同一原生文档。回写须绑定读取时的内容身份及当前账号代次；手动换号、清除或其他原生修改后，旧登录／刷新不能覆盖新值。真实持久化成功后才报告 confirmed／refreshed，不把网络成功或内存状态当作已保存。

迁移由端侧在业务消费者和运行器启动前单向采用已知旧配置。新原生值优先；退役旧配置须核对输入仍为采用时的内容，并保留混合文档里的真实安装事实及业务资料。不双写、不持续回灌、不在失败时静默回退旧 owner。具体旧路径与保护策略由端侧存储文档说明。
