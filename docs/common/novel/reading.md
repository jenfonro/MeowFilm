# 小说业务与阅读契约

这是 Windows／iOS 小说功能的共同语义与验收目标，不代表仅凭文档即可确认
两端 UI、宿主或构建已通过。平台类型、存储和具体执行结果由端侧说明记录。
来源执行仍使用现有 source-runtime；书源管理／私有数据／图片及 Web 交互
协议由[运行器书源仓库](../../runtime/source-library.md)维护，不另建书源引擎。

## 领域与入口

Windows 在影视之后提供小说、书架；iOS 提供小说主入口，内部首页与书架切换，
历史在书架中。设置提供小说分类。两端使用现有搜索入口，目标为音乐、影视、小说，
结果类别为综合、单曲、歌单、影视、小说；附加类别有稳定领域身份，不共享一个
“非音乐结果”会话。切词、加载更多、离开及返回有独立查询 owner 与有效代次。

小说首页的发现来自启用且允许发现的书源，不用固定假书籍、榜单或计数填空。
继续阅读来自真实历史；无书源、无结果和网络失败是不同状态。来源的一次失败
不撤销其他已成功来源，下一页成功后才推进相应来源页码；重复页面停止该源追加。

首轮不含字典、接口设置、整套备份恢复、网页全屏、批量离线下载、书签、正文搜索、
TTS／有声、护眼滤镜、脚本调试台或书架自定义分组，不展示不可用入口。
单项书源／净化规则导入导出、固定简繁转换属于已实现目标，不受这些排除项影响。

## 身份、书架和历史

- 安装身份由运行器生成，书籍来源定位由安装身份＋源内 bookUrl 组成；目录、章节
  URL 和源变量在所有调用中携带同一本书的上下文。URL 不是全局书籍身份。
- 本地书籍有稳定 bookId。搜索已知书名＋作者可匹配同书；缺作者时只按源内定位
  去重，不能把未知作者结果并入任意同名书。补作者、换源、重新排序不改本地 bookId。
- 共享 `identity` 返回的是匹配键，不是持久化主键。`merge` 保留每个候选的安装、
  URL、作者和元数据；不同源内容不混进一个章节缓存。
- 书架与历史独立：阅读不会自动收藏，只看简介不产生正文历史；移出书架不删历史，
  删除历史不移出书架。置顶、本地检索和从历史加书架分别操作自己的记录。
- 业务通过原生原子文档 owner 保存。运行器暂不可用不能阻止查看或修改本地书架、
  历史和阅读设置；不能在原生保存源定义来绕过运行器仓库。保存失败必须明确报告，
  不覆盖损坏数据，不把内存更新当落盘成功。

## 正文与全局净化

来源负责网络与规则提取、分页连接、源内替换、章节元信息和有序文字／图片块。
客户端保留原始结果，调用运行器依次完成用户净化、显示简繁转换，再进行原生排版。
源内 `replaceRegex` 与用户净化规则不是同一个 owner，不能用其中一个冒充另一个。

用户规则沿用 Reader 的管理字段，定义见[共享纯规则资源](../../../packages/novel-rules/README.md)。
正则、捕获组与替换语义由同一 JavaScript 程序解释，不能在两端分别改为 .NET／Swift
正则。scope／excludeScope 是书名或来源 URL 列表，排除优先；规则按 order 稳定排序，
标题与正文开关独立，空 replacement 能删除内容。纯规则不修改图片地址或鉴权信息。

身份归并、章节匹配、规则校验与显示变换统一通过 source 的 `rules.process`，
计算依赖运行器可用；净化配置仍由原生文档 owner 保存，不在运行器建立第二份仓库。
每个启用规则使用其 timeoutMillisecond（缺省 3000ms）在运行器独立的 QuickJS
工作线程执行；截止与取消由 native interrupt 实际中断后确认，不能只停止 UI 等待。
每次规则变换只有整体成功才提交，失败时原始正文仍保留且错误可见。引擎既有
内存／栈预算属于脚本资源边界，不变为产品书籍／来源／结果数量限制。

固定简繁表仅转换显示文字，不能当作自定义字典实现。净化或转换改变内容后，
重新布局时必须重新核对锚点，不将旧显示页号套在新正文上。

## 阅读位置与换源

位置包含 `chapterUrl, chapterTitle, chapterIndex, blockIndex, utf16Offset, ratio`。
UTF-16 偏移使 Swift／C# 能定位同一文本范围；不得切断代理对或组合字形。
原生布局返回页号、行号、滚动偏移是派生状态，不作为跨布局位置事实。
正文未变时字号、宽高、边距、图片晚到等重排保持同一文字／图片锚点；
内容变化后在当前章解析可用锚点或回退到章内比例，不制造超出范围的位置。

换源首先保留本地 bookId 和当前阅读位置，候选内容准备成功再替换当前会话。
新目录按唯一章节 URL、唯一规范化章名定位；跨源通常需使用章名。中文数字、
全角和标点差异可规范化，自动匹配排除卷标题；重名、无匹配或歧义让用户选章，
不能静默用旧章节序号或取末章宣称准确续读。取消／失败保留原会话与进度。

覆盖、平移、无动画横向分页与上下连续滚动均为真实模式；目录顺倒序、刷新、
跳章、章内进度、上一章／下一章与自动阅读共用阅读会话。点击区、拖动、鼠标滚轮
和系统返回手势由平台适配。空正文、单页、缺章、目录缩短和图片失败都必须结束
定位／加载状态，不能永久隐藏正文。

字号、字体、字重、行距、段距、边距、正文宽度、八种预设主题、自定义颜色和本地
背景图实际影响呈现并持久化。正文图片与书封缩略图的解码需求分开；已离开视口的
章节与图像有释放策略，会话缓存不构成离线下载功能。

## Web、购买和资源生命期

原生阅读器不嵌整套网页应用；书源登录、验证码、动态网页获取可以使用受控 Web
宿主。平台只呈现当前有效请求，Cookie 回到对应来源私有 owner，不泄漏给公共
图片加载器。不得绕过验证码或忽略支付状态。源声明 payAction 仅在用户确认书籍、
来源和章节后执行；确认界面取消不发购买调用，成功后重载当前章节。

搜索、书籍、章节、换源、图像租约与 Web 请求分别持有取消和代次。切换与关闭后
旧结果不能进入新页面或重建已退休来源私有状态。关闭等待实际运行任务及存储
收口；iOS 进入后台和页面隐藏及时保存位置、暂停自动阅读，不能只依赖进程终止。
阅读时隐藏非阅读导航／音乐控件但不停止音乐会话，退出后恢复容器呈现。

本端数据不自动云同步；不额外建立账号、WebDAV、网页数据迁移或备份恢复体系。
源码分析、纯规则测试、平台组件、宿主与构建证据分别记录，不互相代替。

## 书源与替换管理

书源与替换净化使用本端共享的管理列表、工具栏、批量选择、原位表单和居中导入确认。搜索／分组不丢失不可见项的选择；全选选当前可见项，取消全选清空全部，反选只翻转可见项。删除分组仅移除标签，保留源／规则。

书源协议明确区分阅读源（Legado）、异次元、轻悦时光（QYSG），与文本／音频／图片／文件内容类型独立。Legado 保留 Reader 六标签64字段的名称、顺序与行数；异次元编辑真实输入键，QYSG 编辑 HTML／脚本或远程候选地址及实际请求／登录配置。不做协议转换或旧数据迁移，未改扩展字段保留 JSON 类型，可在扩展标签编辑。保存沿用运行器 revision／原子替换。Debug 和占位校验按钮不提供。

书源文件／网络／粘贴先经运行器 `library.previewImport`；默认全选，展示协议、分组与已存在状态，确认后仅安装所选。替换规则文件／网络／二维码图片先解析并调用 Node 校验，保留外部 ID；预览默认选新增／更新，不选已有。取消不写，规则保存后沿现有处理器刷新当前阅读内容。规则编辑原位提供 name、group、pattern、isRegex、replacement、scopeTitle、scopeContent、scope、excludeScope、timeoutMillisecond，复制／粘贴不替换当前编辑项的身份。二维码只解码用户所选图片。
