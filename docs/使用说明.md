# MeowFilm 使用说明（只讲配置与使用）

这份文档只回答两件事：

1) **要配什么**  
2) **怎么用起来**

> 核心结论：MeowFilm 必须配好 **catpawrunner 地址** + **站点列表** 才能正常搜索/播放；GoProxy 属于“播放经常需要 headers”时再加的可选项。

---

## 1. 你需要准备什么

- **MeowFilm**：主程序（前端 + 后端）
- **catpawrunner**：解析/脚本运行时（MeowFilm 依赖它来跑站点脚本）
- **GoProxy（可选）**：当直链播放需要 headers（常见于部分网盘直链）时，用它做透传

---

## 2. 启动（本地最小可用）

### 2.1 启动 catpawrunner

```bash
cd catpawrunner
npm i
npm run dev
```

默认监听 `:9988`。

### 2.2 启动 MeowFilm

构建（推荐一次性构建前后端资源）：

```bash
cd MeowFilm
bash build-all.sh
```

启动：

```bash
cd MeowFilm
MEOWFILM_ADDR=":8080" ./build/meowfilm
```

首次启动默认管理员：`admin/admin`。

### 2.3（可选）启动 GoProxy

```bash
cd GoProxy
go run .
```

默认监听 `:3010`。

---

## 3. MeowFilm 需要配置什么（按顺序来）

打开 `http://127.0.0.1:8080/` 登录后进入后台（一般是 `http://127.0.0.1:8080/dashboard/`）。

### 3.1 配 catpawrunner（必须）

在后台添加 catpawrunner 服务，并设置为 Active：

- 示例：`http://127.0.0.1:9988/`

没配好时，最典型的报错就是：**“catpawrunner 接口地址未设置”**。

### 3.2 配“视频源站点列表”（必须）

每个站点只需要 3 个关键字段：

- `key`：唯一标识（自己取，别重复）
- `name`：显示名（可空）
- `api`：站点脚本的 **spider 基路径**（不要写 `.../search`、`.../detail` 这种 action）

`api` 常见两种写法：

- `"/spider/<site>/<ver>"`
- `"/<runtimeId>/spider/<site>/<ver>"`

示例：

```json
[
  { "key": "site1", "name": "站点1", "api": "/spider/site1/3" }
]
```

配置完成后：

- 首页应该能看到站点入口
- 搜索应该能返回站点结果
- 点进详情页应该能出选集与播放

### 3.3（可选）配 GoProxy（播放经常失败才需要）

当你遇到“能拿到直链但浏览器播不了/需要 headers 才能播”的情况，再开启 GoProxy：

- 在后台打开 GoProxy（启用）
- 填一台可访问的 GoProxy 地址

示例（最常用）：

```json
[
  { "name": "local", "displayName": "本机", "base": "http://127.0.0.1:3010", "pans": { "baidu": true, "quark": true } }
]
```

如果你的 GoProxy 通过反代挂在二级目录（例如 `https://example.com/proxy`），这里的 `base` 就填 `https://example.com/proxy`（要包含二级目录）。

### 3.4（可选）配 TMDB / 豆瓣（想要更完整元数据才配）

- `TMDBAPIToken`：不配也能用“站点搜索”，但 TMDB 搜索/详情会提示未配置
- 其他项（API Base / Img Base / 豆瓣代理）按你的网络情况选填即可

---

## 4. catpawrunner 需要配置什么（最少）

你只需要保证：

- catpawrunner 能启动并对 MeowFilm 可访问（例如 `http://127.0.0.1:9988/`）
- 运行目录下有脚本入口（`custom_spider/` 里有可用脚本；或通过在线配置下载）

可选项（用不到就别动）：

- 全局代理：`config.json` 里的 `proxy`
- 网盘 mock：`config.json` 里的 `pan_mock`
- m3u8 + GoProxy：`config.json` 里的 `goProxyApi`

---

## 5. 怎么用（用户视角）

1) 访问 MeowFilm 首页  
2) 选站点或直接搜索  
3) 进入详情页 → 选集 → 播放  
4) 收藏/播放历史会自动记录  

---

## 6. 最常见问题（简短排错）

- **提示“catpawrunner 接口地址未设置”**：后台把 catpawrunner base 填上并设为 Active（如 `http://127.0.0.1:9988/`）
- **能搜到但进详情/播放报错**：站点 `api` 很可能填错了（必须是 `/spider/<site>/<ver>` 这种“基路径”）
- **直链能拿到但播不了**：在后台启用 GoProxy 并配置 `base`（如 `http://127.0.0.1:3010`）
