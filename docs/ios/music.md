# 音乐能力

## 范围

- 页面：推荐、频道、我的、搜索与结果、公开及本地歌单、设置、账号、完整播放器、歌词、队列和历史。
- 官方平台：网易云音乐、QQ 音乐、酷狗音乐。
- 本地能力：加密曲库与凭据、显式曲库导入与回滚、播放队列和历史、系统媒体会话。
- 当前不提供第三方脚本音源、音箱控制或局域网供流、用户下载及离线库。

## 播放与音质

- 网易云标准音质不做本地会员拦截，以平台实际返回决定能否播放。
- 高音质检查真实权益；试听、受保护或无权限资源不能作为完整歌曲。
- 页面显示平台实际返回的音质，不用请求音质代替。
- 平台错误按实际原因分类，诊断信息不得包含凭据、完整签名 URL 或原始响应。

## 页面数据请求

- 推荐与频道的普通歌单卡片消费目录返回的 ID、标题、封面、类型等摘要；已返回的歌曲、成员与预览直接保留，不为了展示摘要进一步读取歌单成员或播放资源。
- 歌曲列表使用已有展示字段和原生来源定位；可选字段不要求补齐。缺少当前展示必需字段时，只对当前缺失项进行必要的本平台补读。
- 聚合搜索取得所选平台当前页的结果，在本地分组、去重和排序。已有 ID、MID、hash 与 `sourceKey` 用于来源定位；信息不足时保守分组，不为融合追加详情或跨平台查询。
- 歌单首屏与后续页按真实成员分页读取。接口已经返回完整批次时，业务层保留完整数据，卡片截行或列表分页只是视图投影。未展示 tab 只保留既有数据，必要补读由明确选择触发。
- 有效已加载页由页面所有者复用；新查询、明确刷新或真实范围失效才清理。页面覆盖、重新绑定和返回不等于新的数据请求。
- 明确播放才进入候选匹配、音质／权限和音频解析链。完整保存必须证明成员覆盖与快照有效，再进入曲库事务；成员完整性与可播放性分别判断，保存不解析音频。
- QQ／酷狗的单页证据不代表全歌单快照。完整动作仍验证完整有序成员，并与页面已观察位置核对；不能以总数、单页哈希或游标结束代替完整性。
- 图片读取独立于目录、成员、展示补读、匹配及音频解析，使用无 CookieJar／凭据存储的独立会话；重定向遵守已有图片来源及 HTTPS 边界。

## 平台客户端上下文

客户端标识、匿名服务状态、协议要求的设备登记、账号授权与单次协商材料具有不同作用域。正常未登录可以使用合法匿名能力；已有账号认证失效不能悄悄转换成匿名成功。

| 平台 | 所有者与交接 |
| --- | --- |
| 网易云 | 安装客户端资料由 `NativeMusicClientService` 在独立受保护文档中持有，公开读取、新登录及适用的播放读取复用。已有凭据的不同设备绑定保留原身份；账号授权及绑定资料仍由凭据 writer 验证和保存。 |
| QQ | 公开客户端 owner 继续使用既有 `music.qq-public.v1` 文档、QIMEI 与匿名 session；账号 adapter 取得同一客户端资料，但账号 auth 不进入公开实例或匿名文档。 |
| 酷狗 | 安装 seed、派生 MID 与已确认 dfid 由客户端 owner 保存，新登录复用；登记只在协议需要的明确业务中发生。导入账号的不同设备绑定不替换成安装标识。 |

- 受保护文档缺失可以正常初始化；损坏、不可读和不兼容状态是错误，不静默重建身份。必要稳定标识跨启动复用，退出账号不无依据重置安装标识。
- 受信响应的客户端更新核对来源、身份、访问代次和读取修订，由唯一 writer 条件提交；账号授权更新仍经过现有账号 lease／CAS，不借客户端更新绕过授权校验。
- 同一客户端协商按等待者合并；单个调用取消不误取消其他有效等待者。访问撤销及关闭清理受影响状态，实际 HTTP 预算直到物理执行结束才释放。
- 产品装配显式提供受保护客户端存储；独立构造的易失上下文不承诺跨启动持久化，也不能作为持久化失败时的回退。

## 缓存

- 实际播放后完整缓存音频，命中、失效、坏文件回退网络和清理由原生服务负责。
- 歌词、封面和播放展示缓存与音频缓存分别管理。
- 缓存不是下载管理；曲库、队列和同步数据不能作为可淘汰缓存。
