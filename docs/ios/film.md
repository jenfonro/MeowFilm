# iOS 影视

`MeowFilmFeature` 持有影视目录模型、豆瓣适配、首页状态、搜索、收藏和 UIKit 页面。App 在 `MeowfilmAssembly.filmSources` 装配首页数据源，在协调器中负责详情导航与实际视频呈现；影视不依赖音乐业务模块。页面请求遵守[共同契约](../common/pages/data-requests.md)。规则、猫源和视频源设置见[影视设置](film-settings.md)；管理清单已接入影视搜索，尚不作为首页来源。

## 首页和数据源

底部“影视”进入保留的首页，使用所属主页面的 App 页头；四个主页面各自保留独立页头。页头显示当前数据源并提供选择菜单。当前装配豆瓣，新增来源实现 `FilmSource` 并加入装配列表即可进入同一选择菜单；不为尚未接入的来源展示虚假选项。

`FilmSourceDescriptor.id` 标识来源；`FilmItemIdentity` 使用来源 ID 与上游影片 ID 的组合。来源自行返回栏目与影片，页面不按豆瓣分类解释其他来源。豆瓣读取与 Windows 一致的四个栏目：热门电影、热门剧集、新番放送、热门综艺，每栏请求 12 个摘要，不预取详情或播放地址。图片地址沿用豆瓣图片代理归一化。

`FilmHomeModel` 持有所选来源、请求及本页面内按来源区分的快照。重复进入不重复读取；切源立即撤销旧请求发布权、取消读取，恢复对应快照或发起首次读取。旧成功或错误不能覆盖新来源。失败在统一错误浮层中提供“重试”，浮层退出后显式重新读取；“确定”仅关闭通知，不发起请求，之后仍可下拉刷新。页面正文只保留加载、失败或空集合状态，不放重试控件。页面从导航生命周期释放时关闭请求。覆盖详情或切换主页面保留首页及滚动位置。

豆瓣 API 与影视图片使用独立匿名 `URLSession`，不使用音乐账号、Cookie 或系统凭据。API 等待后续数据的空闲超时为 15 秒，图片为 30 秒；两类请求的完整资源加载时限均为 30 秒。响应按头部与分块读取执行 4 MiB 的资源边界。API 不跟随重定向；图片重定向重新构建匿名请求。真实空结果、网络错误与加载状态分别处理。

## 详情和收藏

详情消费显式传入的 `FilmDetail`，包括海报、标题、简介、日期、季数、集数、分季剧集、演职人员与相似作品，不因页面出现发起隐藏的详情或片源搜索。已有豆瓣首页摘要只提供海报、标题、评分及摘要副标题；当前未接入详情与影视片源，因此缺失内容保持空状态，播放按钮显示“暂无片源”。后续真实详情应在对应数据源适配边界获取后传入，不能用猜测集数、演员或播放 URL 补齐。

有真实播放 URL 时，选季更新集数，剧集或播放按钮将 URL 交给 App 呈现原生播放器。影片收藏由稳定 `FilmLibrary` 持有，用 `meowfilm.film.library.v1` 保存来源与影片复合身份；收藏不触发播放，也不写音乐曲库。

全局影视搜索的本端装配、会话、真实详情交接、接通状态及定向测试入口见[影视搜索](film-search.md)。

## 布局和交互

首页竖海报为 2:3，一屏三张完整卡片及第四张边缘；宽度按当前安全区视口计算。卡片只显示海报与标题，不显示评分（评分在详情元信息中）。卡片使用 `pic.normal`；同一条目规范化后的 `pic.large` 作为 `FilmItem.largePosterURL`，供详情顶部大图使用。详情按详情背景图、`largePosterURL`、卡片海报的顺序读取，大图失败时回退到下一项。顶部大海报放在固定裁剪的图片框中，透明度渐变遮罩挂在图片框上，在其下缘衔接页面背景；标题、元信息与播放、收藏位于图片框下方，不叠在海报或渐变上。海报静止时略微放大，上滑时图片框与正文同速上移，框内图片随标题接近页头缩回原尺寸，始终铺满图片框，两侧不露空白，渐变固定在图片框下缘。页头背景在海报位于其下方时保持透明，标题接近页头下缘时淡入，到达时不透明并显示片名，因此滑动时页头下缘不出现色带；下拉回弹时图片框保持在顶部。海报可见且页头未过半显现时，状态栏和返回键为浅色，并配随页头显现淡出的顶部暗色渐变；之后或没有海报时恢复页面默认样式。减少动态效果时取消缩放。

音乐与影视共用 `MeowUI.PressFeedback`：触摸时立即缩小和降低透明度，释放、滚动取消、离屏及复用恢复。单元格通过 `layoutAtRest` 在静止几何下完成系统布局，按压缩放不改变内容尺寸，标题不会重新折行。共享 `ArtworkImages` 与 `ArtworkView` 负责缓存、后台解码、取消与复用，同一缓存内相同 URL 的并发读取和解码合并，最后一个消费者取消需等实际读取停止；音乐、影视分别注入自己的数据读取规则和独立缓存。音乐保留显式重试和可见新挂载时的可恢复错误重试，非法地址、坏图及资源超限不重发同URL；影视不增加自动挂载重试。

## 分类浏览

首页支持分类浏览的数据源在栏目右侧显示“查看更多”，通过 `FilmCategorySource` 与 `FilmCategoryModel` 打开对应 UIKit 页面；卡片进入既有详情导航。豆瓣电影、剧集、动漫、综艺使用原有 `recent_hot` 数据来源，动漫保持 `tv_animation`，不接入服务端番剧日历。

分类页安全区内每行三张 2:3 海报卡片，沿用首页图片与按压反馈。筛选名称固定在左侧，每个维度一行，右侧使用共享 `MeowUI.FilterTagsView` 胶囊：单行横滑，溢出才显示箭头，展开后换行并撑开布局，选中后收起该行。音乐通过自己的业务类型适配器使用同一控件，原有标识和行为保持不变。

电影组合“分类＋地区”；剧集在“剧集”分类下支持地区，选择动漫或纪录片时隐藏地区（上游的 `type` 无法同时表达这两种类型与地区）。切回剧集保留先前地区选择。综艺支持国内／国外；动漫固定为现有豆瓣动漫来源，不展示无效筛选。

分类每次请求 24 条，按响应原始条数推进偏移，短页结束；显示条目按来源与影片 ID 去重，不受首页 12 条预览裁剪影响。下滑接近底部或点击“加载更多”读取下一页；筛选变化清空旧列表并从首屏重载，取消和请求身份共同阻止过期结果写入。分页失败保留已加载影片，通过统一错误浮层中的“重试”显式重读同一偏移，失败期间底部分页禁用且滚动不自动重试；“确定”关闭浮层不发请求，仍可下拉刷新首屏。离开页面生命周期时取消请求，详情返回保留当前筛选与滚动位置。
