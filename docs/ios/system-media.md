# 系统媒体控制

音乐沿用 `AVAudioSession` 的 playback category 和 App 的 audio 后台声明。`PlaybackController` 管理当前播放尝试，`PlaybackSystemSession` 负责 `MPNowPlayingInfoCenter`、`MPMediaItemArtwork` 与 `MPRemoteCommandCenter`；`MusicSystemMetadataCoordinator` 将音乐资料映射到该会话，不另建播放器或系统信息写入者。

## 锁屏、控制中心与灵动岛

锁屏歌词开关默认开启。有当前原文歌词时，系统标题为该句歌词，副标题为“歌名 / 歌手”；关闭开关、没有歌词或尚未到第一句时，标题为歌名、副标题为歌手。沿用歌名上的收藏标记，歌手缺失时不拼空分隔符。歌词跟随原生播放时间，拖动及切歌使用当前播放尝试的资料。

这些是共享 Now Playing 字段，控制中心及使用同一信息的外设也可能显示歌词。它们不是只对锁屏生效的独立文案。系统音乐灵动岛使用同一会话和歌曲封面，不增加 ActivityKit 或 Widget extension。

应用提交完整文本、当前封面、时长、位置和播放速率；卡片布局、文字是否滚动、滚动方向及速度、灵动岛的紧凑与展开呈现由 iOS 决定。应用没有实现往返滚动动画，也不保证特定系统版本上必定滚动或灵动岛始终可见。

## 后台封面与身份

当前歌曲的系统封面发布不依赖前台界面渲染。后台切歌、图片在锁屏后完成以及缓存命中均可更新封面；界面绘制和配色采样仍按前台状态暂停。播放器各展示面复用现有图片请求、缓存和缩略图解码，歌词及进度更新不重复下载或编码封面。

封面和歌词归属于当前歌曲、队列条目、账号访问代次及原生播放尝试。换歌、失去访问权限、停止或关闭后，过期结果不能恢复旧信息；新歌没有封面或图片失败时不沿用上一首封面。既有图片传输、解码和字节上限仍属于资源边界。

## 耳机及系统命令

系统命令进入当前 owner 的播放与队列流程：

| 命令 | 行为 |
| --- | --- |
| `playCommand` / `pauseCommand` | 明确播放或暂停，重复命令不反向切换 |
| `togglePlayPauseCommand` | owner 结合原生意图与尚在准入的播放请求，同步转换为明确播放或暂停；再次切换可取消待恢复 |
| `nextTrackCommand` / `previousTrackCommand` | 按当前队列能力启用，进入同一上下首流程 |
| `changePlaybackPositionCommand` | 仅在媒体可定位时接受；实际原生定位完成才更新完成状态 |

EarPods 和部分 AirPods 的单次、双次、三次操作由耳机与系统解释；App 接收语义命令，不计数物理点击。其他耳机或用户设置可能采用不同映射。播放恢复仍遵守[音源排除与准入](music-sources.md#错源)。

耳机输出不可用时立即暂停，并撤销尚未完成切歌的自动播放意图，迟到的队列结果不能从新输出自动播放；已提交的队列内容无需回滚，后续明确播放可继续。输出断开属于环境事实，既有系统适配器在当前播放会话或有效 owner 订阅存续时持续监听，覆盖旧播放器已停止、新音源尚未准备完成的空档。该订阅本身不激活音频会话、不安装媒体命令或发布系统卡片；取消／禁用最后一个订阅且没有播放会话后释放监听。

## 音频中断与交接

原生播放尝试建立后，即开始接收音频会话中断，覆盖 scoped HLS listener 异步启动至 item 安装的等待期。只有系统允许、当前播放意图有效且恢复资格仍属于当前尝试时才自动恢复；中断期间的暂停撤销恢复资格，新歌曲不继承旧歌曲的自动恢复资格。实际中断结束后，用户仍可明确播放。

停止和关闭清理音乐命令、元数据与媒体资源。音乐与影视共用 `PlaybackController` 和同一个系统媒体会话。视频先静默准备，真实首帧及音频准入成功后才接管音乐；准备、准入失败或取消时，音乐保持原播放尝试及播放／暂停意图，不提前停止。

成功接管时撤销旧音乐待播放、恢复及导航请求，防止残留命令或迟到结果夺回视频的播放所有权。音乐队列保留，已接受的播放及退出事实继续按原身份和授权记账，但不能触发旧选择的自动续播。用户可随后明确播放音乐；视频关闭后不自动恢复音乐。

## 验证边界

Swift 测试覆盖元数据、身份、队列意图和播放策略；iOS 组件测试覆盖 UIKit 图片、系统元数据及通知适配。注入音频通知只证明桥接行为，模拟器和构建不能证明物理耳机点击、真实来电或灵动岛外观。系统滚动、支持机型上的灵动岛封面和指定耳机操作需要设备验收。

公开接口依据：[MPNowPlayingInfoCenter](https://developer.apple.com/documentation/mediaplayer/mpnowplayinginfocenter)、[MPRemoteCommandCenter](https://developer.apple.com/documentation/mediaplayer/mpremotecommandcenter)、[EarPods 操作](https://support.apple.com/guide/iphone/use-earpods-iph7a203b610/ios)。成熟播放器如 VLC for iOS 同样直接使用 MediaPlayer；本实现复用项目已有能力，没有复制 VLC 代码或增加其播放器依赖。
