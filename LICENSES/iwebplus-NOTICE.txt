Releases of the jenfonro/QQMusicApi fork. The Apache-2.0 plugin communicates
with it only over loopback HTTP; QQMusicApi is not relicensed under Apache-2.0.
Upstream project: https://github.com/L-1124/QQMusicApi
Fork source and build: https://github.com/jenfonro/QQMusicApi
Releases: https://github.com/jenfonro/QQMusicApi/releases
Upstream base: main, version 0.8.2, commit 27861e51432ea6b6e88dc35c4e8c8e239c0339e8.
Fork main adds Cookie compatibility, account-scoped radar, and play_duration
patches. Release versions use 0.8.2-iwebplus.N; availability is determined by
published Releases, not by this version pattern.
This is a fork build, not an official upstream binary.

corresponding source (including launcher, patches, build materials and dependency
sources), full GPL text, upstream notices, and Python and dependency licenses.

The plugin ZIP includes no Python runtime, QQ executable or manifest, QQ
